# 面试题库 · Interview Bank

个人技术面试题库。面向**华为（车BU 苏州 / 计算产品线 南京）+ 亿嘉和（南京）**，技术主线为**感知算法落地到硬件**（AI 算法 / 端侧部署 / 图像算法 / 感知规控）。

不是通用八股合集。每一道题都尽量挂到自己的项目或文档上——这是和"背题库的人"拉开差距的地方。

---

## 二、怎么用

```bash
# 1. 从本地教学/项目文档批量抽取题目草稿（会跳过操作步骤类标题）
python tools/extract.py --scan

# 2. 生成单文件题库网页 dist/bank.html（双击即开，手机可用）
python tools/build.py

# 3. 校验所有题卡字段与结构
python tools/validate.py
```

网页支持：全文搜索、四维筛选（模块 / 优先级 / 难度 / 岗位）、答案折叠、错题标记（存 localStorage）。

## 三、目录

```
面试题库/
├── content/          一题一 md，唯一内容源
├── companies/        企业档案：岗位要求、流程、面经（与技术题分开）
├── sources/          开源复用台账、来源登记
├── tools/            extract / build / validate 三个脚本
├── dist/             bank.html 单文件成品（Pages 托管的就是它）
├── docs/             schema.md 字段规范
└── README.md
```

## 四、建设状态

见 `CHANGELOG.md`。第一版目标是**完整目录 + 题目索引**，答案按 P0 逐步补。

## 五、两条硬规则

1. **网页内容不许手改**。所有修改落到 `content/**.md`，再跑 `build.py`。否则网页和源文件必然不一致。
2. **来源必须可追**。`source_ref` 不许空；来自开源仓库的必须在 `sources/upstream.md` 登记，并遵守其许可证。
