## 题目

**背景**：手写代码环节的一道数组题，面试官先要思路，再要求说明能不能原地做、复杂度多少。

**问**：给一个整数数组，把每一项替换成它右侧所有元素的最大值，最后一项替换成 -1，怎么实现？

## 口述答案

> 逆序遍历，维护一个 `max_right` 变量。先把最后一个元素置为 -1，`max_right` 初始也是 -1；然后从倒数第二个往前走：暂存当前值，把当前位置写成 `max_right`，再用 `max(max_right, 暂存值)` 更新 `max_right`。一趟扫描完成，时间 O(n)，额外空间 O(1)，而且是原地修改。关键点是"先写后更新"的顺序，写进去的必须是右侧元素的最大值，不能把自身算进去。边界要处理：空数组直接返回，长度 1 时结果就是 `[-1]`。若不允许改原数组，就得多开一个结果数组，空间变 O(n)。

## 讲深一层

```cpp
vector<int> replaceRightMax(vector<int> a) {
    int mx = -1;
    for (int i = (int)a.size() - 1; i >= 0; --i) {
        int cur = a[i];
        a[i] = mx;
        mx = max(mx, cur);
    }
    return a;
}
```
`[17,18,5,4,6,1]` → `[18,6,6,6,1,-1]`。注意 `i` 用 `int` 且先转 `size()-1`，否则无符号下溢成死循环。
循环不变量是 `mx` 恒等于 `a[i+1..n-1]` 的最大值，每轮先写后更新即可保持，正确性用归纳法一句话就能证完。若要求保留原数组，就得额外开一份结果，空间从 O(1) 退到 O(n)。

## 高频追问

1. **正序遍历能做吗？** —— 需要先建后缀最大值数组 `suf[i]=max(a[i..])`，再赋 `a[i]=suf[i+1]`，时间 O(n) 但空间 O(n)
2. **如果要求返回新数组呢？** —— 从右往左写入结果数组，`res[i]=mx` 后再更新 `mx`，同样 O(n)/O(n)
3. **和"除自身以外数组的乘积"像吗？** —— 同一类"前缀/后缀累积"套路，一个用 max 一个用乘法，都要处理自身不参与

## 易错点

- 先赋值再更新导致把自身算进最大值——顺序必须是"写旧 mx、再更新 mx"
- 用 `for (int i = n - 1; i >= 0; --i)` 而 `n` 是 `size_t`——`n-1` 在空数组时下溢，循环直接崩
- 忘了最后一项是 -1 而不是右侧最大值——空集的 max 定义为 -1 是题面约定，不是算出来的
