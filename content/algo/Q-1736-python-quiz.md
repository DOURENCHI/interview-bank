## 题目

```python
import numpy as np
b = np.array([1, 2, 3])
c = np.array([[1, 2, 3], [4, 5, 6]])
print((c * 2).tolist(), (c * b).tolist())
```

- **A.** [[2, 4, 6], [8, 10, 12]] [[1, 4, 9], [4, 10, 18]]
- **B.** [[2 4 6] [8 10 12]] [[1 2 3] [4 5 6]]
- **C.** [[2 4 6] [8 10 12]] [[2 6 12] [8 12 18]]
- **D.** [[1 2 3] [4 5 6]] [[2 4 6] [8 10 12]]

## 口述答案

答案是 **A. [[2, 4, 6], [8, 10, 12]] [[1, 4, 9], [4, 10, 18]]**，实际输出 `[[2, 4, 6], [8, 10, 12]] [[1, 4, 9], [4, 10, 18]]`。

c * b 里 b 被广播到两行，第二行是 [4,5,6]*[1,2,3] = [4,10,18]。这是逐元素乘，形状变了但 b 本身没变。

## 讲深一层

讲深一层：标量 2 被广播到每个元素，c*2 每个格子翻倍；b 的形状 (3,) 按尾部对齐扩成 (1,3)，再复制到两行，所以第二行是 [4,5,6]*[1,2,3]=[4,10,18]。结果是新数组，b 与 c 都没被修改。若写成 c *= b 则原地写回 c，此时 c 变而 b 不变，这是区分是否复制的直观办法。

## 高频追问

1. **广播会复制数据吗？** —— 逻辑上扩展，实现上用 stride 0 避免真实复制。
2. **c\*b 会改 b 吗？** —— 不会，返回新数组。
3. **怎么判断是否原地？** —— 看有没有赋值，`*=` 是原地。

## 易错点

- 把 c\*b 算成 [[1,2,3],[8,10,12]]：第二行漏乘，实际 [4,10,18]
- 以为广播修改了 b：b 仍是 [1,2,3]
- 用 \* 代替矩阵乘：形状对但数值完全不是矩阵乘结果
