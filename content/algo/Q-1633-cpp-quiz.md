## 题目

```cpp
struct S {
    static int n;
    S() { n++; }
    ~S() { n--; }
};
int S::n = 0;
int main() {
    S a;
    { S b, c; cout << S::n; }
    cout << S::n;
}
```

- **A.** 31
- **B.** 33
- **C.** 11
- **D.** 32

## 口述答案

答案是 **A. 31**，实际输出 `31`。

静态成员 n 所有对象共享：块内有 3 个对象；块结束 b、c 析构后剩 1 个。

## 讲深一层

静态成员属于类而不属于对象，所有实例共享同一份存储；类内声明、类外定义（C++17 可写 inline static 就地初始化）。块内 a、b、c 三个对象构造完，n 累加到 3；块结束 b、c 逆序析构各减 1，只剩 a，n=1。n 的净值恒等于当前存活对象数。

## 高频追问

1. **第一个 3 怎么来的？** —— 进入块后 b、c 构造，加上外面的 a，共 3 个对象，每个构造函数都 n++。
2. **第二个 1 呢？** —— 块结束时 b、c 析构各 n--，a 仍存活，所以剩 1。
3. **为什么静态成员要类外定义？** —— 类内只是声明，不分配存储；类外 int S::n = 0; 才是定义。C++17 起可用 inline static 省掉这步。

## 易错点

- 以为静态成员每个对象一份，答 11 选 C
- 漏算块内第三个对象，答 21 或 32 选 D
- 认为块结束时三个对象全析构，答 0（不在选项内）
