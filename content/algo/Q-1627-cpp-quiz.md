## 题目

```cpp
int f() { static int n = 0; return ++n; }
int main() {
    f(); f();
    cout << f();
}
```

- **A.** 1
- **B.** 2
- **C.** 3
- **D.** 0

## 口述答案

答案是 **C. 3**，实际输出 `3`。

static 局部变量只初始化一次，之后的调用接着上一次的值累加。

## 讲深一层

static 局部变量存放在静态区，生命周期到程序结束，初始化只在第一次执行到声明处发生（C++11 起保证线程安全）。所以三次调用依次得到 1、2、3。去掉 static 后每次调用都重新初始化为 0，输出 1。它与全局变量的差别只是作用域和链接性，存储期相同。

## 高频追问

1. **为什么是 3 不是 1？** —— n 只初始化一次，之后每次调用都在上次的值上 ++，第三次自然得 3。
2. **初始化发生在什么时候？** —— 首次执行到该声明语句时；若初始化器是常量表达式，也可在静态初始化阶段完成，效果一样。
3. **多线程下安全吗？** —— C++11 的 magic statics 保证首次初始化只执行一次且线程安全；C++03 需自己加锁。

## 易错点

- 把 static 当「每次调用重置」，答 1 选 A
- 漏算前面两次调用，答 2 选 B
- 以为 n 未初始化默认为 0 且每次归零，答 0 选 D
