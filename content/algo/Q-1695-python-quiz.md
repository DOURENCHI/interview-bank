## 题目

```python
print(7 // 2, 7 / 2, -7 // 2, 7 % 3, -7 % 3)
```

- **A.** 3 3.5 -4 1 2
- **B.** 3 3.5 -3 1 2
- **C.** 3 3.5 -4 1 -1
- **D.** 4 3.5 -3 2 2

## 口述答案

答案是 **A. 3 3.5 -4 1 2**，实际输出 `3 3.5 -4 1 2`。

// 是向下取整除法（向负无穷取整），所以 -7 // 2 = -4 而不是 -3；/ 永远得到 float；% 的结果符号跟除数，这里 -7 % 3 = 2。

## 讲深一层

讲深一层：// 定义为 floor(a/b)，向负无穷取整；% 的结果符号跟除数走，并恒满足 a == (a//b)*b + a%b。所以 -7//2=-4、-7%2=1，而 7//-2=-4、7%-2=-1，两处负数方向相反。对 float 同样成立但会引入精度误差。C++ 的 / 向零截断、% 符号跟被除数，直接照搬必错。

## 高频追问

1. **和 C 的 / 对负数差别在哪？** —— C 里 -7/2 得 -3（向零截断），Python 得 -4（向下取整）。
2. **怎么同时拿商和余数？** —— divmod(-7,2) 返回 (-4,1)，可直接元组解包。
3. **7/2 为什么是 3.5？** —— / 永远是真除法返回 float，要整数商必须用 //。

## 易错点

- 把 -7//2 算成 -3：那是向零截断，输出变 `3 3.5 -3 1 2`，正好是干扰项 B
- 以为 % 符号跟被除数：-7%3 会算成 -1，实际是 2
- 以为 // 总返回 int：10.0//3 得 3.0，类型仍是 float
