## 题目

**题目**（华为机考）：纸张一行能放下的**字符数**有上限 W。一篇文章由若干短语组成，短语之间用空格分隔；同一行的短语之间也用恰好一个空格连接。要求不能把一个短语拆到两行（假设任何短语长度 ≤ W），求把所有短语印完最少需要多少行。
**问**：给出算法与代码。

## 口述答案

> 贪心，一遍线性扫。规则：维护当前行的已用长度 cur，对每个短语按顺序尝试——如果这行还是空的，直接放（cur = 长度）；否则需要"一个空格 + 短语长度"的额外空间，cur + 1 + len ≤ W 就放下（cur += 1 + len），放不下就换行（行数 +1，cur = len）。正确性很直觉：每个短语独立不可拆，能塞进当前行就一定不亏——留给后面短语的行宽不会更差；这就是典型的交换论证，任何最优解都能调整成贪心的样子。复杂度 O(总字符数)。两个边界要想清楚：短语长度恰好等于 W 时自己独占一行；实现时如果题目允许用空格补齐右端（两端对齐），那是另一道题（LeetCode 68 文本左右对齐），先看清题意。

## 讲深一层

```cpp
int min_lines(const vector<string>& ws, int W) {
    int lines = 1, cur = 0;
    for (auto &w : ws) {
        if (cur == 0)            cur = w.size();          // 行首
        else if (cur + 1 + (int)w.size() <= W)
                                 cur += 1 + w.size();     // 接着放
        else { ++lines;          cur = w.size(); }        // 换行
    }
    return lines;
}
```
- 若题目输入是整段文本：先 `istringstream` 按空格切词，其余不变

## 高频追问

1. 如果允许拆分短语呢？——就不是逐词贪心，变成连续字符每 W 个切一刀
2. 两端对齐版怎么做？——每行额外空格按词间均匀分配，余数从左往右分（LeetCode 68）

## 易错点

- 漏掉"词间空格占 1 个字符"的宽度
- 单词长度超过 W 未做防御——按题意假设 ≤W，但面试时主动提出来是加分项
