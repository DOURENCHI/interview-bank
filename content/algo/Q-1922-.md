## 题目

**题目**（华为机考）：给定两个位数可能极长的非负整数（字符串形式），求它们相加的结果。
**问**：怎么实现？注意什么？

## 口述答案

> 不能用整数类型——位数可能几百上千位，long long 早溢出了。标准做法是**按位模拟竖式加法**：把两个字符串从最低位对齐，用双指针从末尾往前走，每位相加再加进位，结果位 = (位和 + 进位) % 10，新进位 = (位和 + 进位) / 10；两边走完后如果进位还剩 1，再补一位。时间 O(max(n, m))，空间同数量级。实现要点三个：结果要**反转**（从低位算起，输出前 reverse）；两指针各自判空（短的先走完就补 0）；最后检查进位。用 C++ 就直接 string 拼；用 Python 虽然原生 int 不限位数可以 int(a)+int(b)，但机考这么写会显得没理解考点，建议还是手写位运算过程。

## 讲深一层

```cpp
string add(string a, string b) {
    string res;
    int i = a.size() - 1, j = b.size() - 1, carry = 0;
    while (i >= 0 || j >= 0 || carry) {
        int s = carry;
        if (i >= 0) s += a[i--] - '0';
        if (j >= 0) s += b[j--] - '0';
        res += char('0' + s % 10);
        carry = s / 10;
    }
    reverse(res.begin(), res.end());
    return res;
}
```
- 同族题：大数减法（先比大小定符号）、大数乘法（每位乘完统一处理进位，O(n·m)）

## 高频追问

1. 大数乘法怎么做？——逐位乘累加到结果数组，再统一处理进位；更快用 FFT/Karatsuba
2. 输入可能带前导零怎么办？——结果输出前去掉前导零（保留一个 0）

## 易错点

- 直接 `stoll` 转数——超长输入直接溢出
- 忘了最后的进位（两个同位数相加最高位进 1）
