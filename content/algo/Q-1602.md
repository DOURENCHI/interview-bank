## 题目

**题目**：第一行一个整数 `n`，第二行 `n` 个整数（可能一行也可能多行），求和输出。

**样例**：
```
输入：
5
1 2 3
4 5
输出：
15
```
**问**：这种「不定长、可能跨行」的输入，C++ 怎么写才不出错？「读一行再切分」和「直接 `cin >>`」该怎么选？

## 口述答案

> 这类输入**不要按行读**。数字之间的空白（空格、换行、制表符）对 `cin >>` 完全等价，所以直接 `for (int i = 0; i < n; ++i) cin >> x;` 就够了，跨不跨行它自己处理。
> 只有当**一行是一个整体**（比如一行一个字符串、含空格的句子）时才需要 `getline`，此时要先处理上一行残留的换行符。

## 讲深一层

```cpp
// 场景一：n 个数，跨行无所谓
int n; cin >> n;
long long sum = 0;
for (int i = 0; i < n; ++i) { int x; cin >> x; sum += x; }

// 场景二：读到 EOF（不知道多少个数）
int x;
while (cin >> x) sum += x;

// 场景三：一行一个含空格的字符串
string line;
cin >> n;
cin.ignore(numeric_limits<streamsize>::max(), '\n');   // 关键：吃掉残留换行
for (int i = 0; i < n; ++i) {
    getline(cin, line);
    // 处理 line
}

// 场景四：一行不定长数字，先切再转
getline(cin, line);
stringstream ss(line);
int v;
while (ss >> v) nums.push_back(v);
```

**`cin >> n` 之后直接 `getline` 会读到空串**，这是 C++ 机考第一大坑：`>>` 停在换行符之前，换行符留在缓冲区，`getline` 立刻读到它并返回空串，后面所有数据错位一行。

## 高频追问

1. **`cin.ignore()` 的参数什么意思？** —— 忽略到指定字符或达到最大字符数为止；`numeric_limits<streamsize>::max()` 就是不设上限。
2. **`getline` 和 `cin.getline` 有什么区别？** —— 前者操作 `std::string`（推荐），后者操作 `char[]`，要自己管长度。
3. **Python 怎么做？** —— `sys.stdin.read().split()` 一把读完再切，最省心；按行处理用 `for line in sys.stdin`。

## 易错点

- `cin >> n` 后直接 `getline`，读到空串，数据整体错位一行
- 按行读却用 `scanf("%s")`，遇到空格就断
- 每行末尾有 `\r`（Windows 换行），字符串比较莫名失败
