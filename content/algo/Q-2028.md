## 题目

**场景**：影石嵌入式面经（2026-11-01）一面连着两问：既问了「如果一个链表存在环，你会采用什么算法检测」，又要求「手写一个函数，判断单链表是否存在环，并说明快慢指针为什么能够完成检测」——既要代码，也要推导。

**问**：判断单链表是否有环：代码怎么写？快慢指针（快 2 慢 1）为什么一定能在环里相遇？

## 口述答案

> **Floyd 判圈（龟兔赛跑）**：快指针每次走 2 步、慢指针每次走 1 步。**无环**：fast 先走到 NULL，返回无环；**有环**：两指针先后进环后，fast 每回合把与 slow 的距离拉近 1（相对速度 2−1=1），**距离有限，迟早从 1 变 0**——所以必然相遇，且因为每步只差 1，不存在「一步跨过」的问题。
>
> 为什么不会漏判：进环瞬间两者的距离是某个 d（0 ≤ d < 环长 L），每走一步 d 减 1（对 L 取模意义下），**最多 L 步内 d 必到 0**。这就是追及问题：只要相对速度不为 0、跑道是圈，必相遇。
>
> 进阶（必追问）：找入环点——相遇后把一个指针放回头结点，**两指针同速前进，再次相遇处就是入环点**。推导：头到入环点距离 a，入环到相遇点距离 x，环长 L，slow 在环内已绕 n 圈；由 2(a+x) = a + x + nL 得 **a = nL − x = (n−1)L + (L−x)**，即从头走 a 步与从相遇点走 L−x 步在入环点会师。复杂度 **O(n) 时间、O(1) 空间**；哈希表法也是 O(n) 时间但要 O(n) 空间，快慢指针赢在常数空间。

## 讲深一层

```cpp
#include <cstdio>

struct ListNode { int val; ListNode *next; ListNode(int v): val(v), next(nullptr) {} };

bool hasCycle(ListNode *head) {                /* Floyd 判圈：快 2 慢 1 */
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {               /* fast 一次跳两步，两个都要判 */
        slow = slow->next; fast = fast->next->next;
        if (slow == fast) return true;         /* 环内相对速度 1，必相遇 */
    }
    return false;                              /* fast 撞 NULL：无环 */
}

int main() {
    ListNode *a = new ListNode(1), *b = new ListNode(2), *c = new ListNode(3), *d = new ListNode(4);
    a->next = b; b->next = c; c->next = d; d->next = b;   /* 环：d 指回 b */
    printf("hasCycle=%d\n", hasCycle(a));      /* 1：有环 */
    d->next = nullptr;                         /* 断环后复测 */
    printf("no-cycle=%d\n", hasCycle(a));      /* 0：无环 */
    return 0;
}
```

**记忆锚点**：「快 2 慢 1，相对速度 1 必相遇；相遇后回头同速走，交点即入环（a = (n−1)L + (L−x)）」。

## 高频追问

1. **fast 一步走 3 步行不行？** —— 不稳。相对速度 2 与环长不互质时（如环长偶数、初始距离奇数）可能永远错开；步长差 1 保证 gcd(1, L)=1，模 L 下必达 0。
2. **和哈希表法怎么选？** —— 哈希表 O(n) 时间直观但 O(n) 空间；Floyd 同为 O(n) 时间且 O(1) 空间，还能顺势找入环点，链表长或内存紧时优。
3. **怎么顺便求环长？** —— 相遇后固定一个指针，另一个绕环计数回到相遇点，走过的步数即环长。
4. **Floyd 和「找重复数」什么关系？** —— 同一套判圈：把数组看成隐式链表 i → nums[i]，找重复数（Q-1837）就是找入环点，推导完全一致。

## 易错点

- 循环条件漏了 fast->next——fast 一次跳两步，只判 fast 在尾节点会空指针解引用。
- 先判相等再走——初始 slow==fast==head，先判永远返回 true；要先走后判。
- 入环点推导背错方向——是 a = (n−1)L + (L−x)，不是「a 等于 x」；操作是从头和从相遇点同速走。
- 只会写代码不会推导——影石这道题明确要求讲「为什么」，追及 + 取模必须说得出。
