## 题目

```python
xs = [1.0, 2.0, 3.0]
ys = [2.0, 4.0, 6.0]
def grad(w):
    return sum(2 * x * (x * w - y) for x, y in zip(xs, ys)) / len(xs)
def cost(w):
    return sum((x * w - y) ** 2 for x, y in zip(xs, ys)) / len(xs)
print(grad(2.0), cost(2.0))
```

- **A.** 0.0 0.0
- **B.** (0.0, 14.0)
- **C.** (6.0, 0.0)
- **D.** (0.0, 1.0)

## 口述答案

答案是 **A. 0.0 0.0**，实际输出 `0.0 0.0`。

w=2 正好是数据的真实斜率，预测全对：梯度为 0（不再需要调整），代价为 0。梯度为 0 就是收敛的判据。

## 讲深一层

对线性模型加平方损失，目标函数是凸二次型，驻点唯一且就是全局最优，所以 `grad(2)=0` 与 `cost(2)=0` 同时成立不是巧合。若数据带噪声，梯度为 0 的点仍存在，但残差不为 0，cost 大于 0。浮点下"恰好为 0"依赖数据可精确表示：这里全是 1、2、3 与整数倍，二进制没有误差。

## 高频追问

1. **梯度为 0 一定是全局最优吗？** —— 凸二次函数是；神经网络非凸，梯度为 0 可能是鞍点或局部极小，要看二阶信息
2. **把 ys 改成 `[2, 4, 7]` 呢？** —— 最优 w=31/14≈2.214，`grad(2) = 2/3·(0+0−3) = −2.0`，cost 为 `1/3 ≈ 0.3333`
3. **工程上怎么判断收敛？** —— 看 `|grad| < tol` 或连续若干轮 loss 变化小于阈值，而不是等 loss 精确为 0

## 易错点

- 认为 cost=0 说明代码写错了——数据完全线性且 w 取到真值时本就该是 0
- 把 `grad(2.0)` 算成 2.0——误把 x 的系数当结果，误差项其实全为 0
- 输出写成 `(0.0, 0.0)` 带括号——`print(a, b)` 用空格分隔，括号是选项 B 的干扰项
