## 题目

**背景**：CVR 预估只用点击样本训练，存在样本选择偏差，面试官问 ESMM 是否真的解决了。

**问**：ESMM 是怎么解决 CVR 样本选择偏差和稀疏问题的？它是否彻底解决了，还有哪些遗留问题？

## 口述答案

> 结论：思路是**不在点击样本上学 CVR，而在全曝光空间学 CTR 和 CTCVR 再相除**。两塔共享 embedding：`pCTR = f(x)`、`pCTCVR = g(x)`，则 `pCVR = pCTCVR / pCTR`。训练时在全量曝光样本上算两个 loss，CTR 用点击 label，CTCVR 用"点击且转化"label。这样 CVR 梯度来自全空间，缓解点击选择偏差，也借了 CTR 的样本量缓解稀疏。但没彻底解决：除法在 pCTR 很小时数值不稳，且依赖两塔一致性假设。

## 讲深一层

```
L = L_ctr(全曝光) + L_ctcvr(全曝光)
pCVR = pCTCVR / pCTR,  仅在 pCTR 不小时稳定
```
| 遗留问题 | 说明 |
|---|---|
| 除法放大误差 | pCTR→0 时 CVR 方差爆炸 |
| 延迟转化 | 转化晚于点击，label 未成熟 |
| 一致性假设 | 共享 embedding 不等于真一致 |
| 曝光偏差 | 只对"有曝光"无偏，仍非全库 |

改进：ESMM2 去掉除法直接约束、ESM2 加约束项、或用因果推断做纠偏。

## 高频追问

1. **为什么不能只用点击样本加权？** —— 权重只能调分布，学不到未点击样本的 CVR 信号。
2. **延迟转化怎么处理？** —— 样本回溯窗口 + 转化时间分布建模（如 DFM），未成熟样本降权或延迟回流入训。
3. **pCTR 很小怎么办？** —— 加 `max(pCTR, ε)`、在 log 空间算，或用不除法的变体直接多任务学习。

## 易错点

- 说 ESMM 直接预测 CVR，实际是 CTCVR/CTR 导出
- 认为解决了曝光偏差（只解决点击选择偏差）
- 忽略延迟转化，用 7 天窗口的 label 当终态
