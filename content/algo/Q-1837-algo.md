## 题目

**输入**：`nums = [4,3,2,7,8,2,3,1]`，值域 1..n，n 为长度。
**输出**：`[2,3]`
**要求**：O(n) 时间，O(1) 空间。

**问**：不用额外空间怎么找重复？

## 口述答案

> 两种思路都能 O(1) 空间。
> **符号标记法**：遍历到值 v 时，把 `nums[|v|-1]` 取负；如果它已经是负数，说明 v 重复。
> **原地置换法**：把 v 换到下标 v-1 上，最后不满足 `nums[i] == i+1` 的位置就是异常。
> 前者更简单，后者能同时处理「找缺失」，看题目要什么。

## 讲深一层

```cpp
vector<int> findDuplicates(vector<int>& a) {
    vector<int> res;
    for (int x : a) {
        int idx = abs(x) - 1;
        if (a[idx] < 0) res.push_back(abs(x));   // 已经标记过 → 重复
        else a[idx] = -a[idx];
    }
    return res;
}
```

| 目标 | 方法 |
|---|---|
| 找重复 | 符号标记 |
| 找缺失 | 原地置换 |
| 两者都要 | 原地置换后扫一遍 |

## 高频追问

1. **符号标记会不会破坏数据？** —— 会改变符号，若要求不改原数组就不能用。
2. **值域不是 1..n 怎么办？** —— 符号标记失效，得用 set 或排序。
3. **只有一个重复数、其他出现一次呢？** —— 可以用「求和/异或」或 Floyd 判圈（不修改数组）。

## 易错点

- ❌ 忘了取绝对值 —— 负数当下标越界
- ❌ 值域假设错了还用这方法
- ✅ 说清前提「值域 1..n」
