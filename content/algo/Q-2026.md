## 题目

**场景**：小鹏 ISP 部门手撕第一题（面经原话：两道手撕都不难）。送分题的分层点在于三种解法能不能一次给全、复杂度递进讲清楚。

**问**：数组中恰有一个数出现一次，其余每个数都出现两次，找出它——朴素解、哈希解、异或解分别怎么写、复杂度多少？

## 口述答案

> **朴素解**：每个数和别人配对计数，找到只出现一次的——时间 O(n²)、空间 O(1)，面试作为起点报一下就过。
> **哈希解**：unordered_map 计数再扫一遍出计数为 1 的——时间 O(n)、空间 O(n)，通用但费内存。
> **异或最优解**：全部数依次异或，结果就是答案——时间 O(n)、空间 O(1)。依据三条性质：**a⊕a=0（自己消自己）、a⊕0=a、交换结合律（顺序无关）**——所有出现两次的数互相抵消成 0，只剩 0⊕单身数=单身数。
>
> 报复杂度时点一句本质：**异或 = 不要账的减法，成对抵消**；哈希是「记账找没销账的」，异或是「现场抵消不用账本」。

## 讲深一层

```cpp
int singleNumber(vector<int>& a) {
    int x = 0;
    for (int v : a) x ^= v;   // 成对抵消，剩唯一数
    return x;
}
```

| 解法 | 时间 | 空间 | 一句话 |
|---|---|---|---|
| 双重循环 | O(n²) | O(1) | 起点解 |
| 哈希计数 | O(n) | O(n) | 通用解 |
| 全体异或 | O(n) | O(1) | 最优解，吃「两两成对」的性质 |

**判断技巧**：位运算题先问自己「什么运算能成对抵消」——异或消偶次、求和-2×和也行（会溢出）、排序后扫描是 O(nlogn) 的保底。**记忆锚点**：「成对出现，异或清零」。

## 高频追问

1. **如果两个数出现一次呢（LeetCode 260）？** —— 全体异或得 x⊕y（非零，必有某位为 1）；按该位是否为 1 把数组分两组，两组各自异或，分别得两数——分组标准保证两个单身狗分进不同组、成对数仍同组抵消。
2. **如果一个数出现一次、其余出现三次呢？** —— 异或不消了（奇数次）；按位计数对 3 取模，或双状态机 ones/twos 的 O(1) 空间解。
3. **异或解有前提吗？** —— 有：其余的数必须恰好出现**偶数次**；次数一变，抵消性质就破，要换位计数思路。
4. **溢出问题？** —— 异或按位运算不会溢出；对比「求和减 2×子集和」的数学解，n 大时加法会溢出，这正是异或解的额外优势。

## 易错点

- 只会哈希解就停——最优解是这题的考点本身。
- 异或初值忘了设 0——0 是异或的单位元。
- 讲不清三条性质——面试官要的是「为什么能抵消」，不是「背了个技巧」。
