## 题目

**题目**：堆排序和简单选择排序都是"选最值"，为什么堆排序快？

**问**：堆排序和简单选择排序怎么实现？

## 口述答案

> **简单选择**：每轮线性扫描找最小值放到前面，找一次 O(n)，做 n 轮 → **O(n²)**。
> **堆排序**：把数组建成大顶堆（O(n)），每次把堆顶换到末尾、堆大小减一、向下调整（O(log n)）→ 总 **O(n log n)**。
> 关键差别：选择排序每轮都重新扫，白白浪费了"前一轮已经比较过的信息"；堆用树结构把这份信息保留下来。

## 讲深一层

```c
void heapify(int a[], int n, int i) {
    int largest = i, l = 2*i+1, r = 2*i+2;
    if (l < n && a[l] > a[largest]) largest = l;
    if (r < n && a[r] > a[largest]) largest = r;
    if (largest != i) { swap(&a[i], &a[largest]); heapify(a, n, largest); }
}
void heap_sort(int a[], int n) {
    for (int i = n/2 - 1; i >= 0; --i) heapify(a, n, i);   // 建堆 O(n)
    for (int i = n-1; i > 0; --i) { swap(&a[0], &a[i]); heapify(a, i, 0); }
}
```
| 算法 | 时间 | 空间 | 稳定 |
|---|---|---|---|
| 简单选择 | O(n²) | O(1) | ❌ |
| 堆排序 | O(n log n) | O(1) | ❌ |
- 堆排序是**唯一 O(n log n) 且原地**的常用排序，但缓存不友好（跳跃访问）。
- 建堆只要 O(n)，不是 O(n log n)。

## 高频追问

1. **建堆为什么是 O(n)？** —— 大部分节点在底层，调整高度小，求和收敛到 O(n)。
2. **堆还能干什么？** —— Top-K、优先队列、定时器（最早到期在堆顶）。

## 易错点

- 以为建堆是 O(n log n)
- 说堆排序稳定
