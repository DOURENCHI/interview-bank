## 题目

```python
import numpy as np
a = np.array([[1, 2], [3, 4]])
print(a.T.tolist())
```

- **A.** [[1, 3], [2, 4]]
- **B.** [[1 2] [3 4]]
- **C.** [[3 4] [1 2]]
- **D.** [[4 3] [2 1]]

## 口述答案

答案是 **A. [[1, 3], [2, 4]]**，实际输出 `[[1, 3], [2, 4]]`。

转置把行列互换，(2,2) 方阵转置后形状不变但元素位置变了：第 0 行变成原来的第 0 列。

## 讲深一层

讲深一层：转置只交换轴的顺序并改写 strides，不搬运数据，所以 a.T 是视图，赋值会写回原数组。方阵转置后 shape 仍是 (2,2)，光看形状判断不出是否生效，要看元素：[[1,2],[3,4]] 变成 [[1,3],[2,4]]。一维数组转置等于自身；复数矩阵求共轭转置要用 .conj().T 或 .H。

## 高频追问

1. **T 是视图还是副本？** —— 视图，改它会改原数组。
2. **一维数组 .T 有变化吗？** —— 没有，仍是一维自身。
3. **怎么按自定义轴序转置？** —— `np.transpose(a, axes=(1,0,2))`。

## 易错点

- 看 shape 没变就说转置没生效：元素已换位，应为 [[1,3],[2,4]]
- 以为 .T 返回副本：是视图，后续赋值会污染原数组
- 把转置当旋转 180°：转置是沿主对角线镜像，不是旋转
