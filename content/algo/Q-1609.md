## 题目

**背景**：二叉树前中后序遍历，递归三行就写完了，但面试常要求"不用递归写一遍"。

**问**：递归和非递归的本质差别在哪？为什么中序遍历的非递归写法最别扭？

## 口述答案

> 本质差别是**谁来保存"还要回来处理"的状态**：递归用函数调用栈，非递归用你自己维护的栈，两者一一对应。
> 中序最别扭，因为它的处理时机在"左子树走完、右子树开始前"——递归里这一句自然落在两个调用之间；非递归里你得用"一路向左压栈、弹出时访问、再转向右子树"来模拟这个中间点。前序和后序的访问时机在两端，所以更直观。

## 讲深一层

```cpp
// 前序：访问在入栈时
vector<int> preorder(TreeNode* root) {
    vector<int> res; stack<TreeNode*> st;
    if (root) st.push(root);
    while (!st.empty()) {
        auto* p = st.top(); st.pop();
        res.push_back(p->val);
        if (p->right) st.push(p->right);   // 先压右，后出栈
        if (p->left)  st.push(p->left);
    }
    return res;
}

// 中序：一路向左压栈，弹出即访问
vector<int> inorder(TreeNode* root) {
    vector<int> res; stack<TreeNode*> st; auto* p = root;
    while (p || !st.empty()) {
        while (p) { st.push(p); p = p->left; }
        p = st.top(); st.pop();
        res.push_back(p->val);
        p = p->right;
    }
    return res;
}
```

| 遍历 | 访问时机 | 非递归技巧 |
|---|---|---|
| 前序 | 入栈时 | 先压右再压左 |
| 中序 | 出栈时 | 一路向左，弹出后转右 |
| 后序 | 左右都处理完 | 前序改成"根右左"再反转，或用双栈 |

**递归的真实代价**：系统栈深度 = 树高。退化成链表时 10⁵ 个节点就会栈溢出，这是"为什么必须会非递归"的实际理由。

## 高频追问

1. **后序为什么常用"反转法"？** —— 按"根-右-左"前序遍历再整体反转，得到"左-右-根"，比双栈好写。
2. **Morris 遍历是什么？** —— 用叶子节点的空右指针做线索，O(1) 空间，代价是代码复杂且会临时改树。
3. **层序遍历用栈吗？** —— 不用，用队列；要按层输出就记录每层长度。

## 易错点

- 前序遍历中"先压左再压右"，输出顺序反了
- 中序循环条件只写 `!st.empty()`，漏掉第一次 `p` 非空的情况
- 忘了树为空时的边界
