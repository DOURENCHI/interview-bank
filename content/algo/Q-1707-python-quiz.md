## 题目

```python
a = [1, 2, 3, 4, 5]
print(a[1:4], a[::2], a[::-1])
```

- **A.** [2, 3, 4] [1, 3, 5] [5, 4, 3, 2, 1]
- **B.** [1, 2, 3] [1, 3, 5] [1, 2, 3]
- **C.** [2, 3, 4] [1, 3, 5] [1, 2, 3]
- **D.** [2, 3, 4] [2, 4] [5, 4, 3, 2, 1]

## 口述答案

答案是 **A. [2, 3, 4] [1, 3, 5] [5, 4, 3, 2, 1]**，实际输出 `[2, 3, 4] [1, 3, 5] [5, 4, 3, 2, 1]`。

切片 [1:4] 左闭右开取下标 1~3；[::2] 步长 2 从头取；[::-1] 负步长即反转，得 [5,4,3,2,1]。

## 讲深一层

讲深一层：切片是 [start, stop) 左闭右开，缺省时 start=0、stop=len、step=1；step 为负则缺省反过来 start=len-1、stop=-1（哨兵，不含该位）。所以 a[::-1] 正好整体反转。越界不报错，自动夹到边界。切片返回新列表（浅复制），改结果不影响原列表，但嵌套的可变元素仍共享。

## 高频追问

1. **a[::-1] 为什么能反转？** —— 负步长从尾部往前走，缺省边界自动对调。
2. **切片会复制吗？** —— 会，浅复制一层，嵌套的可变元素仍共享。
3. **a[10:20] 会报错吗？** —— 不会，返回 []。

## 易错点

- 把 [1:4] 当成取到下标 4：左闭右开，实际是 [2,3,4]
- 把 [::2] 当成取偶数：[1,2,3,4,5][::2] 得 [1,3,5]，不是 [2,4]
- 以为 a[::-1] 改原列表：返回新列表，a 本身顺序不变
