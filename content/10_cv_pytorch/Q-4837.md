## 题目

**背景**：快手大模型算法岗一面，RL 理论题。PPO 的损失函数「逐 token 计算」和优势「通常按序列/组给出」是两个不同维度的粒度，混着答说明没推过公式。判断点在能否分清「loss 的计算位置」和「advantage 的来源粒度」这两件事。
**问**：PPO 的损失是 token 级别还是 sequence 级别的？

## 口述答案

> 答案是：损失本身是 token 级计算的，但优势信号按实现可以是 token 级或序列级，两者要分开说。
> 先看 loss：PPO 的策略损失是 ratio×advantage 在每个 token 位置上算——ratio 是当前策略和旧策略在该 token 上的概率比 π_θ(o_t|s_t)/π_old(o_t|s_t)，逐 token 有逐 token 的 ratio，clip 也是逐 token 夹的，最后对 batch 里所有 token 求和取平均（或按序列平均再平均）。所以「损失是 token 级」没有争议。
> 再看 advantage 从哪来，这才是分水岭。经典 PPO 配 critic 用 GAE：value 网络在每个 token 位置预测价值，逐步 bootstrap 出逐 token 的 advantage，这是 token 级优势。而 GRPO 这类去 critic 的方法，advantage 来自组内相对奖励——同一道题采一组回答，整条序列共享同一个 advantage（reward 减组均值除组标准差），这是 sequence 级优势广播到每个 token。所以更精确的表述是：PPO+GAE 是 token 级 loss 配 token 级优势；GRPO 是 token 级 loss 配 sequence 级优势——loss 的粒度没变，变的是优势信号的分辨率。
> 这个区分有实际后果：sequence 级优势把整条回答的好坏平摊到每个 token，答对的长回答里废步骤也被强化；token 级 GAE 能定位到具体步。代价是 GAE 需要 critic 且 value 估不准会引入偏差——GRPO 就是为了省掉 critic 的训练成本和偏差，牺牲优势的空间分辨率。另外 DAPO 的 Token-level Loss 改的是 loss 聚合方式：从「先按序列平均再平均」改成「全部 token 直接平均」，解决长回答被序列平均稀释的问题，注意这改的是归一化，不是优势粒度。

## 讲深一层

- 三个「粒度」别混：ratio 和 clip 永远是 token 级；advantage 粒度由算法决定（GAE token 级、GRPO sequence 级）；loss 的归一化方式是第三个独立设计（序列平均 vs 全局平均，DAPO 动的是这个）。
- KL 惩罚项的粒度也是 token 级的（逐 token 的 log 比例求和），所以 PPO 的完整目标是 token 级 surrogate+KL 正则，与 advantage 粒度无关。
- 为什么 sequence 级优势也能训得好：CoT 场景里 reward 是序列末尾才有的（答案对错），token 级 credit assignment 本来就只能靠 GAE 的衰减近似，GRPO 用组内对比直接跳过这个估计问题——这是「省掉 critic」的深层理由。

## 高频追问

1. GAE 的 λ 和 γ 各控制什么？——γ 是回报折扣，λ 是 bias-variance 权衡：λ=1 走蒙特卡洛（无偏高方差），λ=0 退化成 TD（低方差有偏）
2. GRPO 的 advantage 广播到每个 token，会不会强化废步骤？——会，这是已知局限，靠组内多样性和 KL 约束缓解，也是过程奖励模型（PRM）要解决的问题
3. clip 逐 token 夹和按序列夹有什么区别？——逐 token 夹是标准做法，序列级 clip 会浪费信息（一条序列里部分 token 出界就整条截断），实际都用 token 级

## 易错点

- 二选一答「token 级」不展开——正确结构是「loss token 级+优势粒度分实现讨论」，GRPO 的 sequence 级优势是本题真正的考点
- 把 DAPO 的 Token-level Loss 理解成「把 loss 改成 token 级」——它本来就是 token 级，改的是聚合归一化方式，概念错位会被追问击穿
- 分不清 advantage 和 reward 的粒度——reward 是序列末端的标量（结果奖励），advantage 是经过基线/组内归一的每 token 信用分配信号，粒度本来就不同
