## 题目

**背景**：快手大模型算法岗一面，紧跟着「介绍 DAPO」的追问。DAPO 是 DeepSeek 系 2025 年公开的 RL 训练改进，四个核心改动里「去掉 KL 惩罚+Clip-Higher」最反直觉——传统 PPO 教科书里 KL 是防崩的正则，去掉它凭什么不跑飞。考的是知不知道 KL 在 RLHF 里真正防的是什么、以及 clip 机制本身承担了什么。
**问**：DAPO 去掉 KL 并使用 Clip-Higher，训练不会跑飞吗？如何解决？

## 口述答案

> 先拆 KL 在传统 RLHF 里防什么：KL(π_θ‖π_ref) 惩罚当前策略偏离参考模型（通常是 SFT 模型），它防的是「策略滑坡」——reward model 有漏洞时，策略会往 reward 高但语言质量崩的方向漂移（reward hacking），KL 是把策略拴在 SFT 分布附近的缰绳。DAPO 的观察是：在可验证奖励（数学、代码有标准答案）场景下，reward 本身可信，不需要缰绳；而 KL 会在训练中后期抑制探索——策略被拴住，低概率但正确的推理路径涨不起来，entropy 提前坍缩，长 CoT 训不动。所以去掉 KL 的前提是「reward 可验证」，不是所有场景都敢去。
> Clip-Higher 解决的是另一个问题：重要性采样 ratio 的 clip。标准 PPO 里 ratio 被夹在 (1-ε, 1+ε)，上界下界对称。问题在概率的动态范围——一个 token 当前概率 0.001，上界 1.06 意味着它最多涨到 0.00106，想被强化也涨不动；而高概率 token 反而容易被进一步压。结果是有用的低概率 token（关键推理步）永远学不上来，策略多样性快速流失，这就是 token 熵坍缩。Clip-Higher 把上界单独放宽（ε_high 大于 ε_low），给低概率 token 留出上涨空间，保住探索。
> 那为什么不会跑飞：第一，on-policy 本身是安全带——每轮更新都用刚采样的数据、小步走，策略漂移一大 ratio 就出 clip 区间，梯度自动截断，不需要 KL 也能约束步长；第二，clip 机制仍然在，只是不对称；第三，DAPO 还有 Dynamic Sampling（全对全错的组不产生梯度，过滤掉重采，保证信号有效）和 Token-level Loss（按 token 计损失避免长回答被序列平均稀释），这套组合拳把「去 KL」的风险兜住了。工程结论：去 KL 是可验证奖励下的选择，仍是 RM 打分的场景不要照抄。

## 讲深一层

- KL 去留的判据是 reward 的可信度分级：可验证任务（数学/代码）reward 即真值，去；RM 打分的开放任务，reward 有漏洞，留——能把这条判据说出来，比背 DAPO 四件套高一档。
- Clip 上下界不对称的后果要能推：ε_high 放大后，低概率 token 的概率可以指数式上涨（ratio 上界变成 1+ε_high 对应的概率倍增空间），所以 DAPO 论文里 ε_high 是超参要调，放太宽又会矫枉过正导致策略抖动。
- 熵坍缩是 RL 训练的头号死因：表现是 reward 还在涨但回答越来越模板化、采样多样性掉光。监控 entropy 曲线是 RL 训练的基本功，Clip-Higher 本质是给 entropy 上保险。

## 高频追问

1. Dynamic Sampling 是干什么的？——组内全对或全错的样本 advantage 全为 0（GRPO 组内相对奖励），等于没梯度还占算力，过滤掉重采直到 batch 里有有效组
2. 为什么 GRPO 组内相对奖励下全对组没梯度？——advantage=(r-mean)/std，全对时每个样本 r-mean=0，没有相对差异就没有学习信号
3. KL 不用 loss 惩罚还能放在哪？——有的实现把 KL 加进 reward 而不是 loss（PLUG 式），DAPO 直接归零；两者效果不同：放 reward 里梯度会穿过 value/advantage，放 loss 里是独立正则项

## 易错点

- 答成「去 KL 是因为 KL 没用」——KL 防的是 reward hacking 下的策略滑坡，在 RM 打分场景依然必要，说出「可验证奖励才敢去」这个边界条件才是完整答案
- Clip-Higher 只答「放宽 clip」不答为什么——关键是低概率 token 在对称 clip 下涨不动的数学事实，答不出 token 熵坍缩等于没理解
- 只背四个组件名不讲组合逻辑——面试官问的是「不跑飞的机制」，要能落回 on-policy 小步更新+clip 双保险，单一组件都担不起这个责任
