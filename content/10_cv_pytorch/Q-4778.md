## 题目

**场景**：后训练阶段要构造正负样本，一条路是拿自己模型的采样结果用奖励筛选，另一条路是调商业 API 拿强模型的输出。

**问**：为什么使用 Rejection Sampling，而不是从其他商业 API 蒸馏正负样本？

## 口述答案

> 先说 Rejection Sampling 是什么：用**当前策略模型**对一个 prompt 采 N 个回答，再用奖励（验证器或 RM）**筛出最好的当正样本**、差的当负样本。相比蒸馏，核心优势四点。
> 一是**分布一致**：正负样本同模型、同 prompt，差异可以干净归因到「回答质量」；蒸馏样本混着教师模型的风格和错误分布，拿它当负样本，教的是「不像 GPT」而不是「不对」。
> 二是**上限不同**：蒸馏的天花板是教师模型，拒绝采样的数据随自己策略变强而变强，能形成 **self-improvement 闭环**。
> 三是**合规与成本**：商业 API 条款通常禁止用输出训练竞争模型，还要按 token 计费、有数据隐私问题；自己采样只花算力，数据完全自有。四是**可控**：奖励标准自己定（单测、答案比对），温度和采样条数可调。

## 讲深一层

| 维度 | Rejection Sampling | 商业 API 蒸馏 |
|---|---|---|
| 样本分布 | 自身策略分布，正负同源 | 教师分布，风格噪声混入 |
| 能力上限 | 随策略迭代持续抬升 | 被教师模型封顶 |
| 合规/成本 | 只花算力，数据自有 | 条款禁训、按量计费、隐私 |
| 可迭代性 | 策略更新后重采，数据同步升级 | 一次性静态数据集 |

```text
RS 流程: prompt → 策略模型采 N 条 → 验证器/RM 打分 →
         取 top 当正样本(SFT/RFT)，或取正负对(DPO/排序)
```

**判断技巧**：蒸馏是「抄别人的答案」，RS 是「按自己的解法刷题再对答案」——前者冷启动快但有天花板和合规坑；二者也常组合：早期蒸馏打底，后期 RS 迭代。

## 高频追问

1. **RS 和 RLHF 什么关系？** —— 都用奖励信号；RS 离线筛样本再 SFT，稳定好调，RL 在线更新策略。
2. **开放任务没有标准答案怎么筛？** —— 用训练好的 RM 打分，重要场景人工投票兜底。
3. **负样本有什么用？** —— 构造偏好对做 DPO/对比学习，或训练排序模型。

## 易错点

- 把 RS 说成「一定优于蒸馏」——蒸馏是冷启动常规手段，RS 赢在分布一致、上限和合规
- 只答「省成本」，漏掉同源分布让正负差异可归因这个核心论点
- 忽略商业 API 训练条款这个现实约束
