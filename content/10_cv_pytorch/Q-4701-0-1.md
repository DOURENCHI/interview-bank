## 题目

**题目**（华为 AI 笔试）：下列激活函数中，值域为开区间 (0,1) 的是哪一个？
A. Leaky ReLU　B. Sigmoid　C. Tanh　D. ReLU
**问**：选哪个，为什么？

## 口述答案

> 选 B，Sigmoid，公式 `1/(1+e^-x)`，输出恒在 0 和 1 之间且取不到端点——x 是 ±∞ 才逼近，所以是开区间。其他三个：Tanh 值域是 (-1,1)，也是开区间但跨零；ReLU 是 [0,+∞)，含 0 且无上界；Leaky ReLU 负半轴有负值、正半轴无界。这类题的本质是记公式加想边界：Sigmoid 和 Tanh 都饱和，ReLU 单侧抑制。Sigmoid 的两个经典问题也顺带说：饱和区梯度接近 0 造成梯度消失，输出不以 0 为中心导致下层输入偏移。

## 讲深一层

| 函数 | 值域 | 备注 |
|---|---|---|
| Sigmoid | (0,1) 开 | 梯度最大 0.25 |
| Tanh | (-1,1) 开 | 零中心 |
| ReLU | [0,∞) | 死神经元问题 |
| Leaky ReLU | (-∞,∞) | 负半轴小斜率 |

## 高频追问

1. Sigmoid 梯度最大是多少？在哪取到？——0.25，x=0
2. 为什么输出层做二分类常用 Sigmoid？——配合交叉熵，输出可当概率

## 易错点

- 把 Sigmoid 说成 [0,1] 闭区间——端点只在无穷远处逼近
- Tanh 的值域记成 (0,1)
