## 题目

模型返回的内容偶尔不是合法 JSON，只在提示词里强调"必须返回 JSON"够吗？

## 口述答案

> 不够。工程上要"**约束 + 校验 + 修复**"三层：
> 1. 约束：用 **Function Calling / JSON mode / 结构化输出**（厂商支持的语法约束解码），比提示词可靠；
> 2. 校验：解析失败要捕获异常，检查必填字段与类型；
> 3. 修复：把解析错误信息回传给模型重试（限次数），或用正则/容错解析提取 JSON 片段；仍失败则降级为纯文本+人工。

## 讲深一层

```text
约束（JSON mode/function call）→ 解析捕获异常 → 字段校验
→ 失败: 回传错误重试(≤2) → 仍失败: 容错提取/降级纯文本
```

## 高频追问

1. **为什么提示词约束不稳定？** —— 采样随机性与长上下文都会让模型"忘记"格式要求。

## 易错点

- 只靠 prompt
- 解析失败直接抛错给用户
