## 题目

**背景**：训练细节的收尾追问，面试官要听具体公式和实现要点，而不是"用了 GRPO"这种结论。

**问**：你这个 GRPO 强化学习中的 Loss 是怎么设置的？

## 口述答案

> 核心是 PPO 的 clipped surrogate，但 advantage 换成组内归一化。对每个 prompt 采样 G 个输出，各算 reward，然后 A_i 等于 r_i 减组内均值再除以标准差，用组均值当 baseline，省掉 critic。损失是负的期望，里面取 min(ρ·A, clip(ρ, 1-ε, 1+ε)·A)，ρ 是新旧策略的概率比，ε 一般 0.2，最后加 β 乘 KL 项，KL 用 k3 估计，约束不要偏离参考模型太远。两个实现要点：归一化在组内做，同一个 prompt 的 G 个样本必须一起算；如果标准差为 0，比如全对或全错，advantage 全是 0，这组没有梯度，通常过滤掉或加小量 eps。

## 讲深一层

```
A_i = (r_i - mean(r_1..r_G)) / (std(r_1..r_G) + eps)
ρ_i = π_θ(o_i|q) / π_old(o_i|q)
L = -E[ min(ρ_i·A_i, clip(ρ_i, 1-ε, 1+ε)·A_i) ] + β·KL(π_θ ‖ π_ref)

KL_k3 = exp(s - r) - (s - r) - 1,  其中 r = log π_ref, s = log π_θ
```
k3 估计的特点是无偏且恒非负，比 k1 更稳。另一个实现细节是归一化粒度：DeepSeekMath、R1 这一系用 token 级损失，除以总 token 数而不是样本数，长回答不会被过度平均；按序列平均会让长输出主导梯度。

## 高频追问

1. **为什么用 k3 估 KL** —— 无偏、非负，不会因为采样噪声出现负的 KL 把惩罚变成奖励
2. **G 太小有什么问题** —— 组内均值方差估计不准，advantage 噪声大，训练抖动
3. **全对全错怎么处理** —— advantage 全零，直接丢弃该组；也可以按难度过滤，避免浪费算力

## 易错点

- 说 GRPO 需要 value network —— 它正是用组内均值替代 critic
- 忽略 clip —— 没有 clip 就是普通策略梯度，容易一步更新过头
- 归一化按全局 batch 做 —— 必须按 prompt 分组，否则不同难度的题会互相干扰
