## 题目

**场景**：Agent 应用面试高频题。**模型在执行任务时会调用工具，但某些步骤我不想让它调用，该怎么做？**

## 口述答案

> 用**白名单控制工具面**，而不是靠提示词求它别调：
> 1. **按阶段注入工具**：每轮只把"当前阶段允许的工具"注册进 Function Call——模型看不到工具就不会调；
> 2. **状态机控制**：流程走到"只分析不动数据"的阶段，把写类工具全部摘除；
> 3. **服务端再校验**：即便模型请求了某个工具，执行前检查会话状态/权限，不合法直接拒绝并把这个结果反馈回去让它换路；
> 4. **审计**：每次工具调用落日志，出现越权调用立即告警。
> 原则：**能力边界由代码定义，模型只在边界内选择**。

## 讲深一层

```python
tools = READ_ONLY_TOOLS if stage == "analysis" else FULL_TOOLS
resp = llm(messages, tools=tools)      # 模型只能看见白名单
if req.tool not in allowed(stage):     # 服务端兜底
    return reject_and_feedback(req)
```

## 高频追问

1. **敏感操作想让人确认怎么办？** —— human-in-the-loop：拦截该类调用转人工审批，通过后带 token 继续执行。
2. **工具太多模型选不准怎么办？** —— 分组/检索式选工具，按任务动态下发 topN 工具。

## 易错点

- 只答"在 prompt 里写请不要调用"——没有任何硬约束，生产必炸
- 忘了服务端校验这层，误以为控制了模型就控制了一切
