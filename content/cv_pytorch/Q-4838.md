## 题目

**场景**：RLHF 训练管线里同时跑 Actor、Critic、RM、参考模型四个网络，Critic 的输出和「优势」的关系经常被混着说。

**问**：PPO 中的 Critic 模型是如何计算优势（Advantage）的？

## 口述答案

> 先纠正一个易混点：**Critic 本身不算优势，它算状态价值 V(s)**——对 LLM 来说就是给 prompt＋已生成序列的每个 token 位置打分，预测「从这里走到结尾的期望回报」。优势是拿这些 V 和实际奖励**用 GAE 组合出来的**。
> 两步：先算每步的 **TD 残差** `δ_t = r_t + γ·V(s_{t+1}) − V(s_t)`，衡量这一步比预期好多少；再把后续残差按 (γλ) 加权求和，得到 **GAE 优势** `A_t = Σ (γλ)^l · δ_{t+l}`。
> λ 是偏差-方差旋钮：λ=0 是纯 TD（方差小、偏差大），λ=1 退化为蒙特卡洛回报减基线（无偏、方差大），实践常取 0.9~0.95。算出的 A 进 policy loss，而 `G_t = A_t + V(s_t)` 当回归目标**反过来训练 Critic 自己**。

## 讲深一层

```text
δ_t = r_t + γ·V(s_{t+1}) − V(s_t)     # TD 残差
A_t = Σ_{l≥0} (γλ)^l · δ_{t+l}        # GAE, λ 折中多步信息
G_t = A_t + V(s_t)                     # Critic 的回归目标
LLM 场景: 奖励 r 只在句尾给(RM 分)，V 沿 token 逐位打分，GAE 在 token 维做
```

| 量 | 含义 | 用途 |
|---|---|---|
| V(s_t) | 状态价值预测 | Critic 用 value loss 学习 |
| A_t | 动作比基线好多少 | 进 policy loss |
| G_t | 实际回报估计 | 训 Critic 的回归目标 |

**判断技巧**：分工记法——Critic 管「预估」，GAE 管「结算」；λ 调「信多步还是信一步」，γ 调「信多远」。

## 高频追问

1. **为什么不直接用 reward 减均值当优势？** —— 那是高方差估计；GAE 用 V 做基线、多步折中，训练更稳。
2. **Critic 怎么初始化？** —— 常从 RM 或 policy 骨干初始化，同结构不同输出头。
3. **value loss 要注意什么？** —— 对 G_t 做 MSE 回归，常配 value clip 防单步更新过猛。

## 易错点

- 把 Critic 的输出 V 当成优势——A 才是优势，由 GAE 算出
- γ 和 λ 含义混——γ 折扣时间距离，λ 混合 TD 与 MC
- 忘了 G_t = A_t + V(s_t) 是 Critic 自己的训练目标
