## 题目

**背景**：面试官已经知道 GRPO 去掉了 critic，继续追问还差在哪。

**问**：PPO 和 GRPO 的差异，除了 critic 还有什么？

## 口述答案

> 除了去掉 critic，还有三处实质差异。
> 1. advantage 来源：PPO 用 GAE 加 value 基线；GRPO 用同一 prompt 的 G 条轨迹做组内均值/标准差归一化；
> 2. KL 处理：PPO 常把 per-token KL 塞进 reward；GRPO 用 k3 无偏估计直接加在 loss 上；
> 3. loss 归一化：PPO 按 token 平均，GRPO 常在序列级归一化再平均，长回答不会被过度放大。
> 省下的是一份与 policy 同规模的 value 网络；代价是每个 prompt 必须多采样。

## 高频追问

1. **GRPO 一定比 PPO 稳吗？** —— 不一定，组内 reward 方差大时基线噪声也大，PPO 的 value 在长序列上反而更平滑。
2. **为什么 GRPO 用序列级归一化？** —— 避免长回答因为 token 多而主导梯度，让每个 rollout 权重相近。
3. **k3 KL 估计是什么？** —— KL ≈ π_ref/π − log(π_ref/π) − 1，恒非负、方差比直接取 log 比值小。

## 易错点

- 说 GRPO"完全不需要基线"，它是用组内均值代替，不是没有基线。
- 忽略 KL 项实现差异，直接照搬 PPO 的 reward 塑形。
- 认为去掉 critic 就没有额外成本，采样数 G 的开销常常更大。
