## 题目

**场景**：序列模型从 RNN 讲到 Transformer，LSTM 的门控是承上启下的一环，要能说清它到底解决什么问题。

**问**：介绍 LSTM 的原理，门控机制是为了解决什么问题而提出的？

## 口述答案

> 先答问题：门控是为了解决 **RNN 的长期依赖问题**——普通 RNN 反向传播时梯度沿时间步连乘，要么**梯度消失**（远处信息学不到）要么梯度爆炸。LSTM 的解法是加一条**细胞状态 c** 当记忆主线，配三个门控制它的读写。
> 三个门都是 sigmoid，输出 0~1 当开关比例：**遗忘门**决定旧记忆留多少，**输入门**决定新信息写多少（配合 tanh 候选状态），**输出门**决定记忆往外暴露多少给隐状态 h。
> 关键在细胞状态是**加法更新**：`c_t = f⊙c_{t-1} + i⊙g̃`。加法通路让梯度能近乎无衰减地流回早期时刻（和残差连接同一思想），这才是缓解梯度消失的根本；三个门则让「记什么、忘什么」变成可学习的行为。

## 讲深一层

```
f_t = σ(W_f·[h_{t-1}, x_t] + b_f)      # 遗忘门
i_t = σ(W_i·[h_{t-1}, x_t] + b_i)      # 输入门
g̃_t = tanh(W_g·[h_{t-1}, x_t] + b_g)   # 候选内容
c_t = f_t ⊙ c_{t-1} + i_t ⊙ g̃_t        # 加法更新：梯度高速公路
o_t = σ(W_o·[h_{t-1}, x_t] + b_o)      # 输出门
h_t = o_t ⊙ tanh(c_t)                  # 对外输出
```

| 门 | 控制 | 记法 |
|---|---|---|
| 遗忘门 f | c_{t-1} 保留多少 | 删旧 |
| 输入门 i | 新内容写入多少 | 存新 |
| 输出门 o | c 暴露多少给 h | 取用 |

**记忆锚点**：c 是传送带（加法更新、梯度直通），三个门是传送带旁的三个阀门（忘、写、读）；GRU 把「忘＋写」合并成更新门、砍掉独立 c，是精简版。

## 高频追问

1. **门为什么用 sigmoid、内容用 tanh？** —— sigmoid 输出 (0,1) 当比例开关，tanh 输出 (−1,1) 中心化后当内容。
2. **LSTM 还有梯度爆炸吗？** —— 消失被加法通路大幅缓解，爆炸仍可能，靠梯度裁剪处理。
3. **GRU 和 LSTM 怎么选？** —— GRU 两个门、参数约为 LSTM 的 3/4，数据少求快用 GRU，多数任务差距不大。

## 易错点

- 说门控「解决梯度爆炸」——它缓解的是消失，爆炸靠 clip
- 把 c 和 h 混为一谈——c 是长期记忆，h 是对外输出
- 遗忘门和输入门的职责说反
