## 题目

**问**：CAN 和 CAN FD 有什么区别？CANopen 了解吗，PDO 和 SDO 有什么差别？

## 口述答案

> 结论：CAN FD 改了两件事——数据段可变速率、单帧数据加长到 64 字节；CANopen 上层用 PDO 传实时数据、SDO 传参数。区别：1. 仲裁段仍用原波特率保证兼容，数据段用 BRS 位切到 2~5Mbit/s；2. DLC 支持 0~64 字节（12/16/20/24/32/48/64 这些档位）；3. CRC 从 15 位加到 17/21 位并加 FDF 位。CANopen：PDO 无协议开销、事件或同步触发、无应答，适合周期过程数据；SDO 带索引+子索引、有应答、可分段，用于配置和读参数。

## 讲深一层

CAN FD 帧序：SOF → ID → FDF=1 → res → BRS → ESI → DLC → Data → CRC(17/21) → CRC delim → ACK → EOF。CANopen SDO 报文 8 字节：命令字 + index(2B) + subindex + data(4B)，快速 SDO 一次传 4 字节；PDO 默认 COB-ID 是 0x180+NodeID（TPDO1）/0x200+NodeID（RPDO1），传输类型 0 为同步非周期、1~240 为同步周期、254/255 为事件驱动。

## 高频追问

1. **CAN FD 和经典 CAN 能挂在同一条总线吗？** —— 理论上可以，但要求所有节点支持 FD 收发器，否则遇到 FD 帧会报错帧。
2. **PDO 怎么配？** —— 通过对象字典 0x1A00（TPDO 映射）和 0x1600（RPDO 映射）配置映射条目，总长度不超过 8 字节（FD 可更长）。
3. **为什么 CAN 用差分？** —— 抗共模干扰，隐性态 CAN_H/CAN_L 都是 2.5V，显性态差约 2V，两端各 120Ω 终端匹配。

## 易错点

- 认为 CAN FD 只是"数据变长"，漏了变速率和 CRC 变化
- 把 PDO 当成有确认的可靠传输
- 忽略终端电阻和共地，误判为协议问题
