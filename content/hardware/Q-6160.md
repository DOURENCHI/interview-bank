## 题目

**场景**：灵动微电子面经题。量产线每天都要 ISP 烧录——考「进 ISP 的三要素配合」和「写一半断电怎么办」的方案意识。

> 原题：MM32 通过 UART 和 Boot Pin 进入 ISP 下载时，启动模式、串口电平和复位时序怎样配合？
> 原题：ISP 更新过程中突然断电，如何设计镜像校验、恢复入口和回滚策略？

## 口述答案

> 直答：**进 ISP 靠「复位释放沿上采样 Boot 引脚」**：BOOT0（部分系列还有 BOOT1）在复位释放的瞬间被采样，决定从主 Flash、系统存储器（ROM 里的 ISP bootloader）还是 SRAM 启动。标准动作：先拉高 BOOT0 → 给复位脉冲再释放 → 芯片从 SystemMemory 启动 → 上位机按约定波特率发握手字节（0x7F），收到 ACK 才开始后续命令。三个配合点：①**时序**：Boot 电平必须在复位释放前稳定，复位脉冲满足最小脉宽——「先设 BOOT 再复位」，顺序反了采样不到；②**串口电平**：TTL 直连，注意 3.3V/5V 电平匹配、TX/RX 交叉、共地；经 USB 转换器时确认它输出的是 TTL 而不是 RS232 电平；③**协议**：每条命令「命令字节＋异或校验」配 ACK/NAK，握手失败先查波特率（bootloader 用内部固定时钟派生，与主频无关）和电平。
>
> 断电恢复：**原则是「任何时刻断电，芯片里都留一份能启动的东西」**。ROM ISP 直接写用户 Flash，写到一半断电的单分区方案有变砖风险，量产要加保护：走自家 bootloader/双分区时，新固件写**备用分区**并校验（长度→CRC→版本）全过才切启动标志，断电自然回退旧分区；单分区兜底方案则要保证「重新进 ISP 是硬件可控的」——Boot 引脚由按键/下载器电路能随时拉起，配合镜像校验（新镜像完整在位才擦旧区），把「写一半断电」变成「重进 ISP 重下」，而不是砖。恢复的底仓是 ROM：它在系统存储器里，不依赖用户 Flash 的内容。

## 讲深一层

启动模式表（复位释放沿采样）：

| Boot 引脚状态 | 启动来源 | 用途 |
|---|---|---|
| BOOT0＝0 | 主 Flash | 正常运行 |
| BOOT0＝1 | 系统存储器（ROM bootloader） | ISP 下载 |
| BOOT0＝1 且 BOOT1＝1（部分系列） | 内置 SRAM | 调试/特殊加载 |

UART ISP 流程（通用协议骨架，具体命令集以芯片手册为准）：

```text
设 BOOT0=1 → 复位脉冲 → 释放 → ROM bootloader 运行
上位机：0x7F ──────────────> 芯片
       <──── ACK            // 握手成功，波特率锁定
GET（读协议版本/支持命令）→ ERASE（擦目标区）
→ WRITE MEMORY（按页写，每包命令+异或+数据+校验）
→ READ MEMORY（回读比对）→ GO（跳转执行）
```

断电恢复设计点：

| 设计点 | 决策 | 为什么 |
|---|---|---|
| 镜像校验 | 长度＋CRC，校验不过不启动 | 写一半断电＝校验不过＝退回旧固件 |
| 恢复入口 | Boot 引脚由硬件可控（按键/下载器强拉） | 软件死了也能重新进 ISP |
| 回退 | 双分区＋启动标志（同 OTA 思路） | 新固件未确认前旧分区仍在 |
| 单分区兜底 | 新镜像完整校验在位后才擦旧区 | 把「写一半」暴露窗口压到最小 |

**记忆锚点**：「**Boot 电平等复位沿，0x7F 握手定波特率；断电不砖靠双份，单份靠硬件留 ISP 入口**」。

## 高频追问

1. **握手一直无响应/NAK，按什么顺序查？** —— 电平（TTL 与 RS232 混淆、未共地）→ TX/RX 是否交叉 → 波特率 → 复位时序（BOOT0 是否在释放沿前稳定）；前两类占绝大多数。
2. **ROM ISP 写 Flash 断电，芯片真会砖吗？** —— 只要 Boot 引脚还能进 ISP 就不算砖：ROM 在系统存储器里、不依赖用户 Flash；真「砖」是恢复入口也被破坏（选项字节/读保护配错、硬件拉不起 Boot）。
3. **读保护和 ISP 什么关系？** —— 读保护打开后 ISP 的读写被限制，解除保护通常要整片擦除；量产时读保护和升级通道要一起设计，别把后路封死。
4. **量产后没有 Boot 按键怎么保证可恢复？** —— 上电早期由代码判断应用分区 CRC，不通过则主动进 ROM ISP 或在自家 bootloader 里等升级；自家 bootloader 是最后防线，所以它自己永不升级（同 OTA bootloader 不动原则）。

## 易错点

- 先复位再拉 BOOT0——采样发生在复位释放沿，顺序反了进不了 ISP。
- 电平想当然——5V/3.3V、共地问题会让握手看起来「像接触不良」。
- 把「写一半断电」寄托在「不会那么巧」——量产必须有校验＋回退或硬件 ISP 入口。
- 读保护/选项字节配错——把唯一恢复通道也锁死，这才是真砖。
