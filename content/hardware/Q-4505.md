## 题目

**题目**：

```c
uint32_t x = 0x12345678;
// 内存里第一个字节是 0x12 还是 0x78？
```

**问**：什么是大端和小端？怎么用代码判断？

## 口述答案

> **大端**：高字节放低地址（`0x12` 在前，符合书写习惯）；**小端**：低字节放低地址（`0x78` 在前）。x86 和 ARM（默认）都是小端，网络字节序是大端。
> 判断只需两行：把 4 字节整数当 `char*` 看第一个字节，是低位就是小端。

## 讲深一层

```c
int is_little_endian(void) {
    uint32_t x = 1;
    return *(uint8_t*)&x == 1;      // 低地址存了低位 → 小端
}
// 或用 union
union { uint32_t i; uint8_t c[4]; } u = { .i = 1 };
// 小端：u.c[0] == 1
```
| 场景 | 字节序 |
|---|---|
| x86 / ARM 默认 | 小端 |
| 网络协议（TCP/IP） | 大端 |
| 部分 DSP / PowerPC | 可配 |
- 跨平台传输必须转：`htons/htonl`、`ntohs/ntohl`。
- ARM 可通过 CPSR 的 E 位切换大小端（Cortex-M 固定小端）。

## 高频追问

1. **为什么网络用大端？** —— 历史约定（RFC 1700），与具体主机无关。
2. **结构体跨平台传输要注意什么？** —— 字节序 + 对齐 + 类型宽度，三样都要固定。

## 易错点

- 直接把结构体 `memcpy` 到 socket 发送
- 用 `>>` 位移判断字节序（那是位序，不是字节序）
