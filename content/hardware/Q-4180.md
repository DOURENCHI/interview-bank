## 题目

**题目**：按键接 PA0，配置了 EXTI0 中断，也开了 NVIC。想搞清楚这两者在链路里各干什么。

**问**：EXTI 和 NVIC 在中断链路里各负责什么？只配一个会怎样？

## 口述答案

> **EXTI 负责"检测边沿"**：GPIO 电平变化 → 边沿检测电路 → 置挂起位（PR）。**NVIC 负责"排队和仲裁"**：根据优先级决定什么时候把中断送给 CPU。
> 所以只配 EXTI 不开 NVIC，挂起位会置起来但 CPU 永远不响应；只开 NVIC 不配 EXTI，永远没有触发源。

## 讲深一层

```
GPIO 电平变化
   ↓
EXTI 边沿检测（上升/下降/双边沿）
   ↓ 置 PR 挂起位
NVIC 优先级仲裁
   ↓
CPU 取向量 → 执行 ISR
   ↓
软件清 PR
```

| 模块 | 职责 | 配置项 |
|---|---|---|
| EXTI | 检测边沿、置挂起位 | 触发方式、屏蔽位 |
| NVIC | 优先级、使能、挂起 | 抢占/子优先级、IRQ 使能 |
| SYSCFG/AFIO | 把 GPIO 线映射到 EXTI | 端口选择（PA0/PB0…） |

```c
// 三步都要做
__HAL_RCC_AFIO_CLK_ENABLE();                       // F1 必须
GPIO_InitStruct.Mode = GPIO_MODE_IT_FALLING;       // EXTI：下降沿
HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
HAL_NVIC_SetPriority(EXTI0_IRQn, 2, 0);            // NVIC：优先级
HAL_NVIC_EnableIRQ(EXTI0_IRQn);
```

**F1 的坑**：`EXTI0` 只能映射到某一个端口的第 0 脚（PA0 或 PB0 或 PC0…），通过 AFIO 的 `EXTICR` 选择——**不能同时有 PA0 和 PB0 两个 EXTI0**。

## 高频追问

1. **为什么 F1 要开 AFIO 时钟？** —— EXTI 的端口映射寄存器在 AFIO 里。
2. **多个引脚能共用一个 EXTI 吗？** —— 同一编号的只能选一个端口。
3. **双边沿触发怎么配？** —— `GPIO_MODE_IT_RISING_FALLING`。

## 易错点

- 只配 EXTI 不开 NVIC（无响应）
- F1 忘了开 AFIO 时钟（映射不生效）
- 同时想用 PA0 和 PB0 做 EXTI0
