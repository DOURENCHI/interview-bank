## 题目

一帧图像从 sensor 出来到处理，中间经过哪些环节？

## 口述答案

> 一条链路：**光 → sensor 感光（Bayer 原始数据）→ MIPI/DVP 接口 → ISP（黑电平、去马赛克、白平衡、降噪、Gamma、RGB/YUV 转换）→ 帧缓冲（DDR/内部 RAM）→ 应用处理（检测/编码/显示）**。
> 关键环节与瓶颈：接口带宽（MIPI lane 数）、ISP 算力、内存带宽（一帧 1080p YUV420 约 3MB，30fps 就是 90MB/s）、CPU 拷贝次数。工程上尽量让 **DMA/硬件流水线**搬运，CPU 只做控制。

## 讲深一层

```text
Sensor → MIPI CSI → ISP → DMA → FrameBuffer → (NPU/CPU) → 输出
```

## 高频追问

1. **Bayer 为什么要去马赛克？** —— 每个像素只有一个颜色分量，需要邻域插值恢复 RGB。
2. **带宽不够怎么优化？** —— 降分辨率/帧率、用 YUV420 代替 RGB888、压缩（MJPEG/H.264）、增加 DMA 通道。

## 易错点

- 把 ISP 当成软件库，忽略它是硬件流水线
- 忽略内存带宽，只算 CPU 算力
