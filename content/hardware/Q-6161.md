## 题目

**场景**：灵动微电子面经题。PWM＋输入捕获是 MCU 岗的「计算基础题」——考账算不算得清、误差懂不懂在哪。

> 原题：用定时器输出 PWM 并捕获输入频率时，怎样核对计数频率、分频和溢出处理？

## 口述答案

> 直答：**先把定时器的「计数节拍」算清，PWM 和捕获共用这一套账**：计数时钟 f_cnt ＝ f_clk ÷ (PSC＋1)（PSC 预分频，决定节拍多细）；PWM 周期是 (ARR＋1) 个节拍，所以 **PWM 频率 ＝ f_clk ÷ [(PSC＋1)×(ARR＋1)]**，**占空比 ＝ CCR ÷ (ARR＋1)**（边沿对齐、向上计数）。溢出/更新事件发生在计数到 ARR 回零时，更新中断可作节拍级时基。核算从目标反推：先选 PSC 把 f_cnt 落到「够细又不至于 ARR 爆表」的区间，再算 ARR——16 位定时器 ARR 上限 65535，ARR 算出来太大就是 PSC 该加大。
>
> 输入捕获测频两条路：①**测周期法（低频适用）**：捕获相邻两个上升沿，周期＝捕获差值×节拍，频率＝1/T；误差是 ±1 个节拍，信号越低频相对误差越小。②**测频法（高频适用）**：固定闸门时间 T_g 内数边沿 N 个，f＝N/T_g；高频信号 N 大，±1 个脉冲的量化误差被摊薄。**高频用测频、低频用测周期，选反了误差差几个量级**。溢出处理是捕获的隐形坑：两个沿之间计数器可能翻转多次，必须配合更新中断累计溢出次数（或用无符号回绕减法＋溢出补偿），否则测出的周期直接差一个 ARR 量级。

## 讲深一层

公式账（先节拍、再周期、最后占空比）：

```text
计数频率   f_cnt = f_clk / (PSC + 1)                ← PSC 先分频，决定节拍
PWM 频率   f_pwm = f_clk / [(PSC + 1) × (ARR + 1)]
占空比     D     = CCR / (ARR + 1)                  ← 边沿对齐向上计数
测周期法   T     = ΔCCRx × (PSC + 1) / f_clk        ← 相邻两上升沿捕获差
测频法     f     = N / T_gate                        ← 闸门时间内数边沿个数
```

例：f_clk＝72MHz 时想要 1kHz、占空比 37.5%——取 PSC＝71 得 1MHz 节拍，ARR＝999 得 1kHz，CCR＝375 得 37.5%；核对 ARR＝999 < 65536 成立（数字按目标芯片时钟同法换算）。

两种测频法对比：

| 方法 | 原理 | 误差来源 | 适用频段 | 相对误差 |
|---|---|---|---|---|
| 测周期法（输入捕获） | 量相邻两沿的时间差 | ±1 计数节拍；溢出漏记 | 低频 | 节拍/周期，低频时很小 |
| 测频法（计数） | 固定闸门内数脉冲 | ±1 个脉冲 | 高频 | 1/N，N 越大越小 |

**记忆锚点**：「**频率看 (PSC＋1)(ARR＋1)，占空比看 CCR/(ARR＋1)；低频测周期，高频测次数**」。

## 高频追问

1. **捕获值差可能是「负数」（翻转）怎么办？** —— 用无符号减法让硬件回绕自然处理（差值＝(B−A) mod (ARR＋1)），同时用更新中断累计溢出次数交叉核对；中断里先读捕获寄存器再清标志，顺序反了会丢沿。
2. **溢出中断和捕获中断谁先处理？** —— 同优先级按中断编号顺序；稳妥做法是在捕获 ISR 里同时检查溢出标志，把溢出计数和捕获差值在同一份现场里合并，避免「先清溢出再读捕获」漏掉一次翻转。
3. **测占空比怎么抓？** —— PWM 输入模式（从模式复位）：同一引脚让上升沿复位计数、下降沿捕获一次，两个捕获值分别给出高电平时间与整周期，直接相除得占空比，不用软件凑两个独立沿。
4. **想要更高分辨率但 ARR 到顶了怎么办？** —— 加大 PSC 是反方向（节拍变粗）；正解是提高定时器时钟（换时钟源/倍频）或换 32 位定时器，也可以用「测频法＋长闸门」换分辨率。

## 易错点

- PSC/ARR 忘了＋1——频率整体差一拍，采样周期、波特率全跟着歪。
- 16 位定时器硬要 ARR＝10 万——寄存器截断，实际频率完全不对；该加大的是 PSC。
- 低频信号用测频法——闸门内只捕到 1 个脉冲，±1 误差就是 ±100%。
- 捕获测频不算溢出——计数器翻转一次，周期就差一个 ARR。
