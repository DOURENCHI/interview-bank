## 题目

**题目**：要产生 1 kHz、50% 占空比的 PWM，TIM3 挂在 72 MHz。

**问**：时基单元怎么算定时时间？PWM 频率和占空比怎么定？

## 口述答案

> 两个公式：
> - **定时时间** = `(PSC+1) × (ARR+1) / f_TIM`
> - **PWM 频率** = `f_TIM / ((PSC+1) × (ARR+1))`，**占空比** = `CCR / (ARR+1)`
> 1 kHz @72 MHz：取 `PSC+1 = 72`（→1 MHz 计数），`ARR+1 = 1000`（→1 kHz），`CCR = 500` 得 50%。

## 讲深一层

```c
htim3.Instance = TIM3;
htim3.Init.Prescaler = 72 - 1;         // 72 MHz / 72 = 1 MHz
htim3.Init.Period = 1000 - 1;          // 1 MHz / 1000 = 1 kHz
htim3.Init.CounterMode = TIM_COUNTERMODE_UP;

// 通道 1 PWM
sConfig.OCMode = TIM_OCMODE_PWM1;
sConfig.Pulse = 500;                   // 50%
HAL_TIM_PWM_ConfigChannel(&htim3, &sConfig, TIM_CHANNEL_1);
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);
```

| 参数 | 作用 | 影响 |
|---|---|---|
| `PSC` | 预分频，降计数频率 | 决定计数精度和时间范围 |
| `ARR` | 自动重装值，决定周期 | 与 PSC 共同决定频率 |
| `CCR` | 比较值 | 决定占空比 |

**计算流程**：先定计数频率（兼顾精度和 ARR 范围，16 位最多 65535），再定 ARR 得到目标频率，最后 CCR 定占空比。

**`PSC+1` 和 `ARR+1` 里的 +1 是最容易漏的**：寄存器值 0 表示"不分频/计 1 个数"，所以实际分频是 `PSC+1`。

**占空比精度**：`1/(ARR+1)`。ARR=999 时精度 0.1%，够用；要更细就提高计数频率（减小 PSC）。

## 高频追问

1. **为什么先定 PSC 再定 ARR？** —— PSC 决定计数频率，ARR 只能在 16 位范围内取值。
2. **能动态改占空比吗？** —— 能，改 `CCR` 立即生效（下一个周期）。
3. **能动态改频率吗？** —— 改 `ARR` 要注意是否在计数中，一般先停再改。

## 易错点

- 忘了 `+1`
- ARR 超过 65535（16 位定时器）
- 改 CCR 时没考虑预装载
