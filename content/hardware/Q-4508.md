## 题目

**题目**：汇川面试真题：从上电复位到 `main()` 第一行，中间发生了什么？

**问**：单片机从上电复位到执行 main 之前做了什么？

## 口述答案

> 五步：**取复位向量**（从向量表第一个字读出初始 MSP，第二个字读出 Reset_Handler 地址）→ **初始化栈指针** → **执行启动代码**（`SystemInit`：配时钟/Flash 等待周期）→ **搬运 `.data` 段、清零 `.bss` 段** → **调用 `__libc_init_array`**（C++ 全局对象构造）→ 进入 `main`。
> `.data` 和 `.bss` 的初始化是启动代码的核心工作——否则全局变量都是垃圾值。

## 讲深一层

| 步骤 | 动作 |
|---|---|
| 1 | 从 0x00000000 取初始 MSP |
| 2 | 从 0x00000004 取 Reset_Handler |
| 3 | SystemInit（时钟、Flash latency） |
| 4 | .data 从 Flash 复制到 RAM；.bss 清零 |
| 5 | 构造全局/静态 C++ 对象 |
| 6 | 调用 main |
- `.data` 的初值存在 Flash 里，运行时要复制到 RAM（RAM 掉电不保存）。
- C++ 的全局对象构造顺序在同一编译单元内按声明顺序，跨单元不确定。
- 看启动文件（`startup_stm32f103xb.s`）能直接看到这段汇编。

## 高频追问

1. **为什么 .bss 要清零？** —— C 标准要求未初始化全局变量为 0，而 RAM 上电内容是随机的。
2. **不跑启动代码直接跳 main 会怎样？** —— 全局变量全是垃圾，`malloc` 也可能挂。

## 易错点

- 只说"跳到 main"，漏掉 .data/.bss 初始化
- 忽略 C++ 全局对象构造
