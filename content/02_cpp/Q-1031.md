## 题目

MCP 工具的参数、权限和错误怎么约束？

## 口述答案

> 三层约束：
> 1. **参数**：用 JSON Schema 定义类型/枚举/必填/范围，服务端入口再校验一次（不信任模型输出）；
> 2. **权限**：工具级白名单 + 会话级授权（敏感工具需用户确认/令牌），按最小权限授予，写操作单独标记；
> 3. **错误**：统一错误码 + 可读信息返回给模型（让它能改参数重试），区分"可重试（超时/限流）"与"不可重试（参数错/无权限）"，并设最大重试次数。

## 讲深一层

```text
模型输出 → JSON Schema 校验（类型/枚举/必填）
         → 服务端业务校验（权限/资源存在）
         → 执行 → 统一错误码（retryable 标记）
```

## 高频追问

1. **模型编造参数怎么办？** —— schema 校验直接拒绝并返回字段错误，让它重填；枚举限定可选项。

## 易错点

- 只写 schema 不做服务端校验
- 所有错误都让模型重试，导致死循环
