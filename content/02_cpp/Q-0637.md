## 题目

**场景**：面试官画了一张内存布局图，问"全局变量、局部变量、`new` 出来的、字符串字面量各在哪个区"。

**问**：C++ 程序的内存分哪几个区？`new` 和 `malloc` 的区别是什么？

## 口述答案

> 五个区：**栈**（局部变量、函数调用）、**堆**（`new` / `malloc`）、**全局/静态区**（初始化和未初始化的全局、静态变量）、**常量区**（字符串字面量、`const` 全局）、**代码区**（指令）。
> `new` 和 `malloc` 的区别：`new` 会**调用构造函数**、返回正确类型的指针、失败抛异常；`malloc` 只分配原始字节、返回 `void*`、失败返回 `nullptr`。

## 讲深一层

```
高地址
┌─────────────┐
│    栈 stack  │ ← 局部变量，向下增长
├─────────────┤
│             │
├─────────────┤
│   堆 heap    │ ← new/malloc，向上增长
├─────────────┤
│  BSS（未初始化全局/静态）│
├─────────────┤
│  Data（已初始化全局/静态）│
├─────────────┤
│  常量区（字符串字面量）   │
├─────────────┤
│  代码区 .text │
└─────────────┘
低地址
```

| 维度 | `new` | `malloc` |
|---|---|---|
| 构造/析构 | 调用 | 不调用 |
| 返回类型 | `T*` | `void*`（需转换） |
| 大小 | 自动算 | 手动 `sizeof` |
| 失败 | 抛 `bad_alloc` | 返回 `nullptr` |
| 配对 | `delete` / `delete[]` | `free` |
| 重载 | 可重载 `operator new` | 不可 |

**混用的后果**：`new` 配 `free` 不会调用析构函数（资源泄漏）；`malloc` 配 `delete` 是未定义行为。

**一个常见误解**：`new[]` 必须配 `delete[]`，因为数组版本要多记一个元素个数（用于逐个析构）。

## 高频追问

1. **栈和堆哪个快？** —— 栈快得多（只是移动栈指针），堆要走分配器、可能系统调用。
2. **栈溢出是什么？** —— 递归太深或局部数组太大，超出栈大小（Linux 默认 8 MB）。
3. **字符串字面量能改吗？** —— 不能，在常量区，修改是未定义行为（可能段错误）。

## 易错点

- `new` 配 `free`、`malloc` 配 `delete`
- 以为局部数组在堆上
- 修改字符串字面量（`char* s = "abc"; s[0]='x';`）
