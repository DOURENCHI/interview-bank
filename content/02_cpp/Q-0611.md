## 题目

**场景**：`std::map<MyKey, int> m;` 里放了自定义类型，编译报错一大串，核心是"no match for operator<"。

**问**：为什么 `map` 的 key 必须可比较？自定义类型要做哪些事？有什么坑？

## 口述答案

> 因为 `map` 内部是**红黑树**，靠比较决定元素位置，所以 key 必须能排出严格弱序。自定义类型要么提供 `operator<`，要么给 `map` 传一个比较器。
> 要注意两点：**比较必须是严格弱序**（不能出现 `a<b && b<a`），**浮点 key 要小心**（NaN 会破坏排序）。

## 讲深一层

```cpp
struct Key { int id; std::string name; };

// 方式一：成员 operator<
bool operator<(const Key &a, const Key &b) {
    if (a.id != b.id) return a.id < b.id;
    return a.name < b.name;              // 所有字段都要参与，否则"相等"的元素会被当成同一个
}

// 方式二：外部比较器（推荐，不侵入类型）
struct Cmp {
    bool operator()(const Key &a, const Key &b) const { return a.id < b.id; }
};
std::map<Key, int, Cmp> m;
```

| 需求 | 容器 | key 要求 |
|---|---|---|
| 有序遍历 | `map` / `set` | 严格弱序（`operator<`） |
| 只查不排序 | `unordered_map` | 可哈希 + 可判等 |
| 范围查询 | `map` | 必须有序 |

**最容易踩的坑**：`operator<` 只比较了部分字段。比如只比 `id` 不比 `name`，那么两个 `id` 相同但 `name` 不同的 key 会被 `map` 认为是**同一个 key**，后插入的覆盖前面的——静默丢数据。

## 高频追问

1. **严格弱序是什么？** —— 不可自反（`a<a` 为假）、传递、且任意两个元素可比出先后；违反它会导致未定义行为。
2. **能重载 `operator<` 但只想比一个字段吗？** —— 能，但要意识到"其余字段被忽略"，`map` 里会出现覆盖。
3. **`unordered_map` 的自定义 key 怎么做？** —— 提供 `std::hash` 特化和 `operator==`。

## 易错点

- 只比较部分字段，导致 key 冲突、数据被覆盖
- 用浮点数当 key，NaN 破坏排序
- `operator<` 写成非 const 成员函数，`map` 编不过
