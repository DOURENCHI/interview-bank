## 题目

**题目**：函数里要修改调用方的指针本身（不是它指向的内容），参数该怎么写？

**问**：二级指针有什么用？它和一级指针、引用怎么选？

## 口述答案

> 二级指针指向"指针变量"，所以能**修改指针本身**——这是它不可替代的地方（一级指针只能改指向的内容）。
> 三个用途：**在函数内改变调用方的指针**、**指针数组/二维数组传参**、**接收 `char** argv` 这类接口**。C++ 里能用 `T*&`（指针的引用）代替，更安全易读。

## 讲深一层

```c
void alloc(char** out, size_t n) { *out = malloc(n); }   // 改调用方的指针
void alloc2(char*& out, size_t n) { out = malloc(n); }   // C++ 更清晰
```
| 写法 | 能改指针本身 | 能改内容 | 可空 |
|---|---|---|---|
| `T*` | ❌ | ✅ | ✅ |
| `T**` | ✅ | ✅ | ✅ |
| `T*&` | ✅ | ✅ | ✅（引用本身不可空） |
- 传二级指针时记得判空（`if (!out) return;`）。
- 二维数组 `int a[3][4]` 传参是 `int (*)[4]`，不是 `int**`。

## 高频追问

1. **`int**` 能接 `int[3][4]` 吗？** —— 不能，类型不同，这是经典错误。
2. **什么时候必须用二级指针？** —— 接口签名已经定了（如 C 库的 `xxx_create(T** out)`）。

## 易错点

- 用 `int**` 接收二维数组
- 二级指针不判空就解引用
