## 题目

**题目**：`struct A { int x; };` 和 `class B { int x; };` 之后，`A a; a.x=1;` 能过，`B b; b.x=1;` 不能。

**问**：struct 和 class 在 C++ 里有什么区别？

## 口述答案

> 只有两个默认值不同：**默认访问权限**（struct 是 public，class 是 private）和**默认继承方式**（struct 是 public，class 是 private）。其余完全一样——都能有成员函数、构造析构、继承、模板。
> C++ 里保留 `struct` 主要是为了**兼容 C** 和**表达习惯**：纯数据聚合用 struct，有不变量的封装用 class。

## 讲深一层

```cpp
struct S { int x; };            // x 是 public
class  C { int x; };            // x 是 private
struct D : S {};                // public 继承
class  E : S {};                // private 继承
```
- 空 struct 的 `sizeof` 是 1（保证每个对象有唯一地址）。
- `struct` 也能有虚函数和 vptr，一样参与多态。
- 代码规范上通常：POD/数据载体用 struct，行为封装用 class。

## 高频追问

1. **C 的 struct 能有成员函数吗？** —— C 不行；C++ 的 struct 可以。
2. **`struct` 能当模板参数吗？** —— 能，和 class 关键字在模板参数列表里等价。

## 易错点

- 说"struct 没有成员函数"
- 忘了默认继承方式也不同
