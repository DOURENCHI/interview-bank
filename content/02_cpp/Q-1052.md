## 题目

#define 宏和 const 的区别，C++ 中 const 还有哪些用法？

## 口述答案

> `#define` 是预处理文本替换：无类型、无作用域、不参与调试符号，容易出括号/副作用问题；`const` 是编译器处理的真变量：有类型、有作用域、可调试，能取地址。
> C++ 中 const 还用于：const 引用传参（避免拷贝）、const 成员函数（不修改对象）、const 指针/指向 const 的指针、`constexpr`（编译期常量，替代宏做常量表达式）、const 迭代器。

## 讲深一层

| | #define | const/constexpr |
|---|---|---|
| 处理阶段 | 预处理 | 编译期 |
| 类型 | 无 | 有 |
| 作用域 | 无（全局替换） | 有 |
| 调试 | 看不到符号 | 可调试 |

## 高频追问

1. **什么时候还必须用宏？** —— 条件编译、头文件保护、字符串化/拼接等预处理能力；常量一律用 constexpr。

## 易错点

- 说宏"更快"（现代编译器常量折叠后无差别）
- 忽略宏没有作用域
