## 题目

**题目**：`printf("%d %s", 1, "hi")` 能处理任意多个参数，而普通函数不行。

**问**：printf 为什么能打印个数不定的参数？

## 口述答案

> 靠**可变参数**：函数声明里用 `...`，函数体内用 `va_list` 系列宏遍历——`va_start` 定位到第一个可变参数，`va_arg` 按类型取下一个，`va_end` 收尾。
> 但**参数个数和类型完全靠格式串推断**，编译器不检查，所以格式写错就是 UB——这就是 `printf` 不安全的原因。

## 讲深一层

```c
int my_sum(int n, ...) {
    va_list ap; va_start(ap, n);
    int s = 0;
    for (int i = 0; i < n; ++i) s += va_arg(ap, int);
    va_end(ap);
    return s;
}
```
- 必须先有一个"固定参数"（如 `n` 或格式串），`va_start` 要靠它定位。
- 默认实参提升：`char`/`short` 提升为 int，`float` 提升为 double。
- 类型不匹配（`%d` 传 double）不会报错，只会读错栈——这也是格式化字符串漏洞的根源。
- C++ 的替代：`std::format`（C++20，类型安全）、`iostream`（无格式串）、可变参数模板。

## 高频追问

1. **能对 `...` 做类型检查吗？** —— 不能；GCC 的 `__attribute__((format))` 能在编译期检查格式串。
2. **`va_list` 能重复遍历吗？** —— 不能直接重来，要 `va_copy` 复制一份。

## 易错点

- 格式串和实参不匹配（`%s` 传 int）
- 忘记 `va_end`
