## 题目

**题目**：面试官问"你平时用 C++14 的哪些特性"，答不出具体的会很尴尬。

**问**：C++14 有哪些常用特性？

## 口述答案

> 四个最常用：**泛型 lambda**（参数写 `auto`）、**函数返回值类型推导**（`auto f()`）、**`std::make_unique`**、**变量模板**。
> 还有容易被忽略但实用的：二进制字面量 `0b1010`、数字分隔符 `1'000'000`、放宽的 `constexpr`（允许循环和局部变量）。

## 讲深一层

```cpp
auto add = [](auto a, auto b) { return a + b; };   // 泛型 lambda
auto sq(int x) { return x * x; }                   // 返回类型推导
auto p = std::make_unique<int>(1);                 // make_unique
template <typename T> constexpr T pi = T(3.14159); // 变量模板
int big = 1'000'000;   int bin = 0b1010;
```
- C++14 是"补 C++11 的坑"的版本，特性不多但都用得上。
- 面试若追问"和 C++11 的区别"，答"泛型 lambda + make_unique + 返回类型推导"三点足够。

## 高频追问

1. **泛型 lambda 怎么实现的？** —— 编译器生成带模板 `operator()` 的闭包类型。
2. **`make_unique` 为什么 C++11 没有？** —— 被遗漏了，C++14 补上（C++11 只能自己写）。

## 易错点

- 把 C++17 的特性说成 C++14（`if constexpr`、结构化绑定）
- 只答"没什么特别的"
