## 题目

**场景**：`template<typename T, int N> class Array;` 里的 `int N` 是什么？和普通参数有什么区别？

**问**：非类型模板参数有什么用？它能是哪些类型？为什么它能让 `std::array` 零开销？

## 口述答案

> 非类型模板参数让**值成为类型的一部分**：`Array<int, 3>` 和 `Array<int, 4>` 是**不同的类型**，大小在编译期就确定。
> 所以 `std::array<int,3>` 内部就是一个 `int[3]` 成员，没有额外指针、没有堆分配，完全零开销。而 `vector` 的大小是运行时的，必须存指针和容量。
> **允许的类型**：整型、枚举、指针、引用、`nullptr_t`，C++20 起还允许浮点和部分类类型。

## 讲深一层

```cpp
template <typename T, std::size_t N>
struct Array {
    T data[N];                       // 大小编译期确定
    constexpr std::size_t size() const { return N; }
    T& operator[](std::size_t i) { return data[i]; }
};

Array<int, 3> a;    // sizeof(a) == 12，没有额外开销
Array<int, 4> b;    // 和 a 是不同类型
```

| 对比 | `std::array<int,3>` | `std::vector<int>` |
|---|---|---|
| 大小 | 12 字节（栈） | 24 字节（3 个指针）+ 堆 |
| 分配 | 无 | 有 |
| 大小已知 | 编译期 | 运行时 |
| 可调整 | 否 | 是 |

**实际用途**：固定大小缓冲区、矩阵维度（`Matrix<double, 3, 3>`）、编译期循环展开、`std::get<N>` 访问元组。

## 高频追问

1. **非类型参数能是 `std::string` 吗？** —— C++20 起有限支持（需要结构类型），之前不行。
2. **能让数组维度自动推导吗？** —— 能，C++17 的 `template<auto N>` 或 `std::array` 的推导指引。
3. **模板参数能默认值吗？** —— 能，`template<typename T, int N = 3>`。

## 易错点

- 以为 `std::array` 和 `vector` 一样有堆分配
- 用非类型参数存大对象（编译期展开，代码膨胀）
- 传运行时变量当非类型参数（必须是常量表达式）
