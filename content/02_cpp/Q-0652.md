## 题目

**场景**：`class Shape { virtual double area() = 0; };` 之后 `Shape s;` 编不过。

**问**：抽象类为什么不能实例化？用基类指针能调用到子类实现吗？抽象类能有构造函数吗？

## 口述答案

> 因为抽象类有**纯虚函数没有实现**，实例化出来的对象调用它就没有代码可执行。编译器在编译期就禁止。
> 用基类指针可以调用到子类实现——这正是多态的用途：`Shape* p = new Circle; p->area();` 走 `Circle::area`。抽象类**可以有构造函数**，供派生类构造基类部分时调用（比如初始化共有成员）。

## 讲深一层

```cpp
class Shape {
public:
    explicit Shape(std::string name) : name_(std::move(name)) {}
    virtual double area() const = 0;      // 纯虚
    virtual ~Shape() = default;
    const std::string& name() const { return name_; }
private:
    std::string name_;
};

std::vector<std::unique_ptr<Shape>> shapes;
shapes.push_back(std::make_unique<Circle>(1.0));
for (auto& s : shapes) s->area();          // 统一调用，各自实现
```

| 问题 | 答案 |
|---|---|
| 能实例化吗 | 不能 |
| 能有构造函数吗 | 能（供派生类用） |
| 能有数据成员吗 | 能 |
| 能有非虚函数吗 | 能 |
| 纯虚函数能有实现吗 | 能（派生类可显式调用） |

**纯虚析构的特殊性**：必须是纯虚且**必须有定义**，否则派生类析构链接失败。

**接口类（interface）的写法**：只有纯虚函数 + 虚析构，没有数据成员，用来表达"能力契约"。

## 高频追问

1. **抽象类指针能 delete 吗？** —— 能，前提是虚析构；否则只析构基类部分。
2. **纯虚函数有实现有什么意义？** —— 提供默认行为，派生类可选择调用 `Base::f()`。
3. **抽象类能做函数参数吗？** —— 不能按值传（无法拷贝），只能传引用或指针。

## 易错点

- 以为抽象类不能有构造函数和数据成员
- 纯虚析构不写定义，链接失败
- 按值传抽象类参数
