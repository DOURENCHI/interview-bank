## 题目

**场景**：VS Code 里每次改完代码都要手动敲 `g++ main.cpp -o main && ./main`，想按 `Ctrl+Shift+B` 一键完成。

**问**：`tasks.json` 怎么配一个「编译 + 运行」任务？

## 口述答案

> 配一个 `type: shell` 的任务，`command` 写编译命令，`args` 传参数；要"编译完自动运行"可以用 `&&` 把两条命令串在 `command` 里，或者配两个任务用 `dependsOn`。
> 关键是设 `group.kind: build` 且 `isDefault: true`，这样 `Ctrl+Shift+B` 直接跑它。

## 讲深一层

```json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "build & run",
      "type": "shell",
      "command": "g++ -std=c++17 -O2 -g ${file} -o ${fileDirname}/a.out && ${fileDirname}/a.out",
      "group": { "kind": "build", "isDefault": true },
      "problemMatcher": ["$gcc"],
      "presentation": { "reveal": "always", "panel": "shared" }
    }
  ]
}
```

| 字段 | 作用 |
|---|---|
| `label` | 任务名，`dependsOn` 引用它 |
| `command` + `args` | 实际执行什么；用 `args` 更安全（不用处理引号） |
| `group` | `build` 组 + `isDefault` 才能被快捷键触发 |
| `problemMatcher` | 把编译错误解析成可点击的列表 |
| `${file}` | 当前文件；`${fileDirname}` 当前目录 |

**用 `args` 而不是拼在 `command` 里**：路径含空格时，拼字符串会断，`args` 数组不会。

## 高频追问

1. **`${file}` 和 `${workspaceFolder}` 区别？** —— 前者是当前打开的文件，后者是工作区根目录。
2. **怎么调试而不是只运行？** —— 那是 `launch.json` 的事，`tasks.json` 只管构建和运行。
3. **`problemMatcher` 有什么用？** —— 把 `error: ...` 解析成问题面板条目，双击跳转到出错行。

## 易错点

- 路径含空格时把参数拼成一个字符串
- 忘了 `group.isDefault`，快捷键找不到任务
- 用 `cwd` 却没意识到相对路径基于它
