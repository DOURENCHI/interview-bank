## 题目

**场景**：自定义比较函数写成 `return a >= b;`，`std::sort` 在某些输入下崩溃或死循环。

**问**：为什么比较函数必须满足「严格弱序」？违反会导致什么？

## 口述答案

> 严格弱序要求：**不可自反**（`cmp(a,a)` 必须为假）、**传递**、**任意两元素可比出先后**。
> `>=` 违反了不可自反（`a>=a` 为真），排序算法会认为"a 应该排在 a 前面"，在快排的分区逻辑里可能让指针不前进，导致越界或死循环。

## 讲深一层

```cpp
// ❌ 违反严格弱序
std::sort(v.begin(), v.end(), [](int a, int b){ return a >= b; });

// ✅ 正确
std::sort(v.begin(), v.end(), [](int a, int b){ return a > b; });
std::sort(v.begin(), v.end(), std::greater<>{});
```

| 要求 | 含义 | 违反的例子 |
|---|---|---|
| 不可自反 | `cmp(a,a) == false` | `a <= b`、`a >= b` |
| 传递 | `cmp(a,b) && cmp(b,c) → cmp(a,c)` | 某些自定义几何比较 |
| 反对称 | `cmp(a,b) → !cmp(b,a)` | 浮点 NaN 参与比较 |
| 等价传递 | `!cmp(a,b) && !cmp(b,a)` 是等价关系 | 只比部分字段可能还好 |

**浮点数的坑**：`NaN` 和任何数比较都返回 false，破坏传递性。用浮点当 key 排序时要么先过滤 NaN，要么用容差比较 + 显式处理等价。

**为什么标准库这么严格**：排序算法（内省排序、归并）依赖这些性质来保证 O(n log n) 和正确性，违反就是未定义行为，`_GLIBCXX_DEBUG` 下会直接断言。

## 高频追问

1. **`a <= b` 为什么不行？** —— `a<=a` 为真，违反不可自反。
2. **怎么调试这类问题？** —— 开 `-D_GLIBCXX_DEBUG`，标准库会检查比较器的合法性。
3. **只比较部分字段可以吗？** —— 可以，只要形成等价类；但注意等价元素顺序不确定（`stable_sort` 才保序）。

## 易错点

- 用 `>=` / `<=` 当比较器
- 浮点直接比较，NaN 破坏顺序
- 比较器写成非 const 或捕获了可变状态
