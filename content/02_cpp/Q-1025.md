## 题目

static 修饰局部变量、全局变量和函数分别有什么作用？

## 口述答案

> 三个场景三个语义：**局部变量**加 static 后生命周期变成整个程序（存静态区，函数返回不销毁），只初始化一次，作用域仍限于函数；**全局变量**加 static 把链接属性变成内部链接，其他文件不能 extern 引用（避免重名冲突）；**函数**同理，static 函数只在本编译单元可见。
> 共同点：都是"限制可见性 / 延长生命周期"，不是"存到栈上"。

## 讲深一层

| 场景 | 存储期 | 链接属性 | 作用域 |
|---|---|---|---|
| 普通局部 | 函数调用 | 无 | 函数内 |
| static 局部 | 整个程序 | 无 | 函数内 |
| 普通全局 | 整个程序 | 外部 | 全工程 |
| static 全局/函数 | 整个程序 | 内部 | 本编译单元 |

## 高频追问

1. **函数内 static 变量线程安全吗？** —— C++11 起首次初始化是线程安全的（magic statics），但后续读写要自己同步。

## 易错点

- 说 static 变量存在栈上（在 .data/.bss）
- 以为 static 全局变量只是"私有"，忽略它影响链接
