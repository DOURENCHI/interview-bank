## 题目

**题目**：

```cpp
int *a[10];      // ?
int (*b)[10];    // ?
```

**问**：数组指针和指针数组怎么区分？

## 口述答案

> 看**谁先和谁结合**（`[]` 优先级高于 `*`）：`int *a[10]` 是**数组**，10 个元素，每个是 `int*`；`int (*b)[10]` 是**指针**，指向一个含 10 个 int 的数组。
> 读法：从变量名往外读，括号改变了结合顺序。

## 讲深一层

```cpp
int *a[10];        // a: array[10] of int*
int (*b)[10];      // b: pointer to array[10] of int
int (*c[3])(int);  // c: array[3] of pointer to function(int)->int
```
- `b = &arr;` 之后 `(*b)[2]` 才是元素，`b+1` 跳过整个数组（40 字节）。
- 二维数组传参退化成 `int (*)[N]`，第二维不能省，这就是"指针数组还是数组指针"最实际的分水岭。

## 高频追问

1. **二维数组 `int a[3][4]` 的 `a` 是什么类型？** —— `int(*)[4]`，数组指针。
2. **怎么写"指向函数指针数组的指针"？** —— `int (*(*p)[3])(int);`，从名字开始逐层往外读。

## 易错点

- 把 `int *a[10]` 说成"指针数组的指针"
- 二维数组传参写 `int**`（类型不兼容）
