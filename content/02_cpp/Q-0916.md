## 题目

**题目**：手写 `strcpy`，不许调库。

**问**：手写一个 strcpy，要考虑哪些边界？

## 口述答案

> 标准写法只有一行：`while ((*dst++ = *src++));`——赋值表达式的值就是拷贝的字符，遇到 `'\0'` 变假，循环结束，顺带把 `'\0'` 也拷了。
> 边界要答三点：**返回 `dst` 的原始指针**（支持链式调用）、**不做长度检查**（越界是调用方的责任）、**不处理重叠**（重叠要用 `memmove`）。

## 讲深一层

```c
char* my_strcpy(char* dst, const char* src) {
    if (!dst || !src) return dst;      // 防御性判断（标准库不判）
    char* ret = dst;
    while ((*dst++ = *src++) != '\0') { }
    return ret;
}
```
- 返回值设计是为了 `strlen(strcpy(a, b))` 这种链式用法。
- `strncpy` 的坑：长度不够时**不补 `\0`**，长度够时**把剩余全填 `\0`**（性能陷阱）。
- 生产代码应优先用 `strlcpy`/`snprintf`/`std::string`。

## 高频追问

1. **`strncpy` 安全吗？** —— 不自动补 `\0` 时会导致后续字符串操作越界读。
2. **为什么参数是 `const char*`？** —— 承诺不修改源串。

## 易错点

- 忘记返回 `dst`
- 用 `strncpy` 就当"安全版 strcpy"
