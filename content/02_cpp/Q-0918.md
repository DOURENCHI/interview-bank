## 题目

**题目**：手写 `strcat`，怎么避免越界？

**问**：手写一个 strcat，怎么避免越界？

## 口述答案

> 先找到 `dst` 的末尾（`\0` 处），再从那里逐字符拷 `src`。`strcat` 本身**没有任何长度检查**，越界只能靠调用方保证 `dst` 足够大。
> 安全写法是自己做长度检查，或改用 `snprintf` / `strncat`（注意 `strncat` 的 `n` 是"最多追加几个字符"，不是目标总容量——这是经典误解）。

## 讲深一层

```c
char* my_strcat(char* dst, const char* src) {
    char* p = dst;
    while (*p) ++p;                  // 找到末尾
    while ((*p++ = *src++) != '\0') { }
    return dst;
}
```
- `strncat(dst, src, n)`：追加最多 n 个字符，**再补一个 `\0`**，所以最多写 n+1 字节。
- 目标缓冲区必须预留 `strlen(dst) + strlen(src) + 1` 字节。
- 反复 `strcat` 是 O(n²)（每次都要重新找末尾），循环拼接应该用"记住尾部指针"或 `snprintf` / `std::string`。

## 高频追问

1. **`strncat` 的 n 是总长度吗？** —— 不是，是最多追加的字符数。
2. **怎么高效拼多个串？** —— 维护尾部指针，或一次性 `snprintf`。

## 易错点

- 把 `strncat` 的 n 当目标容量
- 循环里反复 `strcat`（O(n²)）
