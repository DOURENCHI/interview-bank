## 题目

**题目**：想让任务异步执行并拿到结果，除了 `std::thread` 还有 `packaged_task`。

**问**：std::thread 和 packaged_task 是什么关系？

## 口述答案

> `std::thread` 是**执行载体**（真的开一个线程）；`packaged_task` 是**任务包装器**（把可调用对象和 `future` 绑在一起），它自己不创建线程。
> 所以 `packaged_task` 可以丢进线程池、放进队列，由别的线程执行；`thread` 一创建线程就跑起来了，没法排队。

## 讲深一层

```cpp
std::packaged_task<int()> task([]{ return 42; });
std::future<int> fut = task.get_future();
std::thread t(std::move(task));     // 也可以用线程池执行
t.join();
int v = fut.get();                  // 42
```
| 工具 | 作用 |
|---|---|
| `thread` | 创建线程 |
| `async` | 交给实现决定同步/异步，返回 future |
| `packaged_task` | 包装任务，可延迟/排队执行，取 future |
| `promise` | 手动在某一刻 set_value |
- `packaged_task` 只能移动不能拷贝。
- 任务抛异常会被存进 future，`get()` 时重新抛出。

## 高频追问

1. **`async` 和 `packaged_task` 怎么选？** —— 想控制执行载体（线程池）用 `packaged_task`；只想"异步跑一下"用 `async`。
2. **future 能取几次？** —— 一次，`get()` 之后 `valid()` 为 false。

## 易错点

- 以为 `packaged_task` 会自己开线程
- 对同一个 future 调两次 `get()`
