## 题目

**场景**：`std::unique_ptr<int> p = q;` 编不过，必须 `std::move(q)`。

**问**：`unique_ptr` 为什么只能移动不能拷贝？移动之后原指针是什么状态？

## 口述答案

> 因为 `unique_ptr` 的表达的是**独占所有权**：如果允许拷贝，就会出现两个 `unique_ptr` 都认为自己该 `delete` 同一块内存，必然双重释放。所以拷贝构造和拷贝赋值被显式 `delete`。
> 移动之后原指针变成 **`nullptr`**（标准保证），所以可以安全析构。

## 讲深一层

```cpp
std::unique_ptr<int> p = std::make_unique<int>(1);
// std::unique_ptr<int> q = p;             // ❌ 拷贝被删除
std::unique_ptr<int> q = std::move(p);     // ✅ 转移所有权
assert(p == nullptr);                      // 移动后 p 为空

std::vector<std::unique_ptr<int>> v;
v.push_back(std::make_unique<int>(2));     // ✅ 传右值
// v.push_back(q);                         // ❌ 传左值
v.push_back(std::move(q));                 // ✅
```

| 操作 | `unique_ptr` | `shared_ptr` |
|---|---|---|
| 拷贝 | ❌ 删除 | ✅ 引用计数 +1 |
| 移动 | ✅ 原指针置空 | ✅ |
| 开销 | 与裸指针相同 | 控制块 + 原子操作 |
| 用途 | 独占资源 | 共享所有权 |

**"零开销"是什么意思**：默认删除器下 `sizeof(unique_ptr<T>) == sizeof(T*)`，没有额外存储，只是编译期禁止了拷贝。

**函数返回值可以直接返回 `unique_ptr`**：因为返回的是右值，走移动（或被复制省略）。

## 高频追问

1. **怎么把 `unique_ptr` 放进容器再取出来？** —— `push_back(std::move(p))`，取出时 `auto x = std::move(v[i])`。
2. **`unique_ptr` 能做函数参数吗？** —— 能，按值传表示"转移所有权"，按 `const&` 传表示"借用"。
3. **自定义删除器会影响大小吗？** —— 会，无状态删除器（函数指针或空 lambda）通常仍零开销，有状态会变大。

## 易错点

- 试图拷贝 `unique_ptr`
- 移动后继续用原指针（已为 nullptr，解引用崩溃）
- 用 `unique_ptr` 表达共享所有权
