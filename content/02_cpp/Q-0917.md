## 题目

**题目**：手写 `strcmp`，返回值怎么定义？

**问**：手写一个 strcmp，返回值怎么定义？

## 口述答案

> 返回**第一个不相同字符的差值**：`<0` 表示 s1 小、`0` 表示相等、`>0` 表示 s1 大。
> 两个要点：比较必须按 **`unsigned char`** 做（否则高字节字符会被当成负数，比较反了）；返回**差值**而不是 ±1（标准允许任意正负值，差值最自然）。

## 讲深一层

```c
int my_strcmp(const char* s1, const char* s2) {
    while (*s1 && (*s1 == *s2)) { ++s1; ++s2; }
    return (unsigned char)*s1 - (unsigned char)*s2;
}
```
- 不要写成 `return *s1 - *s2;`（`char` 可能是有符号的，UTF-8 汉字会出错）。
- 返回值只能用于判断正负，**不能用于判断差值大小**（标准只保证符号）。
- 类似的还有 `strncmp`（限长比较）、`memcmp`（按字节比较，可含 `\0`）。

## 高频追问

1. **为什么不能返回 1/-1？** —— 标准允许，但差值更有信息量，且实现更简单。
2. **`memcmp` 和 `strcmp` 区别？** —— 前者按字节比、需给长度、可处理二进制；后者遇 `\0` 停。

## 易错点

- 直接用 `char` 相减（有符号问题）
- 把返回值当"差多少"用
