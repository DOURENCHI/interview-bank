## 题目

**题目**：同一道面试题，被问"C++17 你用过什么"。

**问**：C++17 有哪些常用特性？

## 口述答案

> 按使用频率排：**结构化绑定**（`auto [k, v] : map`）、**`if constexpr`**（编译期分支，替代大量 SFINAE）、**`std::optional` / `variant` / `any` / `string_view`**、**`std::filesystem`**、**类模板实参推导 CTAD**（`std::pair p{1, 2.0}`）、**内联变量**（头文件里定义全局变量不再需要 inline 函数包装）。
> 还有 `[[nodiscard]]`、`[[maybe_unused]]`、折叠表达式、并行算法。

## 讲深一层

```cpp
for (auto& [k, v] : mymap) { ... }              // 结构化绑定
if constexpr (std::is_integral_v<T>) { ... }    // 编译期分支
std::optional<int> f();                          // 可能没有值
std::string_view sv = "abc";                     // 零拷贝只读视图
inline int g_counter = 0;                        // 内联变量
```
- `string_view` 不拥有内存、不保证 `\0` 结尾，**不能存生命周期短于它的字符串**。
- `optional` 替代"用 -1 / nullptr 表示失败"的写法，语义更清楚。
- `if constexpr` 让模板代码从"特化地狱"回到普通 if。

## 高频追问

1. **`string_view` 有什么坑？** —— 指向的缓冲被释放后就是悬垂，函数返回 `string_view` 要小心。
2. **CTAD 会影响重载决议吗？** —— 会，推导出的类型可能不是你想要的（如 `vector v{1,2}` 是 `vector<int>`）。

## 易错点

- 用 `string_view` 接临时 `std::string`
- 把 C++20 的 concepts 说成 C++17
