## 题目

**场景**：`std::sort(v.begin(), v.end(), cmp)` 里的 `cmp` 既可以传函数指针、函数对象，也可以传 lambda。

**问**：函数对象和 lambda 有什么区别？为什么谓词要求"无副作用"？

## 口述答案

> 函数对象是**重载了 `operator()` 的类实例**，能带状态；lambda 是**编译器生成的匿名函数对象**的语法糖——本质也是函数对象，只是写起来短。
> 谓词要求无副作用，是因为标准算法可能**对同一元素多次调用谓词**（快排、去重、lower_bound 都会），也可能**拷贝谓词**（按值传递）。带副作用的谓词（计数、修改外部状态）结果不可预测。

## 讲深一层

```cpp
struct Greater { bool operator()(int a, int b) const { return a > b; } };
auto lam = [](int a, int b) { return a > b; };

std::sort(v.begin(), v.end(), Greater{});   // 函数对象
std::sort(v.begin(), v.end(), lam);         // lambda（等价）
```

| 维度 | 函数对象 | lambda | 函数指针 |
|---|---|---|---|
| 可带状态 | ✅ | ✅（捕获） | ❌ |
| 可内联 | ✅ | ✅ | 通常 ❌ |
| 写法长度 | 长 | 短 | 中 |
| 类型 | 具名 | 匿名（每个不同） | 统一 |
| 存进容器 | 可以 | 可以（`std::function` 或 `auto`） | 可以 |

**"每个 lambda 都是不同类型"的实际影响**：两个写法相同的 lambda 类型不同，所以 `auto` 存它们没问题，但`std::function` 才能统一类型（有间接调用开销）。

**`operator()` 为什么建议加 `const`**：算法可能持有 `const` 谓词副本，非 const 的 `operator()` 会编译失败。

## 高频追问

1. **函数指针为什么通常不能内联？** —— 编译器不知道运行时指向哪个函数，只能间接调用。
2. **lambda 捕获的东西存在哪？** —— 存在 lambda 对象的成员里，所以 lambda 有大小。
3. **`std::function` 有什么代价？** —— 类型擦除 + 可能的堆分配 + 间接调用。

## 易错点

- 谓词里修改外部变量（副作用）
- `operator()` 忘了 `const`
- 以为 lambda 没有开销（捕获多时对象会变大）
