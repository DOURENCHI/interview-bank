## 题目

**题目**：`std::reverse(v.begin(), v.end())` 用了 `std::list` 却编不过。

**问**：`std::reverse` 的复杂度是多少？它需要哪类迭代器？`list` 该怎么反转？

## 口述答案

> `std::reverse` 是 O(n)，只需要**双向迭代器**（能 `++` 和 `--`），所以 `list` **可以**用——真正的限制是它不能用于前向迭代器（如 `forward_list`）。
> `list` 有自己的成员 `reverse()`，是 O(n) 且**不交换元素值、只改指针**，比 `std::reverse` 更高效。

## 讲深一层

```cpp
std::vector<int> v{1,2,3};
std::reverse(v.begin(), v.end());        // ✅ 双向迭代器即可

std::list<int> l{1,2,3};
std::reverse(l.begin(), l.end());        // ✅ 也能用（交换值）
l.reverse();                             // ✅ 更好：只改指针，O(n) 且元素不被移动

std::forward_list<int> fl;
// std::reverse(fl.begin(), fl.end());   // ❌ 前向迭代器不够
```

| 算法 | 迭代器要求 | 复杂度 |
|---|---|---|
| `reverse` | 双向 | O(n) |
| `reverse_copy` | 双向输入 | O(n) |
| `sort` | 随机访问 | O(n log n) |
| `stable_sort` | 随机访问 | O(n log² n) 或 O(n log n) |
| `list::reverse` | — | O(n)，只改指针 |

**为什么 `list::reverse` 更好**：`std::reverse` 用 `std::swap(*first, *last)` 交换元素值，对 `list` 意味着多次对象赋值；成员版本直接改节点指针，大对象时差距明显。

**同类规律**：`list` 有成员 `sort`、`reverse`、`merge`、`splice`，都是指针操作版本。

## 高频追问

1. **`reverse` 会失效迭代器吗？** —— 不会，只交换值，迭代器仍有效但指向的元素变了。
2. **怎么反转字符串？** —— `std::reverse(s.begin(), s.end())`；或 `std::string(s.rbegin(), s.rend())`。
3. **`rbegin()` 和 `reverse` 的关系？** —— 前者是反向视图，不修改容器；后者原地修改。

## 易错点

- 以为 `reverse` 需要随机访问迭代器
- 对 `list` 用 `std::reverse` 而不是成员 `reverse`
- 对 `forward_list` 用 `reverse`
