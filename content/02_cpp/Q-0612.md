## 题目

**场景**：一段代码在遍历 `vector` 时 `erase` 元素，编译通过、样例也过，但在特定数据下崩溃或漏删。

**问**：删除容器元素时，哪类错误编译器不报、结果却会错？

## 口述答案

> **迭代器失效**。`erase` 之后，被删位置及其后的迭代器全部失效，但类型没变、编译照过，运行时就是未定义行为。
> `vector` 上正确写法是接住返回值：`it = v.erase(it)`；`list`/`map` 同理。范围 `erase-remove` 惯用法适用于"删除所有满足条件的元素"。

## 讲深一层

```cpp
// ❌ 典型错误：erase 后继续 ++it
for (auto it = v.begin(); it != v.end(); ++it)
    if (*it % 2 == 0) v.erase(it);        // 迭代器失效

// ✅ vector / list / map 通用
for (auto it = v.begin(); it != v.end(); ) {
    if (*it % 2 == 0) it = v.erase(it);   // erase 返回下一个有效位置
    else ++it;
}

// ✅ 删除所有满足条件的元素（C++20 前）
v.erase(std::remove_if(v.begin(), v.end(),
                       [](int x){ return x % 2 == 0; }), v.end());
// C++20
std::erase_if(v, [](int x){ return x % 2 == 0; });
```

| 操作 | 失效范围 |
|---|---|
| `vector::push_back` 触发扩容 | **全部**指针/引用/迭代器 |
| `vector::erase` | 被删位置及之后 |
| `vector::insert` | 插入点及之后（可能全部） |
| `list` / `map` / `set` 插入删除 | 只有被删元素 |

**另一个静默错误**：范围 `for` 里 `erase`。`for (auto x : v) v.erase(...)` 的迭代器是隐藏的，你没法接住返回值，必崩。

## 高频追问

1. **为什么 `list` 的 `erase` 只失效被删元素？** —— 节点独立分配，其他节点地址不变。
2. **`remove_if` 之后为什么还要 `erase`？** —— `remove_if` 只把要保留的元素前移，返回新逻辑末尾，不改变 `size`。
3. **`map` 能边遍历边删吗？** —— 能，用 `it = m.erase(it)`；C++11 起 `erase` 返回下一个迭代器。

## 易错点

- `erase` 后继续 `++it`
- 范围 `for` 里删除元素
- 只调 `remove_if` 不调 `erase`，容器大小没变
