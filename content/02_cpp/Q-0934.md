## 题目

**题目**：

```cpp
int x = 1;
auto  a = x;    // ?
auto& b = x;    // ?
auto&& c = x;   // ?
```

**问**：`auto`、`auto&`、`auto&&` 有什么区别？

## 口述答案

> `auto` 是**值拷贝**（丢弃引用和顶层 const）；`auto&` 是**左值引用**（必须绑左值）；`auto&&` 是**转发引用**（能绑左值也能绑右值，配合 `std::forward` 保持值类别）。
> 关键坑：`auto` 会**悄悄拷贝**，在范围 for 里写 `for (auto s : vec)` 就复制了每个元素。

## 讲深一层

```cpp
std::vector<std::string> v{"a", "b"};
for (auto s : v)        { }   // 每个元素一次拷贝
for (auto& s : v)       { }   // 引用，可修改
for (const auto& s : v) { }   // 只读引用，零拷贝（推荐）
```
- `auto` 推导**丢弃顶层 const**：`const int x = 1; auto y = x;` 里 `y` 是 `int`。
- `auto&&` 在**没有模板推导**时（如 `auto&& c = x;`）仍然按引用折叠规则工作，等价于万能引用。
- `decltype(auto)` 保留引用和 const，适合转发返回值。

## 高频追问

1. **`auto` 能推导数组吗？** —— 会退化成指针；要保留数组用 `auto&`。
2. **`auto&&` 一定要配 `forward` 吗？** —— 要转发时配 `std::forward<decltype(x)>(x)`；否则具名变量是左值。

## 易错点

- 范围 for 用 `auto` 拷贝大对象
- 以为 `auto` 保留 const
