## 题目

结构体内存对齐，改变成员顺序后大小会不会变？

## 口述答案

> 会变。对齐规则：每个成员相对结构体起始地址的偏移必须是其对齐数的整数倍，结构体总大小要是最大对齐数的整数倍（末尾补 padding）。
> 把大对齐成员放前面、小成员集中放后面，通常能减少 padding。例如 `char + int + char`（12 字节）改成 `int + char + char`（8 字节）。

## 讲深一层

```c
struct A { char a; int b; char c; };   /* 12 字节 */
struct B { int b; char a; char c; };   /* 8 字节 */
```
末尾补齐：总大小必须是最大对齐数（int=4）的整数倍。

## 高频追问

1. **怎么取消对齐？** —— `#pragma pack(1)` 或 `__attribute__((packed))`，但会牺牲访问性能甚至触发非对齐异常。

## 易错点

- 以为总大小就是成员大小之和
- 不知道末尾也要补齐
