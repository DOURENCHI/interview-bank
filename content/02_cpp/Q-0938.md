## 题目

**题目**：`std::move` 和 `std::forward` 都返回右值引用，为什么还需要两个？

**问**：std::move 和 std::forward 有什么区别？完美转发怎么实现？

## 口述答案

> `std::move` **无条件**转成右值；`std::forward` **有条件**——只有当原参数是右值时才是右值，否则保持左值。
> 所以：`move` 用于"我确定这个对象不要了"，`forward` 用于**模板里把参数原样传给下一层**（完美转发）。

## 讲深一层

```cpp
template <typename T>
void relay(T&& x) {                 // 转发引用
    callee(std::forward<T>(x));     // 保持左值/右值
}

relay(1);        // T = int,    转发为右值
int a; relay(a); // T = int&,   转发为左值
```
- 完美转发 = **转发引用（`T&&` 且 T 需推导）** + **`std::forward<T>`**，两者缺一不可。
- 直接用 `x` 传给下一层会退化成左值（具名变量都是左值），丢了移动机会。
- 转发引用只在**有类型推导**时成立；`void f(int&& x)` 是普通右值引用。

## 高频追问

1. **为什么不能统一用 `move`？** —— 会把本该拷贝的左值参数当右值移走，调用方数据被掏空。
2. **`const T&` 能完美转发吗？** —— 不能，const 右值无法移动。

## 易错点

- 在转发函数里直接传 `x`
- 用 `std::move` 转发模板参数
