## 题目

**题目**：

```cpp
int (*f)(int);    // ?
int *g(int);      // ?
```

**问**：函数指针和指针函数有什么区别？

## 口述答案

> `int (*f)(int)` 是**函数指针**：f 是一个指针，指向"接收 int、返回 int"的函数。`int *g(int)` 是**指针函数**：g 是一个函数，接收 int、**返回 int 指针**。
> 判别方法同上：看括号和 `*` 的结合顺序。

## 讲深一层

```cpp
int add(int x) { return x + 1; }
int (*f)(int) = add;      // 函数指针
f(3);                     // 4
int (*tbl[2])(int) = {add, add};   // 函数指针数组 = 跳转表
```
- 函数指针的三大用途：**回调**（qsort 的比较函数）、**跳转表**（状态机、驱动 dispatch）、**动态加载**（`dlsym` 取符号）。
- 函数指针的大小与数据指针**不保证相等**（某些架构不同），但主流平台都是 8 字节。
- C++ 里优先用 `std::function` 或 lambda，但函数指针**没有堆分配、可内联**，热路径仍常用。

## 高频追问

1. **`typedef int (*FP)(int);` 有什么用？** —— 给函数指针类型起名，否则签名难读、易写错。
2. **函数指针能指向成员函数吗？** —— 不能，成员函数指针是另一种类型（需要对象）。

## 易错点

- 混淆 `int (*f)(int)` 和 `int *f(int)`
- 以为函数指针和数据指针大小一定相同
