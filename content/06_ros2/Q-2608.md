## 题目

**场景**：需要一个服务：输入图像路径（string），返回检测到的目标数量（int）。

**问**：用 C++ 从零写这个服务，完整流程是什么？关键文件都在哪？

## 口述答案

> 分五步：**建包 → 定义接口 → 实现服务端 → 实现客户端 → 编译运行**。
> 建包时用 `--dependencies rclcpp example_interfaces`；接口放在独立的 `srv` 目录，CMakeLists 里用 `rosidl_generate_interfaces` 生成代码；服务端 `create_service<接口>(名字, 回调)`；客户端 `create_client` 之后必须 `wait_for_service` 再 `async_send_request`；最后 `colcon build` 并 source。

## 讲深一层

```bash
ros2 pkg create --build-type ament_cmake image_srv \
  --dependencies rclcpp example_interfaces
mkdir -p image_srv/srv
```

`srv/Count.srv`：
```
string image_path
---
int32 count
```

`CMakeLists.txt` 关键三行：
```cmake
find_package(rosidl_default_generators REQUIRED)
rosidl_generate_interfaces(${PROJECT_NAME} "srv/Count.srv")
ament_export_dependencies(rosidl_default_runtime)
```

`package.xml` 要加 `rosidl_default_generators`（build）、`rosidl_default_runtime`（exec），以及：
```xml
<member_of_group>rosidl_interface_packages</member_of_group>
```

服务端：
```cpp
auto cb = [](const std::shared_ptr<image_srv::srv::Count::Request> req,
             std::shared_ptr<image_srv::srv::Count::Response> res) {
  res->count = do_detect(req->image_path);
};
auto srv = node->create_service<image_srv::srv::Count>("count", cb);
```

客户端：
```cpp
auto cli = node->create_client<image_srv::srv::Count>("count");
if (!cli->wait_for_service(std::chrono::seconds(3))) return 1;   // 少了会崩
auto fut = cli->async_send_request(req);
rclcpp::spin_until_future_complete(node, fut);
```

顺序重点：`rosidl_generate_interfaces` 必须在 `add_executable` 之前，否则头文件还没生成就开始编译。

## 高频追问

1. **服务端和客户端能在同一个节点吗？** —— 可以，但回调里再发请求在单线程执行器下会死锁，需要多线程执行器或拆成两个节点。
2. **同步和异步客户端怎么选？** —— 接口本身只有 `async_send_request`；所谓「同步」是自己加 `spin_until_future_complete` 等待。
3. **服务和话题怎么选？** —— 需要应答、结果有因果关系用服务；持续流式数据、多订阅者用话题；长任务可取消用 Action。

## 易错点

- 不写 `wait_for_service`，服务端慢启动就抛异常
- 把 `.srv` 放在包根目录（必须放 `srv/`）
- 忘了 `member_of_group`，`ros2 interface show` 找不到
