## 题目

**背景**：计算机体系结构基础题，考察对存储层次的理解。

**问**：CPU 访问内存的大致过程是什么？Cache 在里面起什么作用？

## 口述答案

> CPU 先发虚拟地址，MMU 用页表基址寄存器逐级查页表翻成物理地址，TLB 命中就跳过这步。拿到物理地址后按索引查 L1，miss 查 L2、L3，全 miss 才访问 DDR，并把数据按 cache line 整块调入。Cache 的作用是利用时间局部性和空间局部性，把访问延迟从 DRAM 的约 80 到 100 纳秒降到 L1 的几个周期，同时大幅降低 DDR 带宽压力。

## 讲深一层

| 层级 | 典型延迟 | 典型容量 |
|---|---|---|
| L1 | ~4 cycle（1–2 ns） | 32–64 KB |
| L2 | ~12 cycle | 256 KB–1 MB |
| L3 | ~40 cycle | 8–32 MB |
| DDR | 80–100 ns | GB 级 |

cache line 通常 64 字节；多核一致性靠 MESI 协议维护。

## 高频追问

1. **TLB miss 为什么贵？** —— 要走多级页表（x86-64 四级），每次可能多次访存，大页能减少 TLB 项压力。
2. **什么是伪共享？** —— 两个核改同一 cache line 的不同变量，导致该行反复失效，用 padding 对齐到 64 字节。
3. **怎么观测 cache 效果？** —— `perf stat -e cache-misses,cache-references` 算 miss rate。

## 易错点

- 说 CPU 直接用虚拟地址访存，漏掉 MMU 和 TLB
- 认为 cache 按字节加载，实际按 cache line
- 混淆延迟数量级，把 L3 说成和内存差不多
