## 题目

**题目**：两个进程要交换数据，除了读写同一个文件，还有哪些办法？

**问**：进程间通信有哪几种方式？哪些需要内核参与？

## 口述答案

> 六种主流方式：**管道（pipe/FIFO）**、**消息队列**、**共享内存**、**信号量**、**信号**、**socket**。
> **全部都要内核参与**（哪怕共享内存，建立和同步也需要内核），区别只是"数据是否经过内核"：共享内存**数据不经过内核**（最快），其余方式数据都要靠内核中转。

## 讲深一层

| 方式 | 数据经过内核 | 特点 |
|---|---|---|
| 匿名管道 | ✅ | 只能亲缘进程，单向 |
| 命名管道 FIFO | ✅ | 无亲缘要求 |
| 消息队列 | ✅ | 有消息边界 |
| 共享内存 | ❌（仅同步走内核） | **最快**，但要配信号量 |
| 信号 | ✅（只是一个编号） | 只能传"发生了某事" |
| socket | ✅ | 可跨机器 |
- 共享内存 + 信号量是最经典的组合：前者搬数据、后者防竞争。
- 管道容量有限（默认 64 KB），写满会阻塞。

## 高频追问

1. **最快的 IPC 是哪个？** —— 共享内存（零拷贝），但同步开销不可忽略。
2. **匿名管道为什么只能用于亲缘进程？** —— 它靠 fork 继承文件描述符。

## 易错点

- 说"共享内存完全不需要内核"
- 用管道传大量数据（容量和拷贝都不划算）
