## 题目

**题目**：

```python
funcs = [lambda: i for i in range(3)]
[f() for f in funcs]     # 你以为 [0,1,2]？
```

**问**：输出是什么？为什么？闭包捕获的是值还是变量？

## 口述答案

> 输出 `[2, 2, 2]`。因为 lambda 捕获的是**变量 `i` 本身**（延迟绑定），不是当时的值；等 lambda 被调用时，循环已结束，`i` 是 2。
> 修复方法是把值绑成默认参数：`lambda i=i: i`，或者用 `functools.partial`。

## 讲深一层

```python
# ❌ 延迟绑定
funcs = [lambda: i for i in range(3)]
[f() for f in funcs]        # [2, 2, 2]

# ✅ 默认参数立即绑定
funcs = [lambda i=i: i for i in range(3)]
[f() for f in funcs]        # [0, 1, 2]

# ✅ partial
from functools import partial
funcs = [partial(lambda x: x, i) for i in range(3)]
```

**LEGB 规则**（查找顺序）：Local → Enclosing → Global → Built-in。

```python
x = 'global'
def outer():
    x = 'enclosing'
    def inner():
        nonlocal x       # 不加这行，x = ... 会创建局部变量
        x = 'changed'
    inner()
    return x             # 'changed'
```

| 关键字 | 作用 |
|---|---|
| `global` | 声明后面用的是全局变量 |
| `nonlocal` | 声明用的是外层函数的变量 |
| 都没有 | 赋值即创建局部变量 |

**`nonlocal` 的必要性**：函数内对变量**赋值**就会让它变成局部变量，读外层变量不报错但改不了——想改必须 `nonlocal`。

## 高频追问

1. **为什么 lambda 会延迟绑定？** —— 闭包保存的是作用域引用，不是值快照。
2. **循环变量在 Python 3 里泄漏吗？** —— 不泄漏（Python 3 有独立作用域），Python 2 会。
3. **装饰器里的闭包有什么坑？** —— 同理，装饰器工厂的参数要立即绑定。

## 易错点

- 在循环里创建 lambda 并用循环变量
- 想改外层变量却忘了 `nonlocal`
- 以为 Python 3 的循环变量会泄漏
