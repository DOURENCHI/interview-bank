## 题目

**题目**：

```python
import copy
a = [[1, 2], [3, 4]]
b = a[:]              # 或 copy.copy(a)
b[0][0] = 99
print(a)              # ?
```

**问**：输出是什么？浅拷贝和深拷贝的区别在哪？

## 口述答案

> 输出 `[[99, 2], [3, 4]]`——`a` 被改了。因为浅拷贝只复制**外层容器**，内层列表仍是同一批对象，改内层会互相影响。
> 深拷贝（`copy.deepcopy`）会递归复制所有层级，彻底独立，代价是更慢、更深。

## 讲深一层

```python
import copy
a = [[1, 2], [3, 4]]

b = a[:]              # 浅拷贝：外层新建，内层共享
b[0][0] = 99          # a 也变了

c = copy.deepcopy(a)  # 深拷贝：完全独立
c[0][0] = 0           # a 不受影响
```

| 方式 | 外层 | 内层 | 速度 |
|---|---|---|---|
| `b = a` | 共享 | 共享 | 最快（别名） |
| `a[:]` / `copy.copy` | 新建 | **共享** | 快 |
| `copy.deepcopy` | 新建 | 新建 | 慢 |

**deepcopy 怎么处理循环引用**：内部用 `memo` 字典记录已复制的对象，遇到环就复用，所以 `a.append(a)` 也能正确深拷贝。

**不可变对象不用深拷贝**：`int`、`str`、`tuple`（元素都不可变）深拷贝会直接返回原对象。

**工程建议**：能用不可变结构（tuple、frozenset、namedtuple）就别用嵌套 list——避免整个拷贝语义的问题。

## 高频追问

1. **`deepcopy` 能复制函数/类吗？** —— 类实例可以，模块/函数返回原对象。
2. **numpy 数组拷贝？** —— `arr.copy()`，切片是视图不是拷贝。
3. **怎么判断两个对象是否共享？** —— `id(a[0]) == id(b[0])`。

## 易错点

- 用 `a[:]` 以为得到完全独立的副本
- 对 numpy 切片误以为是拷贝
- 深拷贝大对象导致性能问题
