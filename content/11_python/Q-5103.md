## 题目

**题目**：

```python
a = [1, 2, 3, 4, 5]
a[1:3]      # ?
a[::-1]     # ?
a[10:20]    # ?
b = a[:]    # b 和 a 什么关系？
```

**问**：切片返回的是拷贝还是视图？负步长和越界切片怎么处理？

## 口述答案

> Python 的切片**返回新列表（浅拷贝）**，不是视图。所以 `b = a[:]` 之后改 `b` 不影响 `a`（但元素是同一批对象，改元素内部属性会互相影响）。
> 越界切片**不报错**，会自动截断到边界。负步长表示反向，`a[::-1]` 是反转。

## 讲深一层

```python
a = [1, 2, 3, 4, 5]
a[1:3]      # [2, 3]        左闭右开
a[::-1]     # [5, 4, 3, 2, 1]
a[10:20]    # []            越界不报错
a[-2:]      # [4, 5]
a[::2]      # [1, 3, 5]

b = a[:]                 # 浅拷贝
b.append(6)              # a 不受影响
c = a                    # 别名，改 c 就是改 a
```

| 表达式 | 结果 | 说明 |
|---|---|---|
| `a[1:3]` | 新列表 | 浅拷贝 |
| `a[:]` | 新列表 | 常用浅拷贝写法 |
| `a[10:20]` | `[]` | 越界截断 |
| `a[::-1]` | 反转副本 | 不是原地 |
| `a.reverse()` | `None` | **原地**，返回 None |

**对比 numpy**：numpy 的切片是**视图**（`a[1:3]` 不复制），改视图会影响原数组。所以"Python 切片是拷贝"这个结论**只对内置序列成立**，套到 numpy 上会出 bug——这是数据科学代码里最常见的误判之一。

**切片赋值能改长度**：`a[1:3] = [9]` 会把两个元素换成一个。

## 高频追问

1. **怎么原地反转？** —— `a.reverse()` 或 `a[:] = a[::-1]`。
2. **切片能用在字符串上吗？** —— 能，返回新字符串。
3. **`a[:]` 和 `copy.copy(a)` 有区别吗？** —— 对 list 等价；对自定义对象语义相同。
