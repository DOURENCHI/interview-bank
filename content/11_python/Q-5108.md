## 题目

**题目**：存一组固定不变的坐标，用 `list` 还是 `tuple`？

**问**：`list` 和 `tuple` 该怎么选？除了"能不能改"，还有什么差别？

## 口述答案

> 除了可变性，还有三条实际差别：**tuple 更省内存、创建更快**、**可哈希（能当 dict key / set 元素）**、**语义上表达"结构固定"**。
> 所以"固定的一组值"（坐标、RGB、函数返回多值）用 tuple；"会增删改的集合"用 list。

## 讲深一层

```python
import sys
sys.getsizeof((1,2,3))     # 64
sys.getsizeof([1,2,3])     # 88（多一个容量字段和指针数组）

# tuple 可哈希
d = {(1, 2): "point"}      # ✅
# d = {[1, 2]: "point"}    # ❌ unhashable

# 函数返回多值本质是 tuple
def f(): return 1, 2
x, y = f()                 # 解包
```

| 维度 | list | tuple |
|---|---|---|
| 可变 | ✅ | ❌ |
| 内存（3 元素） | 88 B | 64 B |
| 可哈希 | ❌ | ✅（元素可哈希时） |
| 方法 | 多（append/sort…） | 少（count/index） |
| 语义 | 同质集合 | 异构记录 |

**性能提示**：tuple 的常量会被编译器缓存复用，`a = (1,2,3)` 两次可能指向同一对象；list 每次都要新建。

**用 tuple 表达"记录"更清晰**：`(x, y)` 是坐标，`[x, y]` 是"一个列表"。虽然 Python 不强制，但语义清楚能减少 bug（比如误 append）。

## 高频追问

1. **namedtuple 有什么用？** —— 带字段名的 tuple，可读性更好且仍是 tuple。
2. **tuple 里有 list 能改吗？** —— 能改 list 内容，但不能换掉那个 list 引用。
3. **`tuple()` 转换有开销吗？** —— 有，会复制。

## 易错点

- 用 list 当 dict key
- 以为 tuple 里面的可变元素也被冻结
- 为省内存滥用 tuple 导致需要改时很别扭
