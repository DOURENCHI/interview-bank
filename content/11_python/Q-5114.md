## 题目

**题目**：

```python
it = iter([1, 2])
next(it)      # 1
next(it)      # 2
next(it)      # ?
list(it)      # ?
```

**问**：迭代器协议是什么？为什么迭代器"用完就废"？

## 口述答案

> 协议是：对象实现 `__iter__()` 返回自身，实现 `__next__()` 返回下一个元素，耗尽时抛 `StopIteration`。
> 第三次 `next` 抛 `StopIteration`；`list(it)` 返回 `[]`——因为迭代器**有状态**，一旦耗尽（或部分消费），就不能重置。

## 讲深一层

```python
class Counter:
    def __init__(self, n): self.i, self.n = 0, n
    def __iter__(self): return self
    def __next__(self):
        if self.i >= self.n: raise StopIteration
        self.i += 1
        return self.i - 1

c = Counter(3)
list(c)      # [0, 1, 2]
list(c)      # []      ← 已耗尽
```

| 概念 | 定义 |
|---|---|
| 可迭代（Iterable） | 有 `__iter__`，如 list、dict |
| 迭代器（Iterator） | 有 `__iter__` + `__next__`，**一次性** |
| `for` 的本质 | 调 `iter()`，然后反复 `next()`，捕获 `StopIteration` |

**这个特性会导致真实 bug**：

```python
nums = iter([1,2,3])
total = sum(nums)        # 6
print(max(nums))         # ValueError: max() arg is an empty sequence
```

所以**不要把迭代器传给多个消费者**，需要多次遍历就传 list。

**`zip`、`map`、`filter` 在 Python 3 里返回迭代器**（Python 2 返回 list），这也是 2→3 迁移的常见坑。

## 高频追问

1. **怎么重置迭代器？** —— 不能，重新调用 `iter(原可迭代对象)`。
2. **`for` 循环为什么不会抛 StopIteration？** —— 它内部捕获了。
3. **生成器也是迭代器吗？** —— 是，`__iter__` 返回自身。

## 易错点

- 把同一个迭代器传给两个函数
- 以为 `map`/`zip` 返回 list
- 在循环外手动 `next` 后又 `for` 遍历
