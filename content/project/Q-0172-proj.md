## 题目

**追问**：U-Net 图上那些横向虚线（跳跃连接）到底在传什么？去掉会怎样？

**问**：U-Net 的跳跃连接具体补了什么信息？不加会怎样？

## 口述答案

> 补的是**高分辨率的浅层特征**：边缘、角点、纹理这些定位信息。
> 编码器每下采样一次，分辨率减半、语义变强但**空间细节丢失**；解码器上采样只能"猜"细节，猜出来的边界是模糊的。跳跃连接把下采样前的特征直接拼过来，等于告诉解码器"这里原来的边界长这样"。

## 讲深一层

```
编码器：512² → 256² → 128² → 64² → 32²（语义强、位置粗）
解码器：32² → 64² → 128² → 256² → 512²（语义弱、位置细）
跳跃：  把编码器每层特征 concat 到对应解码层  ← 关键
```

| 连接方式 | 计算 | 效果 |
|---|---|---|
| concat（U-Net） | 通道数相加 | 保留全部信息，参数多 |
| add（ResNet 式） | 逐元素相加 | 省参数，但会混叠 |
| 无连接 | — | 边界模糊、小目标丢失 |

**不加会怎样**：Dice 可能只掉几个点，但**HD95 会明显变差**——因为边界定位不准。这就是为什么医学分割既看 Dice 又看 HD95（见后面那题）。

**一个进阶点**：跳跃连接也有"语义鸿沟"问题（浅层特征语义弱），所以有 U-Net++（密集跳跃 + 深监督）、Attention U-Net（用门控筛选跳跃特征）这类改进。

## 高频追问

1. **concat 和 add 哪个好？** —— concat 保留信息更多，add 更省参数；医学分割多用 concat。
2. **跳跃连接会增加显存吗？** —— 会，解码层通道数翻倍。
3. **能只连部分层吗？** —— 能，浅层连接对边界贡献最大。

## 易错点

- 说"跳跃连接是为了防梯度消失"（那是 ResNet 的作用）
- 不知道 concat 和 add 的区别
- 只报 Dice 不报边界指标
