## 题目

**题目**：要测一个 1 kHz PWM 输入信号的频率和占空比，用输入捕获。

**问**：从模式控制器的复位模式为什么能一次测出周期和占空比？

## 口述答案

> 因为**复位模式让每次上升沿都把计数器清零**，于是两个通道可以分工：一个通道捕获上升沿（记录周期），另一个捕获下降沿（记录高电平时间）。两次捕获值一比，频率和占空比同时得到。
> 计数器被"对齐"到信号上，所以不需要软件算差值，也不会累积误差。

## 讲深一层

```c
// PWM 输入模式：CH1 上升沿复位计数器并捕获，CH2 下降沿捕获
sConfigIC.ICPolarity  = TIM_INPUTCHANNELPOLARITY_RISING;
sConfigIC.ICSelection = TIM_ICSELECTION_DIRECTTI;
HAL_TIM_IC_ConfigChannel(&htim2, &sConfigIC, TIM_CHANNEL_1);

sConfigIC.ICPolarity  = TIM_INPUTCHANNELPOLARITY_FALLING;
HAL_TIM_IC_ConfigChannel(&htim2, &sConfigIC, TIM_CHANNEL_2);

sSlaveConfig.SlaveMode = TIM_SLAVEMODE_RESET;      // 从模式：复位
sSlaveConfig.InputTrigger = TIM_TS_TI1FP1;
HAL_TIM_SlaveConfigSynchro(&htim2, &sSlaveConfig);
```

```
信号   ‾‾‾|_____|‾‾‾‾‾|_____
CNT    0  ↑清0  ↓捕获   ↑清0
       CCR1 = 周期      CCR2 = 高电平
占空比 = CCR2 / CCR1
```

| 从模式 | 作用 |
|---|---|
| 复位模式 | 触发信号到来时计数器清零 |
| 门控模式 | 触发信号高电平期间才计数 |
| 触发模式 | 触发信号启动计数器 |

**为什么比"两次捕获算差值"好**：差值法要处理计数器溢出（65535 回绕），代码复杂；复位模式每次自动归零，直接读 CCR 就是结果。

**注意**：两次捕获必须用同一个定时器的**不同通道**，且都映射到同一个 TI 输入。

## 高频追问

1. **频率范围受什么限制？** —— 信号频率要低于定时器计数频率，且周期不能超过 65535 个计数。
2. **占空比精度？** —— 取决于计数频率，1 MHz 计数时 1 ms 周期有 1000 个刻度，精度 0.1%。
3. **能测超低频吗？** —— 需要降计数频率或处理溢出。

## 易错点

- 两个通道用了不同的 TI 输入
- 没开从模式复位，CNT 自由跑
- 计数频率太高，周期超过 65535
