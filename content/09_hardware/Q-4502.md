## 题目

**题目**：ARM 有 7 种工作模式，为什么一个 CPU 要分这么多"身份"？

**问**：ARM 有哪几种工作模式？为什么要分模式？

## 口述答案

> 七种：**User**（普通程序）、**FIQ**（快中断）、**IRQ**（普通中断）、**Supervisor**（复位/软中断后进入，特权）、**Abort**（访存异常）、**Undefined**（未定义指令）、**System**（特权模式，和 User 共用寄存器但可访问特权资源）。
> 分模式的目的：**让不同来源的异常有独立的上下文和权限**——中断处理不应该能随便动用户态的数据；User 模式访问受限资源会触发异常，这是操作系统做保护的基础。

## 讲深一层

| 模式 | 触发 | 特权 |
|---|---|---|
| User | 正常运行 | 非特权 |
| FIQ / IRQ | 中断 | 特权 |
| Supervisor | 复位、SVC | 特权 |
| Abort | 访存失败 | 特权 |
| Undefined | 非法指令 | 特权 |
| System | 特权态运行系统代码 | 特权 |
- 模式切换由硬件自动完成（保存 CPSR 到 SPSR、切寄存器组）。
- Cortex-M 简化成**线程模式 + 处理模式**（Handler），靠 CONTROL 寄存器区分特权级。

## 高频追问

1. **为什么 FIQ 比 IRQ 快？** —— 有私有寄存器组（R8–R12），不用保存现场。
2. **Cortex-M 还有 7 种模式吗？** —— 没有，简化成 Thread/Handler 两模式 + 特权/非特权两级。

## 易错点

- 把 System 模式和 User 模式搞混
- 以为 Cortex-M 也是 7 种模式
