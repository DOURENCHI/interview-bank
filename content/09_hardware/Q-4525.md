## 题目

**题目**：FreeRTOS 里那个优先级 0 的空闲任务，除了占内存还有什么用？

**问**：FreeRTOS 的空闲任务和钩子函数是干什么的？

## 口述答案

> 空闲任务是**优先级最低（0）的系统任务**，没有其他任务就绪时运行。它有两个职责：**回收被删除任务的栈和 TCB**，以及执行**空闲钩子**（`vApplicationIdleHook`）。
> 钩子的典型用途：进低功耗模式、喂狗、做后台统计、清理资源。

## 讲深一层

```c
void vApplicationIdleHook(void) {
    __WFI();          // 无任务时进睡眠，中断唤醒
}
```
| 钩子 | 触发时机 | 用途 |
|---|---|---|
| `vApplicationIdleHook` | 空闲任务里 | 低功耗、喂狗 |
| `vApplicationTickHook` | 每个 tick | 计时统计（必须极短） |
| `vApplicationMallocFailedHook` | 堆分配失败 | 记录/复位 |
| `vApplicationStackOverflowHook` | 栈溢出 | 定位问题任务 |
- 空闲钩子**不能阻塞**（不能调用 `vTaskDelay` 或等信号量）。
- 用了 `configUSE_TICKLESS_IDLE` 后，空闲钩子里的 `WFI` 会被替换成更省电的机制。
- 空闲任务的栈由 `configMINIMAL_STACK_SIZE` 决定，钩子写得复杂要加大。

## 高频追问

1. **空闲任务能删掉吗？** —— 不能，调度器依赖它，且删任务的内存回收靠它。
2. **tick 钩子里能做什么？** —— 只能做极短的事（它在中断上下文）。

## 易错点

- 在空闲钩子里阻塞
- 空闲任务栈开太小，钩子里用 `printf` 就溢出
