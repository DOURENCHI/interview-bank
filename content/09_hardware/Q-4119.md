## 题目

**题目**：一个按键要区分短按、长按 2 秒、双击。

**问**：按键的长按和短按怎么在 RTOS 里区分？为什么不能在中断里做？

## 口述答案

> 用**一个按键任务 + 状态机**：任务每 10–20 ms 扫一次，记录按下时刻，松开时算时长判断短按/长按，同时用时间窗口判断双击。
> **不能在中断里做**：中断服务函数必须极短，而按键判断需要延时和多次采样，放中断里会长时间占用 CPU、阻塞其他中断。

## 讲深一层

```c
typedef enum { IDLE, PRESSED, LONG_SENT } key_state_t;

void task_key(void* p) {
    key_state_t st = IDLE;
    TickType_t t_press = 0;
    for (;;) {
        int down = (HAL_GPIO_ReadPin(KEY_PORT, KEY_PIN) == GPIO_PIN_RESET);
        switch (st) {
        case IDLE:
            if (down) { st = PRESSED; t_press = xTaskGetTickCount(); }
            break;
        case PRESSED:
            if (!down) {                                  // 松开
                if (xTaskGetTickCount() - t_press < pdMS_TO_TICKS(500))
                    send_event(EV_SHORT);
                st = IDLE;
            } else if (xTaskGetTickCount() - t_press > pdMS_TO_TICKS(2000)) {
                send_event(EV_LONG);
                st = LONG_SENT;                           // 防止重复触发
            }
            break;
        case LONG_SENT:
            if (!down) st = IDLE;
            break;
        }
        vTaskDelay(pdMS_TO_TICKS(10));                    // 扫描周期，兼做消抖
    }
}
```

| 需求 | 做法 |
|---|---|
| 消抖 | 10–20 ms 扫描周期天然消抖 |
| 短按 | 按下到松开 < 500 ms |
| 长按 | 按住 > 2000 ms，触发一次 |
| 双击 | 第一次松开后启动窗口定时器，窗口内再按算双击 |

**双击的实现要点**：需要一个"等待第二击"的状态，用 `xTaskGetTickCount()` 记第一次松开时刻，超过窗口（如 300 ms）就当作单击。

## 高频追问

1. **为什么用 `xTaskGetTickCount()` 而不是自己计数？** —— 它是系统 tick，天然单调且和 `vTaskDelay` 同源。
2. **按键多怎么办？** —— 一个任务扫全部按键，事件通过队列发出去。
3. **能做成事件驱动吗？** —— 用 EXTI 中断唤醒任务，任务里再做状态机（省电）。

## 易错点

- 在 EXTI 中断里做长按判断
- 长按触发后不复位，一直重复触发
- 扫描周期太长（>50 ms），快速点按丢失
