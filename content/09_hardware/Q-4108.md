## 题目

**场景**：从官网下了 FreeRTOS 源码，目录里几十个文件，不知道该往 Keil 工程里加哪些。

**问**：移植 FreeRTOS 时，源码目录里哪些文件必须拷进工程？哪些可以裁掉？

## 口述答案

> 分三类：**内核核心**（`tasks.c`、`queue.c`、`list.c`，必需）、**可选模块**（`timers.c`、`event_groups.c`、`stream_buffer.c`，用才加）、**移植层**（`port.c`、`portmacro.h`，必需，且要选对编译器/架构目录）、**堆实现**（`heap_1.c`~`heap_5.c`，**只选一个**）。
> `portable/` 下有很多目录，只保留你用的那个（如 `GCC/ARM_CM3` 或 `RVDS/ARM_CM3`）。

## 讲深一层

```
FreeRTOS/Source/
├── tasks.c            必需
├── queue.c            必需
├── list.c             必需
├── timers.c           用软件定时器才加
├── event_groups.c     用事件组才加
├── stream_buffer.c    用流缓冲/消息缓冲才加
├── croutine.c         协程，基本不用，可裁
├── include/           必需（头文件目录）
└── portable/
    ├── MemMang/
    │   └── heap_4.c   ← 只选一个
    └── GCC/ARM_CM3/
        └── port.c     ← 按内核/编译器选
```

| 目录/文件 | 是否必需 | 说明 |
|---|---|---|
| `tasks.c` `queue.c` `list.c` | ✅ | 内核基础 |
| `port.c` + `portmacro.h` | ✅ | 与架构强相关 |
| `heap_x.c` | ✅（选一） | 内存管理方案 |
| `FreeRTOSConfig.h` | ✅ | 自己写，不放源码目录 |
| `timers.c` / `event_groups.c` | 按需 | 不用就别加，省空间 |
| `croutine.c` | ❌ | 协程已过时 |

**选错 port 目录的典型报错**：`undefined symbol vPortSVCHandler`、或编译过但 HardFault——因为寄存器保存方式不对。

## 高频追问

1. **`port.c` 怎么选？** —— 按"编译器 + 内核"两级：`GCC/ARM_CM4F` 表示 GCC + Cortex-M4F（带 FPU）。
2. **`heap_x.c` 能加多个吗？** —— 不能，符号冲突（都定义 `pvPortMalloc`）。
3. **新版还把 `portmacro.h` 放在 port 目录吗？** —— 是，跟着 `port.c` 一起。

## 易错点

- 加了多个 `heap_x.c`，链接报重复定义
- 选错 port 目录（CM3 的 port 用在 CM4F 上）
- 把 `FreeRTOSConfig.h` 放在源码目录，换项目时被覆盖
