## 题目

**题目**：USART1 挂在 72 MHz，要 115200 波特率，`BRR` 该写多少？

**问**：波特率与 `BRR` 的换算关系是什么？误差怎么算？

## 口述答案

> 公式是 `USARTDIV = f_CK / (16 × 波特率)`，`BRR` 的整数部分占高 12 位、小数部分占低 4 位。
> 72 MHz、115200：`USARTDIV = 72e6 / (16 × 115200) = 39.0625`，所以 `BRR = 39×16 + 1 = 625 = 0x271`。

## 讲深一层

```c
// 手算
// USARTDIV = 72000000 / (16 * 115200) = 39.0625
// 整数 39 → 0x27，小数 0.0625*16 = 1
// BRR = (39 << 4) | 1 = 0x271

// 用 HAL 直接设，不用手算
huart1.Init.BaudRate = 115200;
```

| 参数 | 含义 |
|---|---|
| `f_CK` | USART 时钟（USART1 是 APB2=72 MHz；USART2 是 APB1=36 MHz） |
| 16 | 过采样倍数（默认 16 倍） |
| `BRR[15:4]` | 整数部分 |
| `BRR[3:0]` | 小数部分（1/16） |

**误差计算**：`实际波特率 = f_CK / (16 × USARTDIV_实际)`。这里 39.0625 恰好精确，误差 0；如果用 36 MHz 算 115200，`36e6/(16*115200)=19.53`，量化到 19.5 → 实际 115384，误差 0.16%，可以接受（UART 一般容忍 ±2–3%）。

**异步串口为什么允许误差**：接收方在每位中间采样，累计误差不超过半个位就能正确判定；一帧 10 位，所以总误差要小于 5%（实际工程控制在 2% 以内）。

## 高频追问

1. **能改过采样为 8 倍吗？** —— 能（`OVERSAMPLING_8`），高速率时提高精度，但抗噪差一些。
2. **为什么 USART2 的 BRR 不一样？** —— 时钟源是 APB1=36 MHz。
3. **波特率对不上会怎样？** —— 收到乱码或帧错误（FE），完全对不上则收不到。

## 易错点

- 用错时钟源（USART2 用了 72 MHz 算）
- 手算 BRR 时小数部分算错
- 两边波特率差超过 3%
