## 题目

**题目**：I2C 的 SDA/SCL 必须接上拉电阻，忘了接就完全收不到数据。

**问**：推挽与开漏有什么区别？I2C 为什么一定要接上拉电阻？

## 口述答案

> **推挽**有上下两个管子，能主动输出高和低；**开漏**只有下管，只能主动拉低，高电平必须靠外部上拉电阻。
> I2C 是**多设备共享总线**，必须支持"线与"：任一设备拉低就是低，全都不拉才是高。如果某设备用推挽输出高，就会和拉低的设备形成短路。所以 I2C 引脚必须配成开漏输出 + 外部上拉。

## 讲深一层

```
推挽：        开漏：
   VCC           VCC
    │             │
   ┌┴┐           ┌┴┐  ← 上管不存在
   │ │ P         │ │
   └┬┘           └┬┘
    ├── OUT       ├── OUT ──[R]── VCC  ← 外部上拉
   ┌┴┐           ┌┴┐
   │ │ N         │ │ N
   └┬┘           └┬┘
   GND           GND
```

| 特性 | 推挽 | 开漏 |
|---|---|---|
| 输出高 | 主动拉高 | 靠上拉 |
| 线与 | ❌ 会短路 | ✅ |
| 电平转换 | ❌ | ✅（上拉到不同电压） |
| 上升沿 | 快 | 由上拉 RC 决定 |
| 适用 | 单向输出（PWM、时钟） | 共享总线（I2C、SMBus） |

**上拉电阻怎么选**：太大 → 上升沿慢、高速下采错；太小 → 功耗大、灌电流超限。400 kHz 常用 2.2–4.7 kΩ，100 kHz 用 4.7–10 kΩ。

**计算依据**：`t_r ≈ 0.847 × R × C_bus`（C_bus 含走线和引脚电容），要求 `t_r < 0.3 × 位周期`。

**同一根 I2C 总线上不同电压的器件**：各接各自电压的上拉即可实现电平转换（这也是开漏的优点）。

## 高频追问

1. **能用内部上拉吗？** —— 能但不推荐，内部上拉约 40 kΩ，上升沿太慢。
2. **开漏能驱动 LED 吗？** —— 能，但只能灌电流（LED 接 VCC 侧）。
3. **SPI 为什么不用开漏？** —— 每个从机有独立 CS，MOSI/SCK 是单向点对点，不需要线与。

## 易错点

- I2C 配成推挽输出
- 上拉电阻取 100 kΩ，上升沿太慢
- 多个器件用不同上拉电压却没隔离
