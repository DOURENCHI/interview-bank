## 题目

**背景**：小鹏嵌入式二面的定时器题。STM32 定时器是嵌入式面试的固定考点，考 PWM 基础概念（Q-4511 已覆盖频率/占空比/死区）之后的下一层：输出比较和输入捕获两种工作模式的本质区别，以及 PSC/ARR 两个寄存器的定量计算——能不能现场算出具体频率，是「背过概念」和「真配过定时器」的分水岭。
**问**：PWM 输出和输入捕获有什么区别？如何计算 PSC 和 ARR？

## 口述答案

> 先说两者的定位。PWM 输出是「定时器当信号源」：芯片按设定的周期和占空比，在引脚上主动打出方波，用来驱动电机调速、舵机角度、LED 调光这类执行器。输入捕获是「定时器当测量仪」：引脚上进来一路外部信号，定时器在信号的上升沿或下降沿瞬间把当前计数值锁存到捕获寄存器里，用两次锁存的差值乘以计数周期，反推出外部信号的频率、脉宽、占空比——典型用途是测超声波回波脉宽、解码红外遥控信号、测编码器或风扇转速反馈。一个是打出去，一个是量进来，方向相反；底层用的都是同一个计数器 CNT，只是比较/捕获寄存器的角色变了。
> 再讲计数框架。STM32 定时器内部是「预分频器 PSC 加计数器 CNT 加自动重装寄存器 ARR」三级：输入的定时器时钟先被 PSC 分频，得到计数器的计数节拍，CNT 从 0 数到 ARR 后溢出，回到 0 重新数（向上计数模式）。所以输出 PWM 的频率公式是：f_PWM = 定时器时钟 / ((PSC+1) × (ARR+1))，占空比由比较寄存器 CCR 决定：duty = CCR / ARR。注意两个寄存器都要加一，因为 PSC=0 表示不分频而不是二分频，ARR 数到它本身才溢出，计了 ARR+1 个节拍。
> 举个实际数字：72 MHz 的定时器时钟，要输出 1 kHz 的 PWM。72 MHz 除以 1 kHz 是 72000 个计数节拍，拆成 (PSC+1)×(ARR+1)。常见拆法 PSC=71（即 72 分频，计数节拍变 1 MHz）、ARR=999，1 MHz 数 1000 个正好 1 kHz；此时 CCR=500 就是 50% 占空比。反过来输入捕获测频率不用配频率，只配一个尽量小的分频保证分辨率，然后测出两次捕获差值 ΔN，信号频率 = 计数节拍频率 / ΔN。比如节拍 1 MHz、ΔN=20000，信号就是 50 Hz。
> 选 PSC 和 ARR 还有个工程细节：计数分辨率和频率是矛盾的，ARR 越大占空比可调档位越细。所以一般先给 ARR 拉大（比如 999 而不是 99），再用 PSC 凑剩下的分频比，占空比精度就高。

## 讲深一层

- 输出比较模式内部还有 PWM 模式 1/2 之分：模式 1 是 CNT<CCR 时输出有效电平，模式 2 相反，两者只是极性翻转；配 CubeMX 时极性选错，示波器上看是反相波形，这是新手最常踩的坑。
- 输入捕获测高频信号会受限：一次测量跨两个计数周期时要做溢出补偿（把中间的溢出次数乘以 (ARR+1) 加进 ΔN），否则测出来错一个周期量级；更好用的是外部时钟模式或配合从模式复位计数器，让硬件在每个上升沿自动清零 CNT，免除软件补偿。
- 高级定时器（TIM1/TIM8）的 PWM 才有死区和刹车功能，通用定时器没有——电机驱动必须用高级定时器，这也是为什么电机项目里引脚要挑对定时器外设。
- PSC 是带缓冲的：运行中改 PSC/ARR 不会立即生效，要到下一次更新事件（UEV）才装载新值；想立刻生效要手动置 UG 位，这个细节在动态调速、动态改频率的代码里很关键。

## 高频追问

1. 占空比精度不够怎么办？——拉大 ARR 重拆分频比，或者换计数模式：中心对齐模式（先上后下计数）等效频率减半但分辨率翻倍，且对电机控制谐波更友好
2. 输入捕获怎么测占空比？——同时捕获上升沿和下降沿（PWM 输入模式，从通道映射），两次差值分别是周期和脉宽，相除即占空比
3. 编码器接口模式和输入捕获什么关系？——编码器模式是定时器专用的从模式，正交编码器两路信号直接驱动 CNT 加减计数，不用软件逐沿捕获，测位置转速优先用它

## 易错点

- 两个加一漏一个——公式写成 时钟/(PSC×ARR) 直接错一个量级，面试官现场给个数字让你算就露馅；记住「PSC=0 不分频、ARR 计满自身才溢出」
- 说「PWM 频率由 CCR 决定」——CCR 只管占空比，频率只由 PSC、ARR 和时钟决定，把这两个职责说混直接暴露没配过
- 输入捕获只说「测频率」说不出「靠沿触发锁存计数值」——原理层是「外部沿 + 计数器快照」，讲不出快照这个动作就是背的
