## 题目

**题目**：USART1 默认在 PA9/PA10，但这两个脚被占了，能不能换到 PB6/PB7？

**问**：串口引脚为什么必须复用？重映射怎么配？

## 口述答案

> 因为**外设信号要经过复用器接到具体引脚**，一个 USART 只有固定的几组可选引脚（由芯片设计决定），不是任意 GPIO 都能当串口。
> 要换引脚必须开 **AFIO 时钟 + 重映射**（F1 系列），F4 之后改为"复用功能编号（AF number）"配置。

## 讲深一层

```c
// F1：重映射到 PB6/PB7
__HAL_RCC_AFIO_CLK_ENABLE();
__HAL_AFIO_REMAP_USART1_ENABLE();
// 然后把 PB6 配成复用推挽、PB7 配成浮空/上拉输入

// F4：直接指定 AF 编号
GPIO_InitStruct.Alternate = GPIO_AF7_USART1;
```

| 系列 | 配置方式 |
|---|---|
| F1 | AFIO 时钟 + `__HAL_AFIO_REMAP_xxx` |
| F4/F7 | `GPIO_InitStruct.Alternate = GPIO_AFx_xxx` |
| H7 | 同上，AF 编号查数据手册 |

**几个必须知道的点**：
1. **重映射是成组的**，不能只映射 TX 不映射 RX；
2. **原引脚会失效**（同一外设不能同时在两组引脚上）；
3. **F1 的 AFIO 时钟不开，重映射不生效**（这是最常见的"配了没用"）。

**怎么查有哪些引脚**：看芯片数据手册的 "Alternate function mapping" 表，或 CubeMX 里点引脚看可选功能。

## 高频追问

1. **重映射能随便选引脚吗？** —— 不能，只能选手册列出的那几组。
2. **开了重映射原来的脚还能用吗？** —— 作为普通 GPIO 可以，作为该外设不行。
3. **F1 忘了开 AFIO 时钟会怎样？** —— 重映射静默失效，引脚行为不变。

## 易错点

- 只在 CubeMX 里点，没检查 AFIO 时钟（F1）
- 以为任意 GPIO 都能当串口
- 只配了 TX 没配 RX 的模式
