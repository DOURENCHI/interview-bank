## 题目

**问**：建立时间和保持时间是什么？违例了会怎样？

## 口述答案

> 结论：建立时间是时钟沿到来前数据必须稳定的时长，保持时间是时钟沿后数据还要撑住的时长，两个都不能违。
> 后果不同：
> · 建立违例：数据来得太晚，这一拍采到旧值或进亚稳态，降频能救。
> · 保持违例：数据变得太早，新值追上了当前这个沿，采错且与频率无关，降频救不了。
> 方程：Tclk ≥ Tco + Tlogic + Tsu + Tskew；Th ≤ Tco + Tlogic_min − Tskew。
> 修复：建立违例靠降频、拆流水线、减少逻辑级数；保持违例只能插延迟单元或调时钟树偏斜。

## 讲深一层

```
Tco=0.5, Tlogic=6, Tsu=0.3, Tskew=0.2 ns
T ≥ 7ns → f ≤ 143MHz
保持: Tco_min+Tlogic_min = 0.4+0.1 = 0.5ns < Th=0.6ns → 违例 0.1ns
```
保持违例要插 0.1ns 以上的缓冲，且必须在所有 PVT 角复查——慢角修建立、快角修保持，两个角都得过。

## 高频追问

1. **为什么保持违例不能靠降频？** —— 违例发生在同一个时钟沿内部，数据路径太短，周期拉长反而让新数据更早追上沿。
2. **时钟偏斜对两者的影响为什么相反？** —— 时钟到得晚有利于建立（多给时间），但不利于保持（更容易被追上）。
3. **PVT 角怎么选？** —— 建立看慢角（慢管、低压、高温），保持看快角（快管、高压、低温）。

## 易错点

- 说降频能修保持违例——方向反了，越降越糟
- 把 Tsu/Th 当成与工艺无关的固定值——它们随 PVT 明显变化
- 忽略时钟偏斜的方向——偏斜对建立和保持的作用相反
