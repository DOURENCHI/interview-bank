## 题目

汇编和链接有什么区别？链接脚本主要做什么？

## 口述答案

> **汇编**是把汇编源码翻译成机器码（一条指令对一条机器指令，`as` 完成）；**链接**是把多个目标文件（.o）和库按符号表拼成一个可执行文件，解析未定义符号、重定位地址（`ld` 完成）。
> **链接脚本**（.ld）主要干三件事：①**内存布局**：定义 MEMORY 区域（FLASH/RAM 的起始地址和长度）；②**段放置**：把 .text/.data/.bss/.rodata 放到指定区域，`.data` 的初值放 Flash、运行时拷到 RAM；③**符号定义**：提供 `_sdata/_edata/_sbss/_ebss`、栈顶 `_estack`、堆起止等符号，启动代码靠它们初始化。

## 讲深一层

```ld
MEMORY { FLASH (rx): ORIGIN=0x08000000, LENGTH=512K
         RAM  (rwx): ORIGIN=0x20000000, LENGTH=128K }
SECTIONS {
  .text : { *(.isr_vector) *(.text*) } > FLASH
  .data : { _sdata = .; *(.data*) _edata = .; } > RAM AT> FLASH
  .bss  : { _sbss = .; *(.bss*) _ebss = .; } > RAM
}
```

## 高频追问

1. **启动代码怎么用这些符号？** —— 把 .data 从 Flash 拷到 RAM、把 .bss 清零，再跳 main。
2. **改链接脚本最容易错什么？** —— 段溢出（region overflow）和中断向量表没放最前（0x08000000）。

## 易错点

- 混淆汇编与编译（编译是 C→汇编/机器码）
- 以为 .bss 占 Flash（它不占，只占 RAM）
