## 题目

**题目**：用 PWM 调电机转速，同时要避免上下桥臂直通。

**问**：PWM 是什么？频率、占空比、死区各指什么？

## 口述答案

> PWM 是**用数字信号模拟模拟量**：固定周期内让高电平占一定比例，等效输出电压 = 幅值 × 占空比。
> 三个概念：**频率**（周期倒数，决定"细腻度"和噪声）、**占空比**（高电平占一个周期的比例）、**死区**（上下桥臂切换时都关断的一小段时间，防止直通短路）。

## 讲深一层

```c
// 72 MHz，PSC=71 → 1 MHz 计数；ARR=999 → 1 kHz
// CCR=300 → 占空比 30%
```
| 参数 | 影响 |
|---|---|
| 频率 | 太低会抖/啸叫，太高开关损耗大 |
| 占空比 | 决定等效电压/转速 |
| 死区 | 防直通，通常几百 ns ~ 几 μs |
- 电机驱动常用 10–20 kHz（避开人耳可听范围、兼顾开关损耗）。
- LED 调光用 1 kHz 以上避免闪烁。
- 死区由定时器的死区发生器硬件插入，不要靠软件延时。

## 高频追问

1. **为什么需要死区？** —— MOS 关断有延迟，上下管同时导通会短路烧管。
2. **频率选高有什么坏处？** —— 开关损耗和 EMI 增加。

## 易错点

- 把占空比说成"高电平时间"（要带比例）
- 死区靠软件延时实现
