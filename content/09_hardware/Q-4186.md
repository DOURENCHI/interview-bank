## 题目

**追问**：`TIM_TS_TI1FP1`、`TIM_TS_ITR0`、`TIM_TS_ETR` 这些触发源到底怎么选？

**问**：定时器的 TRGI 有哪些来源？从模式控制器怎么选？

## 口述答案

> 四类来源：**内部触发 ITR0–ITR3**（来自其他定时器）、**TI1FP1/TI2FP2**（本定时器的输入通道）、**ETR**（外部触发引脚）、以及**软件触发**（`TIM_EGR_UG`）。
> 选择依据是"**触发信号从哪来**"：测外部信号用 TI1/TI2；多个定时器级联用 ITR；外部时钟用 ETR。

## 讲深一层

| 触发源 | 来源 | 典型用途 |
|---|---|---|
| `TI1FP1` / `TI2FP2` | 本定时器通道输入 | **PWM 输入测量**、外部计数 |
| `ITR0`–`ITR3` | 其他定时器的 TRGO | 定时器级联、同步启动 |
| `ETR` | 外部触发引脚 | 外部时钟计数 |
| 软件 | `UG` 位 | 手动复位/启动 |

```c
// 定时器级联：TIM2 的 TRGO 作为 TIM3 的触发
sMasterConfig.MasterOutputTrigger = TIM_TRGO_UPDATE;   // TIM2 更新事件输出
HAL_TIMEx_MasterConfigSynchronization(&htim2, &sMasterConfig);

sSlaveConfig.InputTrigger = TIM_TS_ITR1;               // TIM3 选 ITR1（对应 TIM2）
sSlaveConfig.SlaveMode = TIM_SLAVEMODE_TRIGGER;
HAL_TIM_SlaveConfigSynchro(&htim3, &sSlaveConfig);
```

**ITR 编号要查手册**：不同定时器的 ITR0–3 对应的源不一样（比如 TIM3 的 ITR1 是 TIM2），查"Timer internal trigger connection"表。

**滤波**：外部触发信号往往有毛刺，`ICFilter` 可以设 0–15 级数字滤波，配合采样频率抑制干扰。

## 高频追问

1. **TRGO 和 TRGI 什么关系？** —— TRGO 是输出（主），TRGI 是输入（从）。
2. **能同时用多个触发源吗？** —— 不能，同一时刻只能选一个。
3. **ETR 和 TI 有什么区别？** —— ETR 是专用引脚，TI 是通道输入（可复用为捕获）。

## 易错点

- ITR 编号查错（不同定时器映射不同）
- 外部信号没开滤波，计数乱跳
- 主从模式都配了但没开 `MasterOutputTrigger`
