## 要点速览

> - 好的电源研发岗基本要研究生，本科别直接赌。
> - 单板开发的学习面 = 元器件 + 手册 + 基本电路 + PCB + 常见接口 + 芯片 + 电源基础。
> - 大厂电源面试点（小米 / 会穿）：buck / boost 拓扑、PCB 走线、上电时序、电源损耗、纹波、运放指标。
> - 推荐路径：先做单板，入职后转电源更稳。

## 展开讲讲

| 主题 | 他的说法 | 备注 |
|---|---|---|
| 电源岗门槛 | 电源研发对口研究生，本科直接投成功率低 | 与 Q-8104「高端岗位档」一致 |
| 单板学习面 | 元器件→手册→基本电路→PCB→接口→芯片→电源基础，是硬件新人主线 | 与 Q-8104 时间分配同构 |
| 电源面试点 | buck/boost 拓扑、PCB 走线（回路面积）、上电时序、损耗、纹波、运放指标——「会穿」= 这些点反复被问 | 车规电源岗（我的目标圈内）问法类似，可见 hardware 模块电源卡 |

## 对我的适用

- 我不投电源研发岗；此卡价值在于：嵌入式 / 部署岗也会被问电源基础（上电时序 / 纹波 / 拓扑名词），hardware 模块按面经频率保持即可。
- 「先做相邻岗再转目标岗」的路径思路与我的「系统集成 → SDK」偏好链同构，可作为 2027 春实习 offer 取舍时的策略参考。
- 若面试被问「会不会电源」，答法：结合 4G 测温项目的供电设计讲，不装深。
