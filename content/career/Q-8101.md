## 要点速览

> - 硬件岗两大类：研发工程师（电源 / 高速 PCB / 射频）与助理工程师（PCB Layout / 测试 / 检测 / 焊接），有条件尽量做研发。
> - EMC 不是独立岗位，只是研发的附属能力要求。
> - 薪资地板（2026 口径）：研发本科 8-15K、硕士 15-20K；助理岗 6-10K。
> - 芯片设计类岗（数字芯片 / 验证 / GPU）硕士为主，27 届总包 35-55W。

## 展开讲讲

| 主题 | 他的说法 | 备注 |
|---|---|---|
| 研发 vs 助理 | 研发工程师做电源 / 高速 PCB / 射频等核心设计；助理工程师做 PCB Layout / 测试 / 检测 / 焊接等执行类工作 | 助理岗接触面窄、天花板低 |
| 有条件尽量研发 | 研发岗积累的是设计能力，跳槽有下家；助理岗容易原地踏步 | 社区经验，非官方数据 |
| 薪资基准 | 研发本科 8-15K、硕士 15-20K；助理 6-10K | 2026 年他直播里的口径，全国平均感 |
| 芯片设计类岗 | 数字芯片 / 验证 / GPU 方向硕士起步，27 届总包 35-55W | 高薪但门槛高，与本库端侧部署方向交集小 |

## 对我的适用

- 端侧 AI 部署 / 嵌入式软件属于「研发工程师」序列，薪资基准可作 anchor：硕士 15-20K/月是硬件口下限口径，车规 SDK / 推理部署岗通常高于此。
- 芯片设计类 35-55W 总包是另一个赛道（数字前端 / 验证），与我的方向不同，仅作市场热度参考。
- 助理岗（Layout / 测试）投递价值低，与我「进研发做部署 SDK」的偏好链一致，简历投递时直接跳过。
