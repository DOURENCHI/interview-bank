# Q-8112 嵌入式五个主流方向怎么选？offer 怎么对比？

## 要点速览

> - 都叫嵌入式，干的活天差地别。有人在写驱动，有人在伺候老产品。
> - **方向 > 平台 > 薪资**，顺序别搞反。
> - 五方向：裸机（门槛低天花板低）→ RTOS+中间件（越写越值钱）→ Linux 驱动/BSP（越老越吃香）→ Linux 应用（与互联网正面竞争）→ 边缘 AI（热度最高门槛在涨）。

## 展开讲讲

| 方向 | 他的定位 | 门槛与天花板 |
| --- | --- | --- |
| 单片机/裸机开发 | 门槛最低、岗位最多，家电/消费/工控都在招 | 起点低天花板也低，要靠行业补 |
| RTOS+中间件 | 比裸机高一档，通信、汽车电子用得多 | 调度和协议栈是壁垒，越写越值钱 |
| Linux 驱动/BSP | 门槛高薪资高 | 内核要啃，越老越吃香，适合沉得住气的人 |
| Linux 应用开发 | 介于驱动和纯软件之间，写业务多 | 注意要和互联网软件岗正面竞争 |
| 边缘 AI/算法部署 | 模型落地、推理加速，热度最高 | 要补数字信号和算力知识，门槛在涨 |

| 选方向三标准 | 关键判断 |
| --- | --- |
| 行业活得久吗 | 工控、医疗、汽车产品生命周期长；风口行业起得快，裁得也快 |
| 技术栈可迁移吗 | RTOS、Linux 内核、C/C++ 到哪都认；私有平台和专有协议别押太重 |
| 有没有人带 | 第一份工作，有人带比大平台重要；没人带，三年后还在原地 |

| 看 JD 排雷 | 信号 |
| --- | --- |
| 维护为主的岗要慎重 | 改 bug、伺候老产品，学不到架构；过渡可以，别待超过一年 |
| 一人全栈要小心 | 硬件软件上位机全包，听着锻炼人，实际没人 review 你的代码 |
| 外包岗 | 简历上项目漂亮但归属存疑（原文此处被截断，大意是不利于深度积累） |

## 对我的适用

- 我的饭碗就是最后一行「边缘 AI/算法部署」——他的判断（热度最高+门槛在涨+要补算力知识）与我现有技术栈（ONNX/TensorRT/量化/Profiling）对齐；短板按他的清单是**数字信号**，我在成像链路（07_imaging）和端侧部署卡里已有部分覆盖，继续走项目路线补。
- 「方向>平台>薪资」与我的既定策略一致：端侧部署岗位池（Momenta/比亚迪/大疆系）优先于公司大小。
- RTOS+中间件是他的第二推荐——我缺车规 RTOS 实操（AUTOSAR 卡是 V2.12 面经吸收的理论卡），Momenta/车端岗位面试前把 Q-6124/Q-6126/Q-6128 串起来过一遍。
- 「有人带>大平台」对 2029 届第一份工作成立：苏州/南京的小而精团队（如禾望/影石类）优先级可以高于大厂边缘部门。
