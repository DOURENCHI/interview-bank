## 题目

**题目**：`lst = [1,1,2,3,3]; list(set(lst))` 能去重，但结果顺序变了。

**问**：set 去重的原理是什么？为什么结果无序？有什么代价？

## 口述答案

> set 是**哈希表**（和 dict 同源，只存 key），插入时算哈希定位，重复的哈希+相等就丢弃，所以去重是 O(n)。
> 无序是因为**遍历顺序由哈希值决定**，和插入顺序无关。代价是：元素必须**可哈希**（list 不行），且**丢失原始顺序**。

## 讲深一层

```python
lst = [3, 1, 2, 1]
list(set(lst))                  # 顺序不确定，常见 [1, 2, 3]

# 保序去重（3.7+ 利用 dict 有序）
list(dict.fromkeys(lst))        # [3, 1, 2]  ✅
```

| 需求 | 写法 | 复杂度 |
|---|---|---|
| 只要去重 | `set(lst)` | O(n) |
| 去重且保序 | `dict.fromkeys(lst)` | O(n) |
| 判存在 | `x in s` | O(1)（list 是 O(n)） |
| 集合运算 | `& | - ^` | O(n) |

**`in` 的性能差异最值得记住**：`x in list` 是 O(n)，`x in set` 是 O(1)。在循环里判断存在性时，把 list 换成 set 是最高性价比的优化之一。

```python
# ❌ O(n²)
for x in big_list:
    if x in another_list: ...

# ✅ O(n)
s = set(another_list)
for x in big_list:
    if x in s: ...
```

**frozenset**：不可变版本，可哈希，能当 dict key 或放进另一个 set。

## 高频追问

1. **set 能存自定义对象吗？** —— 能，需要 `__hash__` 和 `__eq__`。
2. **set 的元素顺序稳定吗？** —— 同一进程内稳定，跨进程可能不同（字符串哈希随机化）。
3. **怎么求交集并保留顺序？** —— `[x for x in a if x in set_b]`。

## 易错点

- 用 `list(set())` 去重后依赖顺序
- 在循环里用 list 做存在性判断
- 试图把 list 放进 set
