## 题目

**题目**：按第二个字段排序一个元组列表，要求相同值时保持原顺序。

**问**：Python 的排序稳定吗？`key` 函数会被调用几次？

## 口述答案

> **稳定**。Python 用 Timsort，相等元素的相对顺序不变。`key` 函数**每个元素只调用一次**（先把 key 算出来存成临时数组，再排），所以 key 里放耗时计算也不会重复执行。
> 代价是额外内存（要存 key 数组）。

## 讲深一层

```python
rows = [("b", 2), ("a", 1), ("c", 2)]
sorted(rows, key=lambda r: r[1])
# [('a', 1), ('b', 2), ('c', 2)]   ← b 在 c 前，保持原序

# 多级排序：先按第 2 字段升序，再按第 1 字段降序
sorted(rows, key=lambda r: (r[1], r[0]))
```

| 特性 | 值 |
|---|---|
| 算法 | Timsort（归并 + 插入的混合） |
| 稳定性 | ✅ 稳定 |
| 复杂度 | 最好 O(n)，平均/最坏 O(n log n) |
| key 调用次数 | **每元素 1 次** |
| 额外空间 | O(n) |

**`sorted` 和 `list.sort` 的区别**：前者返回新列表（任意可迭代对象），后者原地排序、返回 `None`。所以 `a = a.sort()` 会让 `a` 变成 `None`——高频错误。

**多级排序的技巧**：key 返回元组即可；需要"升序+降序混合"时，对数值可以取负，或用两次 `sorted`（稳定排序保证第二次不破坏第一次的顺序）。

## 高频追问

1. **怎么降序？** —— `reverse=True`，或 key 里取负。
2. **能按多个 key 不同方向排吗？** —— 数值取负；字符串可以分两次稳定排序。
3. **`sort` 里能用 `cmp` 吗？** —— Python 3 移除了 `cmp`，用 `functools.cmp_to_key` 转换。

## 易错点

- `a = a.sort()` 得到 None
- 以为排序不稳定
- 在 key 里写有副作用的函数（虽然只调一次，但语义混乱）
