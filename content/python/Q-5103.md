## 题目

**题目**：

```python
a = [1, 2, 3, 4, 5]
a[1:3]      # ?
a[::-1]     # ?
a[10:20]    # ?
b = a[:]    # b 和 a 什么关系？
```

**问**：切片返回的是拷贝还是视图？负步长和越界切片怎么处理？

## 口述答案

> Python 的切片**返回新列表（浅拷贝）**，不是视图。所以 `b = a[:]` 之后改 `b` 不影响 `a`（但元素是同一批对象，改元素内部属性会互相影响）。
> 越界切片**不报错**，会自动截断到边界。负步长表示反向，`a[::-1]` 是反转。

## 讲深一层

| 操作 | 结果 |
|---|---|
| `b = a[:]` | 新列表（浅拷贝） |
| `b = a` | 同一对象 |
| `a[1:3] = [...]` | 原地修改，长度可变 |
| `a[::-1]` | 新列表，反转 |
| `numpy` 切片 | 视图，改子数组影响原数组 |

越界规则：`start`/`stop` 超出范围会被截断到 `[0, len]`，不报错；`step=0` 才报 `ValueError`；单个索引越界才 `IndexError`。

## 高频追问

1. **为什么 `b = a[:]` 后改元素还会互相影响？** —— 浅拷贝只复制引用，元素对象仍是同一个；要彻底隔离用 `copy.deepcopy`。
2. **字符串切片也是拷贝吗？** —— Python 里返回新字符串；但由于不可变，优化上可能复用，语义上仍是新对象。
3. **切片对象能复用吗？** —— 可以，`s = slice(1, 5, 2)`，再 `a[s]`。

## 易错点

- 以为切片一定是深拷贝，改嵌套列表踩坑。
- 把负索引越界和切片越界混为一谈：`a[10]` 报错，`a[10:20]` 返回空列表。
