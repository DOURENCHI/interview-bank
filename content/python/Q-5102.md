## 题目

**题目**：

```python
a = 256;  b = 256;   a is b   # True
c = 257;  d = 257;   c is d   # False（交互式环境下）
e = [1];  f = [1];   e == f   # True
                     e is f   # False
```

**问**：`is` 和 `==` 有什么区别？为什么 256 是 True 而 257 是 False？

## 口述答案

> `==` 比较**值**，`is` 比较**是否是同一个对象**（内存地址）。
> 256 是 True 是因为 CPython 缓存了 **-5 ~ 256** 的小整数，`a` 和 `b` 指向同一个对象；257 超出范围，会新建两个对象，所以 `is` 为 False（同一代码块里编译期常量折叠可能让它变 True，这是实现细节，不能依赖）。

## 讲深一层

```python
import sys
a, b = 256, 256
a is b            # True（小整数缓存）
sys.getrefcount(a)

c, d = 257, 257
c is d            # 交互式下 False，同一 .py 文件里可能 True（常量折叠）

# 判断 None 必须用 is
if x is None: ...        # ✅
if x == None: ...        # ❌ 慢，且自定义 __eq__ 会让它返回奇怪结果
```

| 场景 | 用哪个 |
|---|---|
| 判 `None` / `True` / `False` | `is` |
| 判数值、字符串内容 | `==` |
| 判是否同一对象（缓存、单例） | `is` |
| 判浮点相等 | `math.isclose` |

**为什么 `is None` 比 `== None` 好**：`None` 是单例，`is` 是 O(1) 的地址比较；而 `==` 会调用 `__eq__`，如果对象重载了它（如 numpy 数组）会返回数组，`if` 判断直接报错。

**字符串驻留（interning）**：短标识符字符串会被复用，所以 `'abc' is 'abc'` 通常 True，但 `'a b' is 'a b'` 不一定——**永远不要用 `is` 比较字符串**。

## 高频追问

1. **numpy 数组为什么不能用 `==`？** —— 返回逐元素布尔数组，`if` 里报 `truth value is ambiguous`。
2. **`is` 能重载吗？** —— 不能，它比较地址。
3. **小整数缓存范围能改吗？** —— 不能（编译期常量），但可以自己维护缓存。

## 易错点

- 用 `is` 比较数值或字符串
- 用 `== None`
- 依赖 257 的 `is` 结果（实现细节）
