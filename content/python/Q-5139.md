## 题目

**题目**：用 PyInstaller 打一个只读 Excel 的小工具，产物 400 MB。

**问**：为什么打包体积这么大？怎么减小？

## 口述答案

> 因为 PyInstaller 会把**整个 Python 解释器 + 用到的标准库 + 所有依赖的二进制**打进去。如果环境里装了 numpy/pandas/torch，即使只 import 了一小部分，也可能被整体带上。
> 减体积靠：**干净的虚拟环境重新装**、**排除不需要的模块**、**用 onefile 之外的目录模式**、**必要时换 Nuitka**。

## 讲深一层

```bash
pyinstaller --onefile --noconfirm ^
  --exclude-module tkinter ^
  --exclude-module matplotlib ^
  --exclude-module PyQt5 ^
  app.py
```

| 体积来源 | 典型占比 | 处理 |
|---|---|---|
| Python 解释器 + 标准库 | 15–30 MB | 无法避免 |
| numpy/scipy | 50–100 MB | 用 `--exclude` 或改算法 |
| PyTorch | 500 MB–2 GB | **考虑不打包**，改服务化 |
| Qt/GUI 框架 | 50–150 MB | 排除未用的 |
| 重复的 DLL | 不定 | 清理环境重打 |

**最有效的办法：在干净 venv 里打包**。开发环境里装了几十个包，PyInstaller 会尽量都带上。

**`--onefile` 的代价**：每次启动要把自身解压到临时目录，慢且占磁盘；目录模式（onedir）启动快，但文件多。

**替代方案**：Nuitka（编译成 C，体积小、启动快、但编译慢）；或把重依赖放服务端，客户端只做轻量交互。

## 高频追问

1. **为什么 onefile 启动慢？** —— 要解压到 `%TEMP%`。
2. **能打包成单文件且快吗？** —— 用 Nuitka 或 onedir + 启动器。
3. **杀毒软件误报？** —— 常见，签名或换打包器可缓解。

## 易错点

- 在开发环境直接打包
- 打包 torch 却只用了一个小功能
- 用 onefile 做频繁启动的 CLI
