## 题目

**题目**：

```python
a = [1, 2, 2, 3, 4]
for x in a:
    if x == 2:
        a.remove(x)
print(a)      # ?
```

**问**：输出是什么？为什么？正确写法是什么？

## 口述答案

> 输出 `[1, 2, 3, 4]`——只删掉了一个 2。因为遍历时内部索引在前进，删除元素导致后面的元素整体前移，跳过了一个。
> 正确写法有三种：遍历副本、倒序遍历、或用列表推导重建。

## 讲深一层

```python
a = [1, 2, 2, 3, 4]

# ❌ 遍历中删除，漏删
for x in a:
    if x == 2: a.remove(x)        # [1, 2, 3, 4]

# ✅ 遍历副本
for x in a[:]:
    if x == 2: a.remove(x)        # [1, 3, 4]

# ✅ 倒序删（索引不受影响）
for i in range(len(a) - 1, -1, -1):
    if a[i] == 2: del a[i]

# ✅ 重建（最 Pythonic）
a = [x for x in a if x != 2]
```

| 做法 | 复杂度 | 注意 |
|---|---|---|
| 遍历副本 | O(n²) | `remove` 本身 O(n) |
| 倒序删除 | O(n²) | 同样有 remove 开销 |
| 列表推导重建 | **O(n)** | 创建新列表 |

**dict/set 更严格**：遍历中增删会直接抛 `RuntimeError: dictionary changed size during iteration`，不会静默出错。

**这个问题的本质**：**迭代器依赖容器的结构**，结构一变迭代器的内部索引就失效了。所有语言都有类似问题（Java 的 `ConcurrentModificationException`）。

## 高频追问

1. **为什么 dict 报错而 list 不报？** —— dict 有大小检查，list 只能靠索引，不检测。
2. **`while` 循环删安全吗？** —— 用 `while i < len(a)` 并手动控制 `i`，是安全的但要小心。
3. **删多个条件怎么写？** —— 列表推导最清晰。

## 易错点

- 遍历中 `remove`/`del`
- 遍历中往 list 里 append（可能死循环）
- 以为 dict 也会静默出错
