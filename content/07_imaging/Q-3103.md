## 题目

**背景**：不同 CT 机、不同扫描参数下，同一个组织的原始像素值可能不同。

**问**：HU 是什么？为什么它是可比的？

## 口述答案

> HU（Hounsfield Unit）是 CT 的**标准化衰减单位**，
> 定义是 `HU = 1000 × (μ - μ_water) / μ_water`，即相对于水的线性衰减系数。
> 所以水永远是 0 HU、空气约 -1000 HU、致密骨可到 +1000 以上。
> 它是标准化的，不同机器、不同参数下同一个组织的 HU 基本一致；
> 原始像素值只是存下来的整数，跟扫描参数有关，没法直接比。

## 讲深一层

| 物质 | 典型 HU |
|---|---|
| 空气 | -1000 |
| 肺 | -700 ~ -500 |
| 脂肪 | -100 ~ -50 |
| 水 | 0 |
| 软组织 | +20 ~ +60 |
| 骨 | +300 ~ +1500 |

文件里存的是 `stored_value`，转换成 HU：

```
HU = stored_value * RescaleSlope + RescaleIntercept
```

## 高频追问

1. **为什么水定 0？** —— 定义如此，作为基准。
2. **MRI 有 HU 吗？** —— 没有，MRI 信号强度不是标准化单位，所以 MRI 的可比性差得多。
3. **不同机器 HU 完全一致吗？** —— 基本一致，但仍有校准差异，定量研究要做体模校准。

## 易错点

- ❌ 说「HU 就是像素值」 —— 差一个 rescale
- ❌ 不同机器数据直接混用不做校验
- ✅ 记住公式和几个典型值
