## 题目

**题目**：`size` 命令看到一个可执行文件的 text/data/bss 三段，面试官问各放什么。

**问**：一个程序分为哪几个段？各放什么？

## 口述答案

> 五个主要段：**`.text`** 放机器指令（只读）；**`.rodata`** 放字符串字面量和 const 全局（只读）；**`.data`** 放已初始化的全局/静态变量；**`.bss`** 放未初始化（或初始化为 0）的全局/静态变量；此外还有**堆**和**栈**在运行时才产生。
> 关键点：`.bss` **不占可执行文件空间**，只记大小，加载时清零——这就是"未初始化的大数组不增大 exe 体积"的原因。

## 讲深一层

```c
int g1;              // .bss
int g2 = 0;          // .bss（零初始化也归 bss）
int g3 = 42;         // .data
const char* s = "hi";// 指针在 .data，"hi" 在 .rodata
static int s1;       // .bss
void f() { int x; }  // 栈
```
| 段 | 内容 | 可写 | 占文件空间 |
|---|---|---|---|
| .text | 指令 | ❌ | ✅ |
| .rodata | 常量/字面量 | ❌ | ✅ |
| .data | 已初始化全局 | ✅ | ✅ |
| .bss | 未初始化全局 | ✅ | ❌ |

## 高频追问

1. **`const` 全局变量在哪个段？** —— `.rodata`（C++ 里还有内部链接的差异）。
2. **为什么 .bss 不占文件空间？** —— 内容全是 0，加载时按大小清零即可。

## 易错点

- 以为 `int g2 = 0;` 在 .data
- 把字符串字面量说到 .data 段
