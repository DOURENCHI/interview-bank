## 题目

**题目**：

```cpp
class String {
public:
    String(int n);          // 本意是"预留 n 个字符"
};
String s = 'a';             // 编译通过！'a' 被转成 int(97)
```

**问**：`explicit` 解决什么问题？不加会怎样？哪些构造函数应该加？

## 口述答案

> 不加 `explicit` 的构造函数是**隐式转换**的入口：`'a'` 被转成 `int`，再隐式构造成 `String(97)`——得到一个长度 97 的字符串，完全不是本意。
> `explicit` 禁止这种隐式转换，要求必须显式写 `String(97)` 或 `static_cast`。
> **该加的场景**：单参数构造函数（尤其参数是数值或指针）、转换构造函数、有默认参数导致实际可单参数的构造函数。

## 讲深一层

```cpp
class String {
public:
    explicit String(int n);          // ✅ 禁止隐式
    String(const char* s);           // 这个可以不加（从字面量构造是自然的）
};

String s1(97);                           // ✅ 显式
// String s2 = 97;                       // ❌ 被禁止
void f(String);
// f(97);                                // ❌ 被禁止
```

| 情况 | 建议 |
|---|---|
| `explicit T(int)` | ✅ 加 |
| `explicit T(T*)` | ✅ 加（防 nullptr 意外转换） |
| `explicit operator bool()` | ✅ 加（允许 `if (x)`，禁止 `int n = x`） |
| 拷贝/移动构造 | 不加（`T b = a` 是自然的） |
| `initializer_list` 构造 | 一般不加 |

**C++11 起 `explicit` 还能用于转换运算符**：`explicit operator bool()` 让 `if (obj)` 可用但禁止 `int n = obj;`。

**标准库的例子**：`std::vector<int> v(10)`（10 个元素）和 `v{10}`（一个元素 10）的区别，就是 `explicit` 与 `initializer_list` 优先级共同作用的结果。

## 高频追问

1. **`explicit` 影响拷贝初始化吗？** —— 影响，`T b = x;` 被禁止，但 `T b(x);` 可以。
2. **能对多参数构造用吗？** —— C++11 起可以，用于禁止花括号隐式转换。
3. **为什么 `vector<int> v = 10;` 不合法？** —— 因为 `vector(size_type)` 是 `explicit` 的。

## 易错点

- 单参数构造不加 `explicit`，产生意外转换
- 以为 `explicit` 会禁止直接初始化
- 忘了 `explicit operator bool`
