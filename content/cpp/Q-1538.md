## 题目

如何让一个线程绑定在一个 CPU 核心上，使得该核心一直运行这个线程？

## 口述答案

> 用 `pthread_setaffinity_np`（线程级）或 `sched_setaffinity`（进程级）设置 CPU 亲和掩码，命令行用 `taskset -c 4 ./app`。
> 注意"绑核 ≠ 独占"：只保证只在该核被调度，其他任务/中断仍可能抢。要独占需配合 `isolcpus` 隔离核、把中断亲和迁走（`/proc/irq/*/smp_affinity`）、关 SMT 兄弟核。

## 讲深一层

| API | 粒度 | 备注 |
|---|---|---|
| pthread_setaffinity_np | 线程 | 常用 |
| sched_setaffinity | 进程 | 会影响所有线程 |
| taskset -c N | 进程/线程 | 不改代码 |

独占核还需 isolcpus + 中断迁移。

## 高频追问

1. **绑核一定提升性能吗？** —— 有缓存局部性收益，但负载不均时可能饿死某核，要先测基线。

## 易错点

- 混淆线程级与进程级 API
- 以为绑核就独占
