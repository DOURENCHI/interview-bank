## 题目

**场景**：`obj.setX(1).setY(2).setZ(3);` 这种链式调用是怎么实现的？`this` 到底是什么？

**问**：`this` 指针是什么？为什么静态成员函数没有 `this`？链式调用的返回类型该怎么写？

## 口述答案

> `this` 是**指向当前对象的指针**，在非静态成员函数里隐式存在，类型是 `T*`（`const` 成员函数里是 `const T*`）。
> 静态成员函数不属于任何对象，没有 `this`。链式调用要返回 `T&`（引用），返回 `T` 会产生拷贝、返回 `T*` 就得用 `->`。

## 讲深一层

```cpp
class Builder {
    int x_ = 0, y_ = 0;
public:
    Builder& setX(int v) { x_ = v; return *this; }   // ✅ 返回引用
    Builder& setY(int v) { y_ = v; return *this; }
    int sum() const { return x_ + y_; }
};

Builder().setX(1).setY(2).sum();   // 链式调用
```

| 返回类型 | 链式调用 | 代价 |
|---|---|---|
| `T&` | ✅ | 无拷贝（**推荐**） |
| `T` | ✅ | 每次一次拷贝 |
| `T*` | 需要 `->` | 无拷贝但语法别扭 |
| `const T&` | 只能调 const 方法 | 限制后续修改 |

**`this` 的三种用法**：
1. 区分同名成员和参数：`this->x = x;`
2. 返回自身：`return *this;`
3. 删除 `this`（极少用，如引用计数归零时自删，非常危险）。

**`delete this` 的风险**：对象被删后，调用方可能还在用；且必须是 `new` 出来的对象。

## 高频追问

1. **`this` 能修改吗？** —— 不能，它是右值（C++ 里 `this` 不可赋值）。
2. **`const` 成员函数里 `this` 是什么类型？** —— `const T*`，所以不能修改成员变量。
3. **静态成员函数能访问非静态成员吗？** —— 不能，没有 `this` 就没有对象上下文。

## 易错点

- 链式调用返回 `T`，产生多余拷贝
- 在静态函数里用 `this`
- `delete this` 后继续访问成员
