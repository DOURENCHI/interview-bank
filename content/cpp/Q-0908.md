## 题目

**题目**：

```cpp
struct S { char c; int i; };   // sizeof = ?
union  U { char c; int i; };   // sizeof = ?
```

**问**：`struct` 和 `union` 有什么区别？共用体的大小怎么算？

## 口述答案

> `struct` 的成员**各占独立地址**，总大小是各成员之和再加对齐填充（上面是 8）。`union` 的成员**共用同一块内存**，大小是**最大成员的大小**，再按最大对齐数补齐（上面是 4）。
> 一句话：struct 是"加法 + 对齐"，union 是"取最大 + 对齐"。

## 讲深一层

- 用途差别很大：struct 表达"同时拥有"，union 表达"同一时刻只有一种"，常用于**协议解析**（同一段字节按不同格式解释）和**节省内存**。
- C++11 起 union 可以含非平凡成员（如 `std::string`），但**必须手动调用构造/析构**，否则是未定义行为。
- union 也是"类型双关"的合法写法（C++ 里比 `reinterpret_cast` 更明确），但读非活跃成员仍是 UB（C 允许，C++ 严格说不行）。
- `sizeof(union)` 一定 ≥ 最大成员，且是最大对齐数的整数倍。

## 高频追问

1. **union 里放 `std::string` 会怎样？** —— 能编过，但换成员前必须显式析构再构造。
2. **怎么判断当前 union 是哪个成员？** —— 需要额外的 tag 字段（叫 tagged union），或用 `std::variant`。

## 易错点

- 以为 union 大小是成员之和
- 读了 union 里"非最后写入"的成员（UB）
