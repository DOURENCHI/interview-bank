## 题目

**场景**：新手写 `cout << "hi";` 报 `cout was not declared`，加了 `using namespace std;` 就好了，但不知道为什么。

**问**：`cin` / `cout` 属于哪个命名空间？为什么标准库要引入命名空间这一层？

## 口述答案

> 属于 `std`。它们是 `std::ostream` / `std::istream` 的全局实例，定义在 `<iostream>` 里。
> 命名空间是为了**避免名字冲突**：标准库有 `sort`、`count`、`distance`，你的代码里也常有同名函数。没有命名空间时，一 `#include` 就会冲突；有了之后，`std::sort` 和 `mysort` 互不干扰。

## 讲深一层

```cpp
#include <iostream>

int main() {
    std::cout << "hi" << std::endl;        // 显式限定，最安全
    using std::cout;                       // 只引入一个名字
    cout << "hi\n";
}
```

| 写法 | 作用域 | 建议 |
|---|---|---|
| `std::cout` | 这一处 | ✅ 首选 |
| `using std::cout;` | 当前作用域 | ✅ 局部用 |
| `using namespace std;` | 整个作用域 | ⚠️ 只在 `.cpp` 里用 |
| 头文件里 `using namespace std;` | 传染所有包含者 | ❌ 禁止 |

**为什么头文件里禁止**：`#include` 是文本插入，头文件里的 `using` 会污染所有包含它的文件，可能让别人的 `count` 变成 `std::count`，产生极难排查的错误。

**`endl` 和 `'\n'` 的区别**：`endl` 除了换行还会 `flush`，频繁使用会显著拖慢输出；`'\n'` 只换行。

## 高频追问

1. **`cout` 是对象还是函数？** —— 是对象（`std::ostream` 的实例），`<<` 是重载的运算符。
2. **为什么 `<<` 能链式调用？** —— 它返回流的引用 `ostream&`，所以能继续 `<<`。
3. **`printf` 和 `cout` 能混用吗？** —— 能，但默认同步会拖慢 `cout`；设 `ios::sync_with_stdio(false)` 后不能混用。

## 易错点

- 在头文件里 `using namespace std;`
- 用 `endl` 刷输出导致超时
- 以为 `cout` 是函数，写成 `cout("hi")`
