## 题目

**追问**：`cout << obj` 里的 `<<`，为什么不能写成 `obj.operator<<(cout)`？

**问**：`operator<<` 为什么通常写成非成员函数？写成成员函数会怎样？

## 口述答案

> 因为**左操作数是 `cout`**，不是你的类。成员函数的隐含第一参数是 `this`（本类对象），而这里左边是 `std::ostream`，语法上根本表达不出来。
> 所以只能写成非成员函数（自由函数或 `friend`），参数顺序是 `(ostream&, const T&)`。

## 讲深一层

```cpp
struct Point { int x, y; };

// ✅ 非成员
std::ostream& operator<<(std::ostream& os, const Point& p) {
    return os << '(' << p.x << ',' << p.y << ')';
}

// ✅ 需要访问私有成员时才用 friend
class Secret {
    int v_ = 1;
    friend std::ostream& operator<<(std::ostream&, const Secret&);
};

// ❌ 成员函数，左操作数成了 Point
struct Bad { std::ostream& operator<<(std::ostream& os) const; };
// 只能写成 p << cout，没人这么用
```

| 运算符 | 建议写法 | 原因 |
|---|---|---|
| `<<` `>>` | 非成员（`friend`） | 左操作数是流 |
| `+` `-` `*` | 非成员（基于 `+=`） | 允许左操作数隐式转换 |
| `+=` `-=` | 成员 | 要修改自身 |
| `==` `<=>` | 非成员 | 两侧对称 |
| `[]` `()` `->` | **必须**成员 | 语言规定 |

**一条经验**：需要"两侧对称"或"左操作数不是本类"的运算符，写成非成员；需要修改自身状态的，写成成员。

## 高频追问

1. **非成员怎么访问私有成员？** —— 声明为 `friend`，或提供公有 getter。
2. **`operator==` 为什么也推荐非成员？** —— 让 `1 == obj` 也能工作（如果允许隐式转换）。
3. **`friend` 会破坏封装吗？** —— 削弱，但它把授权显式写在类里，可控。

## 易错点

- 把 `operator<<` 写成成员函数
- 返回 `ostream` 而不是 `ostream&`，产生拷贝
- 忘记 `return os`，链式调用断掉
