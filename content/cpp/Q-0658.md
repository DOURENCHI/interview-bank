## 题目

**场景**：`template<typename T> struct Printer;` 对 `int` 要有特殊实现，对 `T*` 要有另一套。

**问**：全特化和偏特化有什么区别？各解决什么问题？

## 口述答案

> **全特化**是把所有模板参数都指定为具体类型（`Printer<int>`），相当于给某个具体类型写专门实现。**偏特化**只指定部分参数或加约束（`Printer<T*>`），仍然是模板，只是匹配范围更窄。
> 只有**类模板**支持偏特化，函数模板只能全特化——这也是为什么实践中建议用重载代替函数模板特化。

## 讲深一层

```cpp
template <typename T> struct Printer {          // 主模板
    static void print() { cout << "generic"; }
};
template <> struct Printer<int> {               // 全特化
    static void print() { cout << "int"; }
};
template <typename T> struct Printer<T*> {      // 偏特化：指针
    static void print() { cout << "pointer"; }
};

Printer<double>::print();   // generic
Printer<int>::print();      // int
Printer<char*>::print();    // pointer
```

| 类型 | 全特化 | 偏特化 |
|---|---|---|
| 类模板 | ✅ | ✅ |
| 函数模板 | ✅ | ❌ |

**匹配优先级**：全特化 > 偏特化 > 主模板。多个偏特化都匹配时，选"更特化"的那个；无法比较则报歧义。

**典型用途**：`std::hash` 对不同类型的特化、`std::tuple_size`、类型萃取（`is_pointer`）。

## 高频追问

1. **函数模板为什么不能偏特化？** —— 语言规则限制；用重载或 `if constexpr`（C++17）替代。
2. **偏特化能匹配"任意容器"吗？** —— 不能直接匹配，需要 `template<typename T> struct X<std::vector<T>>` 逐个写。
3. **`if constexpr` 能替代特化吗？** —— 多数场景能，代码更集中，但会导致所有分支都要能编译。

## 易错点

- 试图偏特化函数模板（编译不过）
- 多个偏特化冲突，报歧义
- 特化写在不同的头文件里，导致 ODR 问题
