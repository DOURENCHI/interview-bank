## 题目

**场景**：`std::hash<T>` 对自定义类型不能用；`std::is_pointer<T>` 需要区分 `T` 和 `T*`。

**问**：模板特化解决什么问题？全特化和偏特化各怎么写？

## 口述答案

> 特化让你**为特定类型提供不同实现**，而不改变调用方式。全特化指定所有参数（`Printer<int>`），偏特化只指定部分或加约束（`Printer<T*>`）。
> 语义上它解决的是"**大部分情况用通用实现，少数情况需要特殊处理**"，比如 `vector<bool>` 就是 `vector<T>` 的全特化（按位存储）。

## 讲深一层

```cpp
template <typename T> struct TypeName { static const char* get() { return "unknown"; } };
template <> struct TypeName<int>    { static const char* get() { return "int"; } };     // 全特化
template <typename T> struct TypeName<T*> { static const char* get() { return "pointer"; } }; // 偏特化
template <typename T> struct TypeName<std::vector<T>> { static const char* get() { return "vector"; } };

TypeName<int>::get();        // "int"
TypeName<char*>::get();      // "pointer"
TypeName<std::vector<int>>::get();  // "vector"
```

| 类型 | 全特化 | 偏特化 |
|---|---|---|
| 类模板 | ✅ | ✅ |
| 函数模板 | ✅ | ❌（用重载代替） |
| 变量模板 | ✅ | ✅ |

**匹配优先级**：全特化 > 偏特化 > 主模板。多个偏特化都匹配时选"更特化"的，无法比较则报歧义。

**标准库里的例子**：`std::vector<bool>`（位压缩）、`std::hash` 对整型的特化、`std::tuple_size`、`std::is_integral`。

## 高频追问

1. **为什么函数模板不能偏特化？** —— 语言规则；用重载或 `if constexpr`（C++17）替代。
2. **特化必须写在同一个命名空间吗？** —— 必须，否则是未定义行为（ODR 违反）。
3. **`if constexpr` 能替代偏特化吗？** —— 多数场景能，但要求所有分支都能编译。

## 易错点

- 在不同头文件里写同一个特化，ODR 冲突
- 试图偏特化函数模板
- 特化写错签名，静默没生效
