## 题目

**题目**：`std::find` 只能按值找，想按条件找（比如"第一个大于 10 的元素"）就要用 `std::find_if`。

**问**：两者的区别是什么？谓词该怎么写？找不到时返回什么？

## 口述答案

> `find` 是**按值相等**查找（内部用 `==`），`find_if` 是**按条件**查找（内部调谓词）。都返回迭代器，找不到返回 `last`（通常是 `end()`）。
> 判断是否找到必须用 `if (it != v.end())`，不能解引用后再判断——`*end()` 是未定义行为。

## 讲深一层

```cpp
auto it1 = std::find(v.begin(), v.end(), 42);              // 按值
auto it2 = std::find_if(v.begin(), v.end(),
                        [](int x) { return x > 10; });     // 按条件

if (it2 != v.end()) {
    std::cout << *it2 << " at " << (it2 - v.begin());
}
```

| 算法 | 条件 | 返回值 |
|---|---|---|
| `find` | `*it == value` | 迭代器或 `last` |
| `find_if` | `pred(*it)` | 迭代器或 `last` |
| `find_if_not` | `!pred(*it)` | 迭代器或 `last` |
| `count` / `count_if` | 同上 | 个数 |
| `any_of` / `all_of` / `none_of` | 谓词 | `bool` |

**这是"开头算法家族"的通用约定**：所有 `_if` 后缀的算法都接收谓词，没后缀的接收值。

**性能提醒**：`find_if` 是**线性扫描**，O(n)。在有序区间里应该用 `lower_bound` / `binary_search`（O(log n)）。

## 高频追问

1. **`find` 对 `set` / `map` 有效率吗？** —— `find` 是线性的；应该用容器自己的 `find()` 成员（O(log n)）。
2. **谓词能捕获局部变量吗？** —— 能，lambda 捕获；注意生命周期。
3. **找不到时能返回 `-1` 吗？** —— 不能，迭代器不是整数；要下标就 `std::distance(begin, it)`。

## 易错点

- 解引用 `end()` 判断是否找到
- 有序区间还用 `find_if`（应该 `lower_bound`）
- 对 `set` 调 `std::find` 而不是成员 `find`
