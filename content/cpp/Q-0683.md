## 题目

**题目**：`std::set_intersection(a.begin(), a.end(), b.begin(), b.end(), out)` 在未排序的 `vector` 上返回了错误结果。

**问**：为什么要求两个区间都有序？输出是什么顺序？复杂度是多少？

## 口述答案

> 因为它用的是**归并式双指针扫描**：两个指针各自前进，比较当前元素，相等就输出、两边都前进，不等就移动较小的那边。这个逻辑只有在**有序**时才能保证不漏掉交集元素。
> 输出天然有序（因为是按顺序扫描出来的），复杂度 O(n+m)。

## 讲深一层

```cpp
std::vector<int> a{1,2,3,4}, b{3,4,5};
std::sort(a.begin(), a.end());       // 必须有序
std::sort(b.begin(), b.end());
std::vector<int> out;
std::set_intersection(a.begin(), a.end(), b.begin(), b.end(),
                      std::back_inserter(out));   // {3,4}
```

```cpp
// 内部逻辑（简化）
while (first1 != last1 && first2 != last2) {
    if (*first1 < *first2) ++first1;
    else if (*first2 < *first1) ++first2;
    else { *d_first++ = *first1; ++first1; ++first2; }
}
```

| 算法 | 输入要求 | 输出 | 重复元素 |
|---|---|---|---|
| `set_intersection` | 有序 | 有序 | 取较少的次数 |
| `set_union` | 有序 | 有序 | 取较多的次数 |
| `set_difference` | 有序 | 有序 | 差集 |
| `merge` | 有序 | 有序 | 全部保留 |

**输出容量**：`set_intersection` 不自己扩容，目标区间必须够大，或者用 `back_inserter`。

**为什么不用 `std::set`**：`set_intersection` 对**任意有序区间**都有效（`vector`、数组、`list`），不要求容器是 `set`。

## 高频追问

1. **怎么去重？** —— 先 `sort` 再 `unique` + `erase`，或直接用 `set`。
2. **能用自定义比较吗？** —— 能，最后一个参数传比较器，两边必须用同一个。
3. **未排序时怎么办？** —— 先排序（O(n log n)），或用哈希集合（O(n) 但需要额外空间）。

## 易错点

- 输入未排序就调 `set_intersection`
- 目标区间容量不足（越界写）
- 两个区间用了不同的比较器
