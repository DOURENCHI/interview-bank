## 题目

**题目**：

```cpp
int i = 0;
int a = i++;   // ?
int b = ++i;   // ?
```

**问**：前置自增和后置自增有什么区别？哪个更快？

## 口述答案

> `i++` 返回**自增前的旧值**（要先存一份副本），`++i` 返回**自增后的引用**。
> 对 `int` 这种内置类型，编译器优化后两者一样快；但对**迭代器、自定义类型**，后置版本要构造一个临时对象返回，前置版本直接返回 `*this` 的引用——所以泛型代码里习惯写 `++it`。

## 讲深一层

```cpp
struct It {
    It& operator++()    { p_ += 1; return *this; }          // 前置：返回引用
    It  operator++(int) { It t = *this; ++*this; return t; } // 后置：返回副本
};
```
- 后置版本的 `int` 参数只是用来区分重载的哑元，不参与运算。
- 后置版本无法避免一次拷贝（返回值语义要求）。
- 老式 for 循环写 `i++` 无妨，但 C++ 代码规范一般统一写 `++i`。

## 高频追问

1. **为什么后置要一个 `int` 参数？** —— 为了让 `++obj` 和 `obj++` 能重载成两个不同函数。
2. **`i = i++` 是什么结果？** —— C++17 前是未定义行为，C++17 起先自增再赋值，得到自增后的值。

## 易错点

- 说"后置一定更慢"（内置类型一样快）
- 在自定义迭代器上大量用 `it++`，白白多一次拷贝
