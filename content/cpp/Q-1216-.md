## 题目

**背景**：写链表删除函数时想直接改头指针，面试官问指针的指针用在哪。
**问**：二级指针什么时候用？举个实际场景。

## 口述答案

> 核心场景只有一个：**要在函数里修改"指针本身"**。传一级指针只能改指针指向的内容，改不了调用方的指针变量；传二级指针才能把调用方那个指针改掉。经典例子是链表头删除：`void pop_head(Node **head)` 里 `*head = (*head)->next;`，调用方的头指针真的移动了。主函数的 `argv`、`envp` 也是二级指针——指向"指针数组"。其他常见场合：函数需要返回"一组指针"（比如数组分配成功后回填各元素地址）、C 语言里实现句柄表（句柄→对象指针的表）。C++ 里多数场景可以拿"指针的引用"或返回值替代，但 C 和内核代码里二级指针是标准写法。

## 讲深一层

```c
// 头删：必须二级指针，否则改的是副本
void pop_head(Node **head) {
    Node *n = *head;
    *head = n->next;
    free(n);
}
```
- malloc 失败置空的习惯写法 `safe_free(&p)` 也是同理：要改 p 本身

## 高频追问

1. 用返回值返回新 head 有什么区别？——语义更清晰，但"原地修改多个指针"时就不够了
2. 三级指针什么时候见？——要改"指针数组里的某个指针"时（少见）

## 易错点

- 传一级指针试图改头指针——函数返回后调用方原地不动
- 把二级指针和"指针数组"混为一谈：`int **` 与 `int *arr[10]` 兼容但含义不同
