## 题目

**题目**：面试官问"`const` 和 `static` 各有什么用"，很多人只答得出 const 是常量。

**问**：`const` 和 `static` 各自的作用是什么？

## 口述答案

> **`const`** 是"只读承诺"：修饰变量（不可改）、修饰指针（锁内容还是锁指针，看位置）、修饰成员函数（不修改成员）、修饰参数/返回值（承诺不改）。
> **`static`** 有三处完全不同的语义：**局部静态变量**（生命周期延长到程序结束，只初始化一次）、**文件作用域的 static**（内部链接，只本编译单元可见）、**类的静态成员**（属于类不属于对象，所有实例共享）。

## 讲深一层

| 位置 | static 的含义 |
|---|---|
| 函数内局部变量 | 静态存储期，只初始化一次 |
| 全局变量/函数 | 内部链接，仅本文件可见 |
| 类成员变量 | 全类共享，需类外定义（C++17 可 `inline static`） |
| 类成员函数 | 无 `this`，不能访问非静态成员 |
- 局部静态的线程安全初始化由 C++11 保证（magic static），但之后的多线程读写仍需同步。
- `static` 成员函数常用于工厂函数、工具函数。
- `const` 成员函数里 `this` 是 `const T*`，所以不能改成员（`mutable` 除外）。

## 高频追问

1. **`static` 局部变量线程安全吗？** —— 初始化安全，后续访问不安全。
2. **`const` 成员函数能改成员吗？** —— 只能改 `mutable` 成员。

## 易错点

- 只说"static 是静态的"
- 忘了类静态成员要在类外定义
