## 题目

**题目**：`int a[5]; int* p = a;` 之后 `a[2]`、`*(a+2)`、`*(p+2)`、`p[2]` 结果都一样。

**问**：数组名什么时候会退化成指针？`a[i]` 和 `*(a+i)` 为什么等价？

## 口述答案

> 数组名在大多数表达式里会**隐式转换**成指向首元素的指针，所以 `a` 等价于 `&a[0]`。而 `a[i]` 在语言层面就定义为 `*(a+i)`，所以四种写法天然等价。
> **不退化的三种情况**：`sizeof(a)`、`&a`、以及用引用绑定数组（`int (&r)[5] = a;`）。

## 讲深一层

```cpp
int a[5];
sizeof(a);        // 20（整个数组），不退化
&a;               // int(*)[5]，指向数组的指针，类型不同
int (&r)[5] = a;  // 引用绑定，不退化
int* p = a;       // 退化成 int*
```

| 表达式 | 类型 | 值 |
|---|---|---|
| `a` | `int[5]` → `int*` | 首元素地址 |
| `&a` | `int(*)[5]` | 数组整体地址（值相同，类型不同） |
| `&a[0]` | `int*` | 首元素地址 |
| `a + 1` | `int*` | 第二个元素地址 |

**`&a` 和 `&a[0]` 值相同但类型不同**：`&a + 1` 会跳过整个数组（20 字节），`&a[0] + 1` 只跳 4 字节。这是面试常挖的点。

**为什么 `a[i] == *(a+i)` 还引出 `i[a]`**：因为加法可交换，`*(a+i)` 和 `*(i+a)` 等价，所以 `2[a]` 也合法——只是没人这么写。

## 高频追问

1. **数组作为函数参数会怎样？** —— 退化成指针，`sizeof` 得到指针大小，所以必须额外传长度。
2. **怎么在函数里拿到数组长度？** —— 用模板 `template<size_t N> void f(int (&a)[N])`，或 `std::array`。
3. **二维数组怎么退化？** —— `int a[3][4]` 退化成 `int(*)[4]`，第二维不能省。

## 易错点

- 函数里 `sizeof(arr)` 当长度用
- 混淆 `&a` 和 `&a[0]` 的类型
- 二维数组传参写成 `int**`
