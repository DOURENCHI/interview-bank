## 题目

**题目**：做一个计算器，需要把 `3+4*2-(1+5)` 转成后缀表达式再求值。

**问**：中缀转后缀（调度场算法）的思路是什么？括号和优先级怎么处理？

## 口述答案

> 用**一个操作数输出队列 + 一个运算符栈**：遇到数字直接输出；遇到运算符时，把栈里**优先级不低于它**的运算符全部弹出输出，再把自己压栈；遇到 `(` 压栈；遇到 `)` 一直弹到 `(` 为止。
> 核心规则就一条：**栈里等待的运算符，只有在遇到更低优先级时才轮到它输出**。

## 讲深一层

```cpp
int prec(char op) {
    if (op == '+' || op == '-') return 1;
    if (op == '*' || op == '/') return 2;
    return 0;
}

std::string toRPN(const std::string& s) {
    std::string out;
    std::stack<char> ops;
    for (char c : s) {
        if (isdigit(c)) out += c;
        else if (c == '(') ops.push(c);
        else if (c == ')') {
            while (!ops.empty() && ops.top() != '(') { out += ops.top(); ops.pop(); }
            ops.pop();                       // 弹出 '('
        } else {
            while (!ops.empty() && prec(ops.top()) >= prec(c)) { out += ops.top(); ops.pop(); }
            ops.push(c);
        }
    }
    while (!ops.empty()) { out += ops.top(); ops.pop(); }
    return out;
}
```

`3+4*2-(1+5)` → `342*+15+-`

| 输入 | 动作 | 输出 | 栈 |
|---|---|---|---|
| `3` | 数字 | 3 | |
| `+` | 压栈 | 3 | + |
| `4` | 数字 | 34 | + |
| `*` | 优先级高，压栈 | 34 | +* |
| `2` | 数字 | 342 | +* |
| `-` | 弹出 `*`、`+` | 342*+ | - |
| `(` | 压栈 | 342*+ | -( |
| ... | | | |

**求值时**：遇数字压栈，遇运算符弹两个数计算再压回。

**右结合运算符（如 `^`）**：弹出条件要改成 `>` 而不是 `>=`，否则 `2^3^2` 会算错。

## 高频追问

1. **为什么用栈？** —— 括号嵌套和优先级都是"后进先出"的匹配关系。
2. **能直接求值不转后缀吗？** —— 能，用两个栈（数字栈 + 符号栈）一次扫描。
3. **怎么支持多位数？** —— 数字要连续读，读到非数字才结束。

## 易错点

- `)` 时忘了弹出左括号
- 右结合运算符用了 `>=`
- 多位数被拆成单字符
