## 题目

**背景**：字节抖音电商 AI Agent 开发一面的第四问，后训练方向的对比题。库内 Q-4682 已从「GRPO Loss 怎么设置」角度覆盖实现细节（组内归一化、省 critic、k3 KL），本题从「奖励归因 + critic 区别」的对比角度作答，两卡互补：这题答的是「为什么 GRPO 能去掉 critic、两种算法的信用分配机制差在哪」。
**问**：GRPO 和 PPO 的奖励归因、critic 有什么区别？

## 口述答案

> 从 PPO 说起。PPO 是 actor-critic 架构：策略网络（actor）之外还要训一个价值网络（critic）估计状态价值 V(s)，每个 token 位置的 advantage 用 GAE(λ) 从 TD 残差递推算出来——advantage 描述「这个动作比平均预期好多少」。奖励归因走的是 critic 的逐状态估计：序列里每个 token 都有自己的 advantage，信用分配到 token 级。代价是 critic 本身要训准（价值损失 + 策略损失联合优化），critic 与策略同规模时显存和训练复杂度接近翻倍，而且 LLM 场景下 critic 的估计对象是整条序列的价值，本来就不容易估准。
> GRPO 把这套东西换掉了：同一个 prompt 采样 G 个回答，每个回答拿一个序列级 reward（规则判分或 reward model 打分），然后 advantage = (r_i − 组内均值) / 组内标准差——组内均值当 baseline，完全不用 critic。奖励归因从「critic 逐 token 估计」变成「组内相对比较」：比同组平均好的回答 advantage 为正、差的为负，序列级 reward 广播到该序列的全部 token。
> 三点区别归纳：一是 baseline 来源——PPO 用学出来的价值网络（要训练、可能不准），GRPO 用组内均值（免训练，但要求同一 prompt 可并行采样多次且 reward 可比）；二是归因粒度——PPO 是 token 级 GAE，过程奖励可以自然接入，GRPO 天然是序列级，要逐 token 信用分配得额外接过程奖励模型 PRM；三是开销与稳定性——GRPO 省 critic 的显存和训练，但采样开销乘 G 倍，且组内 reward 全相同（全对/全错）时标准差为 0、advantage 全 0、这组没梯度，要过滤或加 eps。
> 为什么 LLM/Agent 后训练里 GRPO 成了主流：LLM 的 reward 天然是序列级（答案对不对、格式合规不合规），没有可靠的逐 token 监督信号；序列级价值让 critic 很难训准，PPO 的优势发挥不出来。GRPO 用「组内比较」绕开了「学 baseline」这个最难的环节——reward 本身就是自己的对照组。

## 讲深一层

- reward 是什么、critic 估什么的区别：reward 是环境给的真值信号（每条序列一个），critic 是对「未来累计奖励」的学习估计——PPO 的 advantage 本质是「真值信号 − 学习估计」的残差组合，GRPO 干脆用组内均值这个统计量代替了「学习估计」。
- 与 RLOO 的亲缘：GRPO 的组均值 baseline 和 RLOO 的 leave-one-out baseline 同族，都是「用同一 prompt 的多次采样互为对照」，reinforce-with-baseline 这一支的工程化形态。
- 过程奖励的补法：GRPO 要 token 级信用分配，通常接 PRM 给逐步打分再加权——这正是「序列级 RLVR + 过程奖励」两条线的结合处，Agent 任务里多步工具调用的归因就靠这个。
- KL 约束两边都有但角色不同：PPO 的 KL 是防策略崩的训练稳定性手段，GRPO 的 β·KL(k3) 是锚定参考模型防 reward hacking——Q-4662 的 reward hacking 治理正好衔接。

## 高频追问

1. GRPO 的 advantage 为什么除以组内标准差？——组间 reward 尺度差异大，归一化让不同 prompt 的梯度量级一致，等价于一个自适应的学习率
2. 全对/全错的组怎么处理？——标准差为 0、advantage 全 0 无梯度，过滤掉或加小量 eps；采样策略上尽量让组内有多样性
3. critic 真的一无是处吗？——不是：需要 token 级信用分配（长序列多步任务）时 GAE+critic 仍有优势，PPO 在过程奖励充分的场景没有过时
4. 采样次数 G 怎么权衡？——G 大则 baseline 估计稳但算力翻倍，常见 4~16；太小的组均值方差大，等价于噪声 baseline

## 易错点

- 说「GRPO 就是把 PPO 的 critic 删了」就停——删掉 critic 后 baseline 换成了组内均值、归因粒度从 token 级变序列级，这两条后果才是对比的实质
- 把 reward 和 critic 混为一谈——reward 是环境真值，critic 是学习的估计，概念混了整题崩
- 忘了 GRPO 的代价——采样 ×G、全同 reward 组无梯度、序列级归因丢过程信用，只吹优点像没用过
- 说出「token 级 advantage」却讲不清 GAE——追问「GAE 的 λ 是干什么的」直接挂，至少要说 TD 残差的指数加权
