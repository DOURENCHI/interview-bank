## 题目

**场景**：函数参数用指针还是引用？成员变量用指针还是对象？面试官常顺着问"那引用到底是什么"。

**问**：指针和引用有什么区别？各自适合什么场景？

## 口述答案

> 四点区别：**引用必须初始化且不能换绑**，指针可以为空、可以改指向；**引用没有独立的地址语义**（`&r` 取的是被引用对象的地址），指针本身有地址；**引用不占额外空间**（实现上通常是别名），指针是一个变量；**没有引用的引用、没有引用的数组**。
> 场景上：函数参数想"必须传且不为空"用引用；需要表达"可能没有"、需要改指向、需要做链表节点，用指针。

## 讲深一层

| 维度 | 指针 `T*` | 引用 `T&` |
|---|---|---|
| 能否为空 | 能 | 不能（合法引用必须绑定对象） |
| 能否换绑 | 能 | 不能 |
| 是否占空间 | 占（一个地址大小） | 通常不占（编译期别名） |
| 算术运算 | 支持 | 不支持 |
| 多级 | `T**` | 无 `T&&&`（`&&` 是右值引用） |
| 数组 | `T* arr[]` | 无引用数组 |

```cpp
void byRef(int& x)  { x = 1; }        // 必须传有效对象，会改到调用方
void byPtr(int* x)  { if (x) *x = 1; } // 可为 nullptr，调用方需检查
```

**为什么引用"通常不占空间"**：它在语言层面是别名，编译器直接操作原对象；但如果引用作为类成员或需要运行时绑定（如函数参数通过寄存器传递不了），实现上仍会用指针。

## 高频追问

1. **引用能返回吗？** —— 能，但不能返回局部变量的引用（悬垂）。
2. **`const T&` 能绑定临时量吗？** —— 能，生命周期延长到引用作用域结束；`T&` 不能绑定临时量。
3. **引用做成员变量要注意什么？** —— 必须在初始化列表绑定，且类不可赋值（赋值运算符被删除）。

## 易错点

- 说"引用就是指针的语法糖"，忽略不能换绑这个本质区别
- 返回局部变量的引用
- 用引用表达"可能为空"，导致调用方无从判断
