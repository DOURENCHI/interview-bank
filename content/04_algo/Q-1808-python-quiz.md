## 题目

```python
import torch
m = torch.nn.Linear(2, 1)
with torch.inference_mode():
    out = m(torch.ones(1, 2))
print(out.requires_grad)
```

- **A.** False
- **B.** True
- **C.** None
- **D.** 0

## 口述答案

答案是 **A. False**，实际输出 `False`。

inference_mode 比 no_grad 更彻底，连版本计数都不记，推理首选；no_grad 也能达到不建图的效果。
