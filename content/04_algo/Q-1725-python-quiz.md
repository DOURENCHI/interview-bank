## 题目

```python
print((1, 2) + (3,), (1,) * 3)
```

- **A.** (1, 2, 3) (1, 1, 1)
- **B.** [1, 2, 3] (1, 1, 1)
- **C.** (1, 2, 3) (1, 1, 1, 1)
- **D.** ((1, 2), 3) (1, 1, 1)

## 口述答案

答案是 **A. (1, 2, 3) (1, 1, 1)**，实际输出 `(1, 2, 3) (1, 1, 1)`。

元组相加是拼接、乘法是重复；元组不可变，所以只有这两种「看起来像修改」的操作。

## 讲深一层

讲深一层：元组不可变，但 + 和 * 会创建新元组，不违反不可变性；(1,)*3 得 (1,1,1)，写成 (1)*3 则只是整数 3。单元素元组的逗号是语法必需，不是风格问题。元组「不可变」指结构固定：若元素本身是 list，仍可改那个 list 的内容，`(1,[2])[1].append(3)` 是合法的。

## 高频追问

1. **(1) 和 (1,) 区别？** —— 前者是 int，后者是一元组。
2. **元组真的完全不可变吗？** —— 结构不可变，但内部可变元素的内容可改。
3. **元组比列表好在哪？** —— 更紧凑、可哈希、能做字典键。

## 易错点

- 写 (1)\*3 想复制元组：得到整数 3，不是 (1,1,1)
- 以为 (1,2)+(3) 合法：(3) 是 int，抛 TypeError
- 认为元组内 list 也不能改：(1,[2])[1].append(3) 实际成功
