## 题目

```python
import numpy as np
a = np.array([[1, 2], [3, 4]])
print(a[0, 1], a[1], a[:, 0], a[0, :])
```

- **A.** 2 [3 4] [1 3] [1 2]
- **B.** 1 [3 4] [1 3] [1 2]
- **C.** 2 [3 4] [1 3] [3 4]
- **D.** 2 [3 4] [3 1] [1 2]

## 口述答案

答案是 **A. 2 [3 4] [1 3] [1 2]**，实际输出 `2 [3 4] [1 3] [1 2]`。

a[0,1] 取第 0 行第 1 列；a[1] 取整行；a[:,0] 取所有行的第 0 列；a[0,:] 取第 0 行全部。

## 讲深一层

讲深一层：二维数组用逗号一次定位 a[i,j]，等价 a[i][j] 但只做一次索引、更快。a[i] 取整行、a[:,j] 取整列，返回的是视图而非副本，改它会影响原数组；要独立副本得 .copy()。切片保留维度，a[0:1] 仍是 (1,2) 的二维，而 a[0] 降成 (2,) 一维，这个差异在广播时很关键。

## 高频追问

1. **视图和副本怎么区分？** —— 视图共享 base，改视图原数组变；.copy() 切断。
2. **a[0] 和 a[0:1] 区别？** —— 前者降维成 (2,)，后者保持 (1,2)。
3. **怎么取多个不连续列？** —— `a[:, [0,2]]` 花式索引，返回副本。

## 易错点

- 把 a[:,0] 当成取第 0 行：冒号在前表示所有行，得到的是第 0 列 [1,3]
- 以为切片返回副本：是视图，改 a[:,0] 会改原数组
- 把 a[0,1] 和 a[0][1] 当完全等价：取值相同，但链式索引在花式索引下行为不同
