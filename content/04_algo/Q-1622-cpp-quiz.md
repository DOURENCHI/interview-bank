## 题目

```cpp
int a[5] = {1, 2};
cout << a[2] + a[4];
```

- **A.** 0
- **B.** 随机值
- **C.** 3
- **D.** 编译错误

## 口述答案

答案是 **A. 0**，实际输出 `0`。

部分初始化时，没给出的元素自动补 0。

## 讲深一层

聚合初始化时显式给出的元素按顺序填入，其余做值初始化补 0，所以 a[2]、a[3]、a[4] 都是 0。若连初始化列表都不写（int a[5];），局部数组是不确定值，读它属未定义行为；只有全局或 static 数组才零初始化。写 int a[5] = {}; 也能全零。

## 高频追问

1. **为什么 a[4] 不是随机值？** —— 只要出现了初始化列表，未列出的元素就被值初始化，内置类型补 0，不是留垃圾。
2. **什么情况下才是随机值？** —— 完全不写初始化列表的局部数组 int a[5];，其元素未初始化，读出来是栈上残留，属 UB。
3. **C++20 能指定下标吗？** —— 可以，int a[5] = {[1]=2, [3]=4}; 未指定的下标仍补 0，其余元素为 0。

## 易错点

- 以为部分初始化后剩余元素是随机值，选成 B
- 把 a[2]+a[4] 当成 1+2=3，选成 C
- 以为初始化列表长度不足会编译错误，选成 D
