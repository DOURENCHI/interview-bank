## 题目

**题目**：一个网格，`0` 是通路 `1` 是墙，问从左上到右下的最短步数。另一道题：问从左上到右下**一共有多少条**不同路径。

**问**：这两道题长得很像，为什么一道用 BFS、一道用 DFS？选择依据是什么？

## 口述答案

> 看**问的是"最短"还是"全部"**。求最短路径用 BFS，因为它按层扩展，第一次到达目标时的层数就是最短距离；求方案总数用 DFS（或 DP），因为它要把每条路径都走一遍。
> 底层原因：BFS 的队列保证"先访问的一定更近"，DFS 的栈只保证"一条路走到黑"，没有距离信息。

## 讲深一层

| 需求 | 选谁 | 原因 | 复杂度 |
|---|---|---|---|
| 最短步数 / 最少操作 | BFS | 按层扩展，首次到达即最短 | O(V+E) |
| 是否存在路径 | DFS / BFS 都行 | 只关心可达性 | O(V+E) |
| 所有方案 / 排列组合 | DFS + 回溯 | 需要枚举完整路径 | 指数级 |
| 连通块 / 岛屿数量 | DFS / BFS 都行 | 洪水填充 | O(V+E) |
| 状态空间很大但要最优 | 优先队列 BFS（Dijkstra/A*） | 边权不同 | O(E log V) |

```cpp
// BFS 求最短步数
queue<pair<int,int>> q; q.push({0,0});
dist[0][0] = 0;
while (!q.empty()) {
    auto [x, y] = q.front(); q.pop();
    for (auto [dx, dy] : dirs) {
        int nx = x+dx, ny = y+dy;
        if (合法 && dist[nx][ny] == -1) {
            dist[nx][ny] = dist[x][y] + 1;   // 入队时定距，不要出队时算
            q.push({nx, ny});
        }
    }
}
```

**一个必须注意的细节**：BFS 的距离要在**入队时**赋值，不能在出队时算，否则同一个点可能被重复入队。

## 高频追问

1. **DFS 会爆栈吗？** —— 网格 1000×1000 递归深度可能到 10⁶，必须改迭代或手工栈。
2. **BFS 内存太大怎么办？** —— 双向 BFS（从起点终点同时扩展），或换成 A* 加启发式。
3. **带权图还能 BFS 吗？** —— 不能，要 Dijkstra；边权只有 0/1 时用 0-1 BFS（双端队列）。

## 易错点

- 求最短却用 DFS，超时或答案不是最短
- BFS 出队时才记距离，导致重复入队
- 忘了标记起点已访问，起点被反复入队
