## 题目

**背景**：背包问题两兄弟——0-1 背包每件物品**最多选一次**，完全背包每件**可选无限次**。
**问**：两者在状态转移上到底差在哪？代码上怎么体现？

## 口述答案

> 差别只有一个：内层循环的方向。
> 0-1 背包一维优化时内层**倒序**（从大到小），保证 `dp[j-w]` 还是上一轮的值，每件物品只被算一次；
> 完全背包内层**正序**，`dp[j-w]` 是本轮刚更新过的值，同一件物品就被允许重复选。
> 二维写法两者一样，区别只在第三层循环的枚举次数——所以一维压缩才是两者的分水岭。
> 典型题：0-1 是「分割等和子集」；完全背包是「零钱兑换」「完全平方数」。

## 讲深一层

```cpp
// 0-1：倒序 —— 每件一次
for (int i = 0; i < n; ++i)
    for (int j = W; j >= w[i]; --j)
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);

// 完全：正序 —— 每件无限
for (int i = 0; i < n; ++i)
    for (int j = w[i]; j <= W; ++j)
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

| | 0-1 背包 | 完全背包 |
|---|---|---|
| 每件选几次 | 0 或 1 | 0~∞ |
| 一维内层 | 倒序 | 正序 |
| 代表题 | 分割等和子集 | 零钱兑换 |

## 高频追问

1. 为什么二维写法没有方向问题？——`dp[i][j]` 依赖 `dp[i-1][*]`，天然隔离
2. 求方案数而不是最大值呢？——把 max 换成加法，方向规则不变
3. 多重背包怎么处理？——二进制拆包转化成 0-1 背包

## 易错点

- 两者的内层方向记反——正序会把 0-1 背包跑成完全背包
- 只背结论不理解：倒序的本质是「用上一轮的值」
