## 题目

**背景**：看到"最长子数组"几个字就往滑动窗口上套，结果有些题套上去答案错，比如「和至少为 K 的最短子数组」（数组含负数）。

**问**：滑动窗口到底在什么条件下才能用？怎么快速判断一道题能不能套？

## 口述答案

> 核心条件只有一个：**窗口扩张时，你要维护的那个量必须单调**。右指针右移让条件"更满足"，左指针右移让它"更不满足"，这样两个指针都只往一个方向走，才是 O(n)。
> 数组全是正数时，窗口和随右扩必增、随左缩必减，单调成立；一旦有负数，加一个元素和可能变小，单调性破坏，窗口就不能用了——那类题要换前缀和 + 单调队列。

## 讲深一层

判断流程：

1. 明确"窗口内要维护什么量"（和、不同字符数、最大值…）；
2. 问：右指针右移，这个量是否**单调不减**（求最长）或**单调不减地趋于满足**（求最短）？
3. 若单调 → 滑窗；若不单调 → 前缀和 / 二分 / DP。

| 题目 | 维护量 | 单调？ | 能用滑窗 |
|---|---|---|---|
| 最长无重复子串 | 窗口内字符计数 | 是 | ✅ |
| 最小覆盖子串 | 覆盖计数 | 是 | ✅ |
| 和 ≥ K 的最短子数组（全正） | 窗口和 | 是 | ✅ |
| 和 ≥ K 的最短子数组（含负） | 窗口和 | 否 | ❌ 用前缀和 + 单调队列 |
| 滑动窗口最大值 | 窗口内最大值 | 用单调队列维护 | ✅（配双端队列） |

```cpp
// 求最短：收缩用 while，因为可能连续收缩多次
int l = 0, best = INT_MAX;
long long sum = 0;
for (int r = 0; r < n; ++r) {
    sum += a[r];
    while (sum >= K) { best = min(best, r - l + 1); sum -= a[l++]; }
}
```

## 高频追问

1. **含负数怎么办？** —— 前缀和 + 单调队列（求"和 ≥ K 的最短"），或转成"前缀和数组上的双指针"（需单调）。
2. **窗口大小固定时怎么写？** —— 右指针到 k-1 后，每次进一个出一个，不用 while。
3. **怎么证明复杂度是 O(n)？** —— 每个元素最多被左右指针各访问一次，总移动次数 ≤ 2n。

## 易错点

- 见到"子数组"就套滑窗，不看单调性
- 求最短时用 `if` 收缩，漏掉连续收缩的情况
- 用 `int` 存窗口和，溢出
