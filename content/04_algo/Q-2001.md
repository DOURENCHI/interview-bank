## 题目

**题目**：手写直接插入排序，再说明希尔排序在它基础上改了什么。

**问**：直接插入排序和希尔排序的思路与复杂度？

## 口述答案

> **直接插入**：把第 i 个元素插到前面已排好的序列里的正确位置，像摸扑克牌。最好 O(n)（已有序）、最坏/平均 O(n²)、空间 O(1)、**稳定**。
> **希尔排序**：先按较大间隔做插入排序（让元素大步移动），逐步缩小间隔到 1。因为间隔大时每次能跨很远，整体比较次数下降，**平均 O(n^1.3)**，但**不稳定**。

## 讲深一层

```c
void insertion_sort(int a[], int n) {
    for (int i = 1; i < n; ++i) {
        int key = a[i], j = i - 1;
        while (j >= 0 && a[j] > key) { a[j+1] = a[j]; --j; }
        a[j+1] = key;
    }
}
void shell_sort(int a[], int n) {
    for (int gap = n/2; gap > 0; gap /= 2)
        for (int i = gap; i < n; ++i) {
            int key = a[i], j = i - gap;
            while (j >= 0 && a[j] > key) { a[j+gap] = a[j]; j -= gap; }
            a[j+gap] = key;
        }
}
```
| 算法 | 最好 | 平均 | 最坏 | 稳定 |
|---|---|---|---|---|
| 插入 | O(n) | O(n²) | O(n²) | ✅ |
| 希尔 | O(n log n) | O(n^1.3) | O(n²) | ❌ |

## 高频追问

1. **插入排序为什么适合小数组？** —— 常数小、无递归、局部性好；`std::sort` 在小区间就切到插入排序。
2. **希尔排序的间隔怎么选？** —— 常用 `n/2` 折半；Hibbard/Sedgewick 序列更优。

## 易错点

- 说希尔排序稳定（间隔跳跃会破坏稳定性）
- 插入排序写成每次都交换（退化成 O(n²) 且多两次赋值）
