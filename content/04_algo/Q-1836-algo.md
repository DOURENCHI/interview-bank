## 题目

**规则**：活细胞周围活邻居 2–3 个则存活，否则死亡；死细胞周围恰好 3 个活邻居则复活。
**要求**：原地更新，不能同时读写冲突。

**问**：怎么原地更新而不覆盖下一轮要用的状态？

## 口述答案

> 用**复合状态编码**：用两位表示「当前状态 + 下一状态」。
> 例如 2 表示「原来是活、现在变死」，3 表示「原来是死、现在变活」，0 和 1 保持原样。
> 统计邻居时把 `> 0` 都算作「原本是活的」，这样读取不受影响；
> 全部算完后，再统一把 2 归 0、3 归 1。

## 讲深一层

```cpp
void gameOfLife(vector<vector<int>>& b) {
    int R = b.size(), C = b[0].size();
    int dx[8] = {-1,-1,-1,0,0,1,1,1};
    int dy[8] = {-1,0,1,-1,1,-1,0,1};

    for (int i = 0; i < R; ++i)
        for (int j = 0; j < C; ++j) {
            int live = 0;
            for (int k = 0; k < 8; ++k) {
                int x = i + dx[k], y = j + dy[k];
                if (x>=0 && x<R && y>=0 && y<C && (b[x][y] & 1)) ++live;
            }
            if (b[i][j] & 1) {                  // 原本活着
                if (live == 2 || live == 3) b[i][j] = 3;   // 活 + 下一轮仍活
            } else {
                if (live == 3) b[i][j] = 2;                // 死 + 下一轮活
            }
        }

    for (auto& row : b)
        for (int& x : row) x = (x == 3) ? 1 : (x == 2 ? 0 : x);
}
```

## 高频追问

1. **为什么用 `& 1` 取原状态？** —— 低位存原状态，高位存新状态，位运算最快。
2. **用额外数组不行吗？** —— 行，但题目要求原地。
3. **无限网格怎么办？** —— 用哈希存活细胞坐标，只遍历它们和邻居。

## 易错点

- ❌ 边算边写 —— 覆盖后续要读的状态
- ❌ 邻居统计用了新状态
- ✅ 说清「两位编码 + 最后统一归一化」
