## 题目

**输入**：`nums = [1,2,3,4,5,6,7], k = 3`
**输出**：`[5,6,7,1,2,3,4]`
**要求**：原地，O(1) 额外空间。

**问**：三次反转为什么等价于右移 k 位？

## 口述答案

> 整体反转把后 k 个挪到了前面但顺序反了，再分别反转前 k 个和后 n-k 个，就把两段各自正回来。
> 以 `[1,2,3,4,5,6,7], k=3` 为例：
> 整体反转 → `[7,6,5,4,3,2,1]`；前 3 个反转 → `[5,6,7,4,3,2,1]`；后 4 个反转 → `[5,6,7,1,2,3,4]`。
> 关键是 **k 要先对 n 取模**，否则 k > n 时切分点越界。

## 讲深一层

```cpp
void rotate(vector<int>& a, int k) {
    int n = a.size();
    k %= n;                          // 必须
    reverse(a.begin(), a.end());
    reverse(a.begin(), a.begin() + k);
    reverse(a.begin() + k, a.end());
}
```

| 方法 | 空间 | 说明 |
|---|---|---|
| 额外数组 | O(n) | 最简单 |
| 环状替换 | O(1) | 但下标推敲麻烦 |
| **三次反转** | **O(1)** | 最好写 |

## 高频追问

1. **k > n 会怎样？** —— 不取模会越界或错误切分，右移 10 位等价于右移 10%7=3 位。
2. **左移 k 位呢？** —— 对称：反转前 n-k 个、后 k 个、再整体。
3. **三次反转的复杂度？** —— 每次 O(n)，共 3 次，仍 O(n)。

## 易错点

- ❌ 忘了 `k %= n`
- ❌ 边界：`k = 0` 时反转会打乱顺序（应先判断）
- ✅ 能举一个例子手推三步
