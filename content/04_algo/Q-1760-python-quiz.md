## 题目

```python
xs = [1.0, 2.0, 3.0]
ys = [2.0, 4.0, 6.0]
w = 1.0
def grad(w):
    return sum(2 * x * (x * w - y) for x, y in zip(xs, ys)) / len(xs)
def cost(w):
    return sum((x * w - y) ** 2 for x, y in zip(xs, ys)) / len(xs)
for _ in range(10):
    w -= 1.0 * grad(w)
print(round(w, 4), round(cost(w), 4))
```

- **A.** -1615055826.8985 1.2172558208808118e+19
- **B.** (-1.6151, 2.0)
- **C.** (0.0, 0.0)
- **D.** (1.0, 4.6667)

## 口述答案

答案是 **A. -1615055826.8985 1.2172558208808118e+19**，实际输出 `-1615055826.8985 1.2172558208808118e+19`。

学习率从 0.01 放大到 1.0 后步子太大直接发散：w 变成天文数字、代价爆炸。梯度下降必须配足够小的学习率。

## 讲深一层

稳定条件是 `lr < 2/λmax`，这里 `λmax = 2Σx²/n = 28/3 ≈ 9.33`，临界值约 0.214。lr=1.0 时误差乘子为 `1 − 1.0×9.33 = −8.33`，绝对值大于 1 且为负，于是每步放大 8 倍多并交替变号，10 步后到 1e9 量级。注意 10 步内还没溢出成 inf，仍是有限大数，只是符号为负。

## 高频追问

1. **为什么结果是负数且绝对值爆炸？** —— 乘子为负说明每步越过最优点并反向，`|−8.33|>1` 使幅度指数增长
2. **临界学习率是多少？** —— 约 0.214；超过它震荡发散，恰好等于它则等幅震荡
3. **训练出现 inf/nan 怎么排查？** —— 先把 lr 降一个数量级，再加梯度裁剪、检查输入是否未标准化

## 易错点

- 认为发散一定得到 nan——10 步内是有限大数 `−1.6e9`，inf 要更多步或更大 lr
- 把 lr 当"越大收敛越快"——超过 2/λmax 直接发散，这正是本题考点
- 只说"变得很大"不说符号——输出带负号，漏掉符号就选不出 A
