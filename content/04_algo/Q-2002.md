## 题目

**题目**：快排和冒泡都是交换排序，为什么快排快那么多？快排什么时候最慢？

**问**：快速排序和冒泡排序的区别？快排最坏情况是什么？

## 口述答案

> **冒泡**每轮只把最大元素"冒"到末尾，相邻交换，**O(n²) 且交换次数多**。
> **快排**选基准 partition，一趟就把数组分成"小于/大于"两半，然后递归——每层 O(n)，共 O(log n) 层，所以平均 **O(n log n)**。
> **最坏情况 O(n²)**：每次选的基准都是极值（数组已有序且取首元素），分区退化成 1 和 n-1。

## 讲深一层

```c
int partition(int a[], int lo, int hi) {
    int p = a[hi], i = lo;
    for (int j = lo; j < hi; ++j)
        if (a[j] < p) { swap(&a[i++], &a[j]); }
    swap(&a[i], &a[hi]);
    return i;
}
```
| 算法 | 平均 | 最坏 | 稳定 | 额外空间 |
|---|---|---|---|---|
| 冒泡 | O(n²) | O(n²) | ✅ | O(1) |
| 快排 | O(n log n) | **O(n²)** | ❌ | O(log n) 栈 |
- 避免最坏：**随机选基准**、三数取中、小区间切插入排序（introsort）。
- 快排不稳定：partition 的交换会打乱相等元素的相对顺序。

## 高频追问

1. **为什么快排实际比归并快？** —— 原地、常数小、缓存友好（虽然渐进复杂度相同）。
2. **已排序数组用快排会怎样？** —— 取首元素做基准就退化成 O(n²)，所以基准要随机化。

## 易错点

- 说快排最坏也是 O(n log n)
- 忘了快排不稳定
