## 题目

```python
import torch
a = torch.tensor([[1.0], [2.0]])
b = torch.tensor([10.0, 20.0, 30.0])
print(tuple((a + b).shape), (a + b).tolist())
```

- **A.** (2, 3) [[11.0, 21.0, 31.0], [12.0, 22.0, 32.0]]
- **B.** ((3, 2), [[11.0, 12.0], [21.0, 22.0], [31.0, 32.0]])
- **C.** ((2, 3), [[11.0, 12.0], [21.0, 22.0], [31.0, 32.0]])
- **D.** ((2, 3), [[11.0, 21.0, 31.0]]

## 口述答案

答案是 **A. (2, 3) [[11.0, 21.0, 31.0], [12.0, 22.0, 32.0]]**，实际输出 `(2, 3) [[11.0, 21.0, 31.0], [12.0, 22.0, 32.0]]`。

(2,1) 与 (3,) 广播时，(3,) 被看作 (1,3)，(2,1) 补成 (2,1)，结果 (2,3)。PyTorch 广播规则与 NumPy 一致。

## 讲深一层

广播从最右维对齐：维度相等或其一为 1 才能算，否则报错。`(2,1)` 与 `(3,)` 对齐成 `(2,1)` 与 `(1,3)`，各扩到 `(2,3)`。边界在 `(2,1)+(2,)`：末维 1 对 2 不兼容，直接报错。广播不复制数据，靠 stride=0 视图。

## 高频追问

1. **`(2,1)` 和 `(2,)` 相加呢？** —— 报错，右对齐时最后一维 1 与 2 不匹配，得先把 `(2,)` 改成 `(2,1)`
2. **为什么第一行是 `[11,21,31]`？** —— `a[0,0]=1` 被广播到整行，与 `[10,20,30]` 逐元素相加
3. **换成 `a @ b` 会怎样？** —— 内维 1 与 3 不匹配，报矩阵乘维度错误；广播只对逐元素运算生效

## 易错点

- 以为 `(3,)` 会补成 `(3,1)`——那样得 `[[11,12],[21,22],[31,32]]`，就是选项 B
- 把广播理解成"复制成同形状再算"——实际是 stride=0 视图，`a.expand(2,3)` 不占新内存
- 以为形状不同一定报错——只要满足右对齐规则就能算，这是判断题最常见的失分点
