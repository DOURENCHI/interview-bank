## 题目

**题目**：给定只含 `()[]{}` 的字符串，判断括号是否有效（同类型闭合、顺序正确）。

```
输入："()[]{}"   输出：true
输入："([)]"     输出：false
输入："(]"       输出：false
```

**问**：为什么必须用栈，不能用计数器？

## 口述答案

> 因为计数器只能表达"数量"，表达不了"嵌套顺序"。`"([)]"` 里左右括号数量完全相等，但它无效——右括号 `)` 出现时，栈顶应该是 `(`，可实际是 `[`，类型不匹配。
> 栈保存的是**未闭合括号的嵌套顺序**，这是计数做不到的信息。

## 讲深一层

```cpp
bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') { st.push(c); continue; }
        if (st.empty()) return false;                 // 右括号多了
        char t = st.top();
        if ((c == ')' && t != '(') ||
            (c == ']' && t != '[') ||
            (c == '}' && t != '{')) return false;     // 类型不匹配
        st.pop();
    }
    return st.empty();                                // 左括号多了
}
```
时间 O(n)，空间 O(n)。

**三条失败路径**，讲全了才完整：
1. 右括号来时栈空 → 右括号多了；
2. 栈顶类型不匹配 → 顺序错；
3. 结束时栈非空 → 左括号多了。

**一个能加分的说法**：如果用哈希表存 `)`→`(` 的映射，可以把三种判断压成一次比较：`if (st.empty() || st.top() != map[c]) return false;`。

## 高频追问

1. **只有一种括号时能用计数器吗？** —— 可以，`(` 加一 `)` 减一，中途为负或结尾非零就失败。多种括号就不行。
2. **最长有效括号怎么求？** —— 栈里存下标而不是字符，遇到不匹配时用下标差算长度。
3. **能不用栈吗？** —— 可以用递归（本质还是栈），或原地把匹配的括号对标记删除，反复扫描。

## 易错点

- 只检查数量相等，`"([)]"` 判成 true
- 忘了结束时检查栈是否为空
- 空串返回 false（应该是 true）
