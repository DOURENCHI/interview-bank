## 题目

```python
import numpy as np
b = np.array([1, 2, 3])
c = np.array([[1, 2, 3], [4, 5, 6]])
print((b + c).shape, (b * c).shape, (b + 1).tolist())
```

- **A.** (2, 3) (2, 3) [2, 3, 4]
- **B.** (3, 2) (2, 3) [2 3 4]
- **C.** (2, 3) (3, 2) [2 3 4]
- **D.** (2, 3) (2, 3) [2 3 4 5 6 7]

## 口述答案

答案是 **A. (2, 3) (2, 3) [2, 3, 4]**，实际输出 `(2, 3) (2, 3) [2, 3, 4]`。

广播把 (3,) 看成 (1,3) 再和 (2,3) 逐行相加；b * c 是逐元素乘不是矩阵乘（矩阵乘要用 @ 或 dot）。

## 讲深一层

讲深一层：广播从尾部维度对齐，逐维要求「相等或其中一个是 1」，所以 (3,) 被看作 (1,3) 后扩展成 (2,3)。* 在 ndarray 上恒为逐元素乘，矩阵乘必须用 @、np.dot 或 np.matmul；(2,3)@(3,) 得 (2,)，而 * 得 (2,3)。若形状既不相等又没有 1，如 (2,3)+(2,)，直接抛 ValueError。

## 高频追问

1. **广播的对齐规则？** —— 尾部对齐，每维相等或为 1。
2. **\* 和 @ 区别？** —— 逐元素乘 vs 矩阵乘。
3. **为什么 (2,3)+(3,) 可以？** —— (3,) 视作 (1,3)，可广播到两行。

## 易错点

- 把 b\*c 当矩阵乘：得到逐元素积，形状 (2,3) 而非 (2,2)
- 以为 (2,3)+(2,) 能广播：尾部 3 与 2 不匹配，抛 ValueError
- 用 (3,) 想做列广播：它是行向量，列要用 (3,1)
