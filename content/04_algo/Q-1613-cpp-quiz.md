## 题目

```cpp
cout << -7 / 2 << " " << -7 % 3;
```

- **A.** -3 -1
- **B.** -4 2
- **C.** -3 2
- **D.** -4 -1

## 口述答案

答案是 **A. -3 -1**，实际输出 `-3 -1`。

C++11 起整数除法向零取整：-3.5 取整为 -3；余数的符号跟着被除数，所以 -7 % 3 = -1。Python 的结果是 -4 和 2，正好不同。

## 讲深一层

C++11 起商向零截断，并强制 (a/b)*b + a%b == a，余数符号随被除数：-7%3=-1、7%-3=1、-7%-3=-1。C++98 对负商是实现定义，老编译器可能给 -4 和 2。换浮点则 -7.0/2 得 -3.5 不截断，fmod(-7,3) 仍是 -1.0。换到 INT_MIN/-1 是唯一溢出点，属未定义行为。

## 高频追问

1. **余数符号到底跟谁？** —— 跟被除数，恒满足 a == (a/b)*b + a%b：-7%3=-1、7%-3=1、-7%-3=-1，与除数符号无关。
2. **为什么不是向下取整？** —— C++11 明确规定向零截断（trunc）；C++98 对负商是实现定义。Python 用 floor 除法，所以才有 -4 和 2 那组答案。
3. **换浮点或换边界值呢？** —— -7.0/2 = -3.5 不做截断，fmod(-7,3) 给 -1.0；INT_MIN/-1 溢出，是未定义行为而不是 2147483648。

## 易错点

- 把 -7/2 当 -3.5 再四舍五入，得 -4，选成 B
- 按「余数跟除数」推，算出 -7%3 = 2，选成 C
- 以为 C++ 与 Python 规则一致，记成 -4 2
