## 题目

**题目**：找到字符串中第一个不重复的字符，返回它的下标，没有则返回 -1。

```
输入："loveleetcode"   输出：2（字符 'v'）
输入："aabb"           输出：-1
```

**问**：为什么用计数数组而不是哈希表？两遍扫描各自在做什么？

## 口述答案

> 因为字符集是固定的（小写字母 26 个，或 ASCII 128 个），数组比哈希表更快——没有哈希计算、没有冲突、内存连续。
> 两遍扫描分工明确：**第一遍统计次数，第二遍按原顺序找第一个次数为 1 的**。必须两遍，因为"第一个"依赖原始顺序，边统计边判断会漏掉后面才出现重复的情况。

## 讲深一层

```cpp
int firstUniqChar(string s) {
    int cnt[26] = {0};
    for (char c : s) ++cnt[c - 'a'];
    for (int i = 0; i < (int)s.size(); ++i)
        if (cnt[s[i] - 'a'] == 1) return i;
    return -1;
}
```
时间 O(n)，空间 O(1)（26 个 int）。

| 方案 | 时间 | 空间 | 适用 |
|---|---|---|---|
| 计数数组两遍 | O(n) | O(1) | 字符集固定 |
| 哈希表两遍 | O(n) 平均 | O(k) | 字符集大或未知 |
| 队列 + 计数 | O(n) | O(k) | **流式输入**，来一个处理一个 |

**为什么不能用队列一次遍历**：题目要求返回下标而不是字符，队列适合"流式"场景（字符源源不断到来），一次性给完整字符串时没必要。

## 高频追问

1. **如果要求返回字符而不是下标？** —— 同样两遍，第二遍返回 `s[i]`。
2. **流式输入怎么做？** —— 队列存候选，计数数组记次数；每次取队头，若次数 > 1 就弹出。
3. **大小写都要考虑？** —— 数组开到 128，直接用 `c` 当下标（注意 `char` 可能为负）。

## 易错点

- 边统计边判断，第一遍统计不全
- 数组只开 26 却输入含大写字母，越界
- `char` 直接当下标，遇到负值越界
