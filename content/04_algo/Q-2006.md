## 题目

**题目**：链表可能有环，怎么判断？有环的话入口在哪？

**问**：怎么判断链表是否有环？入口怎么找？

## 口述答案

> **快慢指针**（Floyd 判圈）：慢指针走 1 步、快指针走 2 步，若有环必定相遇，无环则快指针先到 `nullptr`。
> 找入口：相遇后把**一个指针移回头部**，两个指针都改成每次走 1 步，再次相遇的位置就是入口。

## 讲深一层

```c
ListNode* detectCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {                 // 相遇
            slow = head;
            while (slow != fast) { slow = slow->next; fast = fast->next; }
            return slow;                    // 入口
        }
    }
    return nullptr;
}
```
**为什么这样能找到入口**：设头到入口距离 a、入口到相遇点距离 b、环长 L。相遇时慢走 a+b、快走 a+b+kL，且快是慢的两倍 → `a+b = kL` → 从头走 a 步到达入口时，从相遇点走 a 步也正好到入口。
| 方法 | 空间 | 备注 |
|---|---|---|
| 哈希表存节点 | O(n) | 简单但费内存 |
| 快慢指针 | **O(1)** | 首选 |

## 高频追问

1. **快指针走 3 步行不行？** —— 能判环，但可能永远不相遇（取决于环长），2 步是安全选择。
2. **怎么求环长？** —— 相遇后继续走一圈计数。

## 易错点

- 只判环不找入口（面试常追问入口）
- 循环条件漏掉 `fast->next` 判空
