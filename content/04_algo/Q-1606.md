## 题目

**背景**：两道题摆在一起：「两数之和 II（有序数组）」和「无重复字符的最长子串」。前者常被叫双指针，后者常被叫滑动窗口。

**问**：这两者到底有什么区别？是两种技巧，还是同一个东西的两种叫法？

## 口述答案

> **滑动窗口是双指针的一个特例**。双指针泛指用两个下标协同移动；滑动窗口特指两个指针**夹出一个连续区间**，并且这个区间要维护某种"窗口内状态"（和、计数、是否重复）。
> 区别在移动方式：普通双指针往往一个从头一个从尾**相向**移动（如两数之和 II）；滑动窗口是同向移动，右指针扩张、左指针收缩。

## 讲深一层

| 类型 | 移动方式 | 典型题 | 维护的状态 |
|---|---|---|---|
| 相向双指针 | 左++、右-- | 两数之和 II、盛最多水的容器 | 无（只比较两端） |
| 快慢指针 | 同向，速度不同 | 链表判环、找中点 | 无 |
| 滑动窗口 | 右扩左缩 | 最长无重复子串、最小覆盖子串 | 窗口内的计数/和 |

```cpp
// 滑动窗口模板：右指针扩张，不满足时左指针收缩
int l = 0, ans = 0;
for (int r = 0; r < n; ++r) {
    // 1. 把 a[r] 纳入窗口
    while (/* 窗口不合法 */) {
        // 2. 把 a[l] 移出窗口
        ++l;
    }
    ans = max(ans, r - l + 1);
}
```

**相向双指针能成立的前提**：区间具有单调性。「盛最多水的容器」里，移动矮的那一侧不会漏掉最优解，因为宽度只会变小，高度由矮的决定——这是需要能讲出来的论证。

## 高频追问

1. **滑动窗口一定要用 `while` 收缩吗？** —— 求"最长"时用 `if` 也能过（每次最多移一步），求"最短"时必须用 `while`。
2. **窗口里能不能放栈/堆？** —— 能，就变成"单调队列/堆 + 滑窗"，如滑动窗口最大值。
3. **双指针能解决什么问题类型？** —— 有序性、单调性、区间性质；无序数据一般要先排序。

## 易错点

- 把两者当成互不相关的两个技巧
- 滑动窗口用 `while` 还是 `if` 分不清
- 相向双指针不说清"为什么这样移动不会漏解"
