## 题目

**输入**：`[[1,2,3],[4,5,6],[7,8,9]]`
**输出**：`[[7,4,1],[8,5,2],[9,6,3]]`（顺时针 90°）
**要求**：原地。

**问**：原地顺时针 90° 怎么推？

## 口述答案

> 拆成两步：**先转置**（沿主对角线交换 `m[i][j]` 和 `m[j][i]`），**再左右翻转**（每行 reverse）。
> 这两步都好写、都不容易错，比直接做四点交换清晰得多。
> 逆时针 90° 则是「先转置，再上下翻转」。

## 讲深一层

```cpp
void rotate(vector<vector<int>>& m) {
    int n = m.size();
    for (int i = 0; i < n; ++i)
        for (int j = i + 1; j < n; ++j)     // j 从 i+1 开始，只处理一半
            swap(m[i][j], m[j][i]);
    for (auto& row : m) reverse(row.begin(), row.end());
}
```

| 方向 | 步骤 |
|---|---|
| 顺时针 90° | 转置 + 左右翻转 |
| 逆时针 90° | 转置 + 上下翻转 |
| 180° | 左右翻转 + 上下翻转 |

## 高频追问

1. **`j` 为什么从 `i+1` 开始？** —— 从 0 开始会交换两次，等于没转置。
2. **四点交换怎么写？** —— `temp = a; a = b; b = c; c = d; d = temp;` 四元轮换，容易写错。
3. **非方阵呢？** —— 旋转非方阵不能原地，需要新数组。

## 易错点

- ❌ 内层循环从 0 开始 —— 转置失效
- ❌ 顺时针和逆时针的翻转方向搞反
- ✅ 记住「转置 + 翻转」两步法
