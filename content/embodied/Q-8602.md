## 口述答案

直答：一句话分工——VLA 是手，VLN 是腿，世界模型是脑内预演。VLA 输出手部小动作，每秒几十次；VLN（Vision-Language-Navigation）管导航，输入画面加指令——比如「出门左转走到厨房冰箱前停下」——输出的是方向性动作：走多远、转向、停，走一步想几次。

拿 NaVILA 走一遍 VLN 循环：system prompt、之前看到的画面（memory）、当前画面、指令一起喂给 VLA-8B，每张图占 196 个 token；模型输出 turn left 45°，翻译层执行，再看新画面进下一轮循环。数据集也跟着演进：R2R 是离散选点，VLN-CE 走向连续环境。

世界模型是第三件事：先从大量视频学会「这么做会发生什么」，动作前先在脑内预演。交互式世界模型（Genie 系）和视频生成的区别是「游戏 vs 电影」：核心机制是画面加 action 预测下一帧，视频生成没有 action 这个输入。

Genie 的动作是隐式的：从 3 万小时游戏视频的前后帧差异反推出 8 类按键。难点有三个：快——24fps 就是每帧 40ms；稳——拿自生成画面续训会出「复印机效应」，越印越糊；记得住——Genie1 只能记 1 秒，Genie3 到了 1 分钟。Genie4 的演示是 Gemini 文字指令指挥人形机器人下跳棋，发生在模拟内。

和具身世界模型的分工要说清：NVIDIA Cosmos、V-JEPA 2 以机器人本体为中心推演物理演化，Genie 重画面可玩性，两条线不冲突。收一句：**「手和腿的输出粒度不同，脑内预演让机器人先在想象里摔够跟头」**。

## 讲深一层

| 维度 | 要点 | 展开 |
|---|---|---|
| VLA=手 | 输出手部小动作 | 每秒几十次，操作粒度 |
| VLN=腿 | Vision-Language-Navigation | 输入画面+指令，输出走多远/转向/停，走一步想几次 |
| NaVILA 循环 | 画面+指令进模型、输出动作、循环 | system prompt+之前画面（memory）+当前画面+指令→VLA-8B（每图 196 token）→turn left 45°→翻译层执行→循环 |
| VLN 数据集演进 | R2R→VLN-CE | R2R 离散选点，VLN-CE 连续环境 |
| 世界模型 | 脑内预演 | 先从视频学会「这么做会发生什么」，动作前在想象里过一遍 |
| 交互式世界模型 vs 视频生成 | 游戏 vs 电影 | 核心机制=画面+action 预测下一帧；视频生成没有 action 输入 |
| 隐动作 | 从帧差反推 | 3 万小时游戏视频，前后帧差异反推 8 类按键 |
| 三难点 | 快 / 稳 / 记得住 | 快=24fps 即 40ms/帧；稳=自生成画面续训「复印机效应」越印越糊；记得住=Genie1 1 秒→Genie3 1 分钟 |
| Genie4 演示 | 模拟内指挥机器人 | Gemini 文字指令指挥人形机器人下跳棋 |
| 与具身世界模型分工 | Genie vs Cosmos / V-JEPA 2 | 后者以机器人本体为中心推演物理演化；Genie 重画面可玩性 |
| VLA-8B 的角色 | NaVILA 的导航大脑 | 「手」的模型被拿去当「腿」的大脑——模型可跨层复用 |
| 走一步想几次 | VLN 的决策节奏 | 每步推理后动一次，远低于 VLA 每秒几十次的小动作流 |

**三条线的接口**：NaVILA 的导航大脑就是 VLA-8B 这类 VLA 模型——「手」的模型给「腿」当大脑用；世界模型则可以给两者提供预演环境，三者是分工不是竞争。

**成本视角**：VLN 循环每步都带 memory，每图 196 token，走得越远上下文越长，推理成本随步数涨——这是导航和单轮问答在工程上的最大区别。

**一句话记法**：手（VLA）出小动作、腿（VLN）出方向、预演（世界模型）出经验。

**「游戏 vs 电影」为什么是本质区别**：电影只要求「像」，游戏要求「对动作负责」——同一个画面，按不同的 action 会得到不同的下一帧，这正是机器人预演需要的性质。

**NaVILA 的上下文大头**：每步至少带当前画面（196 token），memory 再叠加历史画面，步数一多 token 线性膨胀——这就是 memory 裁剪的动机。

## 高频追问

1. **VLN 的 memory 裁剪为什么影响成本？** —— 每张图 196 token，之前看到的画面都要进上下文，走得越远 token 越多、每步推理越贵；裁 memory 省成本，但丢的画面可能是认路要用的信息，是成本和记性的权衡。
2. **交互式世界模型的「复印机效应」怎么破？** —— 自生成画面续训会误差累积、越印越糊，目前没有标准解；常见思路是少拿自生成画面续训、以真实视频为锚，把「印自已印」的代数压住——所以「稳」还挂在难点上。
3. **Genie 的动作是隐式的，机器人怎么用它？** —— 那是从帧差反推的 8 类按键，不是关节指令；用法是把它当「想象环境」做预演（Genie4 演示里 Gemini 文字指令指挥人形机器人下跳棋，也发生在模拟内），动作落到本体还差一层对应。
4. **VLA 和 VLN 输入这么像，为什么不合成一个模型？** —— 输出粒度差一个量级：手部动作每秒几十次，导航动作走一步想几次，控制频率和动作空间都不同，分「手」和「腿」两条线更自然；NaVILA 里 VLA-8B 也是被拿来当导航大脑用的。
5. **世界模型为什么还是「候补」而不是主力？** —— 它卡在快、稳、记得住三个难点上（每帧 40ms、复印机效应、Genie1 一秒到 Genie3 一分钟），离直接上手干活还有距离。

## 易错点

- **把 VLN 当成 VLA 的子集**：输入接近（画面+指令），输出粒度完全不同——VLA 出手部小动作每秒几十次，VLN 出方向性动作（走多远/转向/停），一个管手一个管腿。
- **把交互式世界模型当视频生成**：视频生成像电影，没有 action 输入；交互式世界模型像游戏，画面+action 预测下一帧，能对动作负责。
- **以为 Genie 的动作能直接驱动机器人**：那是从游戏视频帧差反推的 8 类隐动作，不是关节指令，落到本体还差一层对应。
- **把 Genie 和 Cosmos / V-JEPA 2 混为一谈**：具身世界模型以机器人本体为中心推演物理演化，Genie 重画面可玩性，分工不同。
