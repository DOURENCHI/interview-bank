## 口述答案

直答：具身机器人的系统通常分三层——大脑层（System 2）、操作层、运动控制层。大脑层用 VLM，负责理解、规划、推理；操作层用 VLA/WAM，把理解变成动作序列；运动控制层是全身控制器，跑 1kHz 级实时闭环，直接稳住物理世界。

大脑层的学习范式：RL 后训练做对齐，而且可以照搬 DeepSeek R1 那套 LLM 的 RL 范式——代表工作有 NVIDIA Cosmos Reason 1、Embodied R1。

操作层是混合范式：模仿+RL 混着用；纯 RL 框架的代表是 π0.6，字节做了 JRL。

运动控制层：RL 已经是工业标配——在仿真里几千个环境并行训练，再落到真机，Boston Dynamics Atlas、宇树开源方案都是代表。RL 的循环就是 policy 拿到 state、输出 action、环境给 reward、循环更新；PPO（2017 OpenAI）是仿真机器人策略的通用底座。

最后把三种学习范式放一起分清：监督学习给标准答案，模仿学习给示范，RL 只给分数让自己试——像学骑自行车，没人给你分解动作，摔几次自己找平衡。收一句：**「大脑想得慢但对，小脑想得快但笨——分层不是妥协，是带宽分工」**。

## 讲深一层

| 维度 | 要点 | 展开 |
|---|---|---|
| 大脑层（System 2） | VLM：理解/规划/推理 | RL 后训练对齐，照搬 DeepSeek R1 范式；代表 NVIDIA Cosmos Reason 1、Embodied R1 |
| 操作层 | VLA/WAM：把理解变成动作序列 | 模仿+RL 混合；π0.6 是纯 RL 框架，字节做了 JRL |
| 运动控制层 | 全身控制器，1kHz 级实时闭环 | RL 已是工业标配：仿真几千并行训练；Boston Dynamics Atlas、宇树开源方案 |
| 学习范式分野 | 监督 / 模仿 / RL | 监督给标准答案、模仿给示范、RL 只给分数自己试（骑自行车例子） |
| RL 循环 | policy→state/action/reward→environment | 出策略、观测状态、执行动作、拿奖励、更新，循环往复 |
| PPO | 2017 OpenAI 提出 | 仿真机器人策略训练的通用底座 |
| 频率对比 | 大脑秒级 / 控制 1kHz | 差约三个数量级，各干各的，靠接口解耦 |
| 分层本质 | 带宽分工 | 大脑几秒一次管「对」，控制层 1kHz 管「稳」——不是妥协 |
| 各层范式速记 | 大脑 RL 后训练 / 操作模仿+RL / 控制 RL 标配 | 同一个 RL 思想，三层形态不同 |
| 大脑层别名 | System 2 慢思考 | 理解/规划/推理都是秒级任务——对应「慢而对」 |
| 控制层输出 | 全身实时控制 | 消费动作序列/动作目标，1kHz 闭环解算到全身关节 |
| RL 三要素 | state / action / reward | 环境给状态和奖励，policy 出动作，分数驱动更新 |
| 模仿 vs RL | 示范 vs 分数 | 一个照着示范做，一个只看得分自己试——输入信号本质不同 |

**为什么控制层必须是 1kHz**：物理平衡是毫秒级的事，重心偏一点就要在下一个周期补回来；大脑层面对的任务变化是秒级，跑太快白烧算力——所以两层差了三个数量级的更新频率。

**为什么 VLM 能借 LLM 的 RL 范式**：大脑层本来就是 VLM，理解/规划/推理和 LLM 同构，都是序列生成任务，DeepSeek R1 验证过的 RL 后训练流程可以整套装过来。

**仿真并行训练的意义**：真机上试错又慢又贵还危险，仿真里几千个环境并行，一晚跑出真机几年的经验——这是控制层敢全面转 RL 的前提。

**一句话记法**：大脑管对、操作管翻译、小脑管稳；三层的节拍从秒级到毫秒级。

## 高频追问

1. **为什么运动控制层必须 1kHz，大脑层可以几秒一次？** —— 控制层对抗的是毫秒级物理失稳，必须每个周期闭环；大脑层的环境变化是秒级，理解规划跑太快不提升效果还烧算力——带宽分工。
2. **层间接口通常传什么？** —— 大脑层给操作层传理解和规划（做什么、按什么顺序），操作层给控制层传动作序列/动作目标，控制层自己解算成 1kHz 的全身实时控制。
3. **为什么 VLM 后训练可以照搬 LLM 的 RL 范式？** —— 大脑层就是 VLM，与 LLM 同构，DeepSeek R1 那套 RL 后训练直接迁移；NVIDIA Cosmos Reason 1、Embodied R1 就是这条线的代表。
4. **三层是不是三种不同的 RL？** —— 思想同一个（只给分数自己试），形态不同：大脑层 RL 后训练对齐、操作层模仿+RL 混合、控制层 RL 标配，PPO 是仿真侧通用底座。
5. **操作层为什么是模仿+RL 混合，而不是纯 RL？** —— 遥操示范先给一个「能干活的底子」，再用 RL 的分数往上磨；π0.6 证明纯 RL 框架也可行，字节 JRL 在探索这条路。

## 易错点

- **把三层当成三块互不相干的模型**：分层是带宽分工——大脑想得慢但对、小脑想得快但笨，层间靠接口衔接，不是随便拼三个网络。
- **以为 RL 只用在运动控制**：三层都有 RL 的影子——大脑层 RL 后训练、操作层模仿+RL 混合、控制层 RL 标配，只是形态不同。
- **混淆三种学习范式**：监督学习给标准答案、模仿学习给示范、RL 只给分数自己试；骑自行车是摔会的，不是看教程看会的。
- **低估控制层的实时性要求**：1kHz 级实时闭环是它单独成层的硬理由，不是大脑层降频就能兼着的活。
