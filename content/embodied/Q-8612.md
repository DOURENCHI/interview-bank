## 口述答案

具身智能最缺的是遥操数据——教机器人动手这件事没有互联网可爬，每条数据都得人教或真机跑，全行业都缺。破法有四条：仿真合成、人手视频编伪本体、世界模型脑内预演、模型 API 化。

前两条 GR00T 已示范：几十条真机演示在仿真里扩成 54 万条；EgoDex 的 2 万小时人手视频，无标签部分用隐动作模型编出伪本体动作。第三条世界模型路线——让模型先看视频学会「这么做会发生什么」，动手前在脑内预演。

第四条是生态玩法：π API 开放（Physical Intelligence，2026-10-13），数据传上去云端微调，有公司 33 条数据次日就上了真机；Dream API（Dream Labs，9000 万种子轮）主打 zero-shot 无数据，一次出 48 步动作块、1.6 秒，$3 一小时，RoboDojo 6 真机评测 59.3 分，对 GPT-6 Astra 的 42.5。

大小脑混合的数字最能说明趋势：GPT-6 Astra 全包 26%，Astra+π0.5 混合（π0.5 出动作、Astra 审查修正）48%，加 22 个点；Astra 简单抓放强（20/19）、精细差（拼图 2/20）、慢（13 秒一次决策对 π0.5 的 47 毫秒）。大模型规划加小模型与工具调用，正在成为 VLA、世界模型之后的第三条路线。

**数据不够，拿架构和生态凑——小模型干活，大模型监工，云厂收租。**

**API 化改变了什么**：训练能力被服务化——不养训练集群，拿数据换模型；33 条数据次日上真机，迭代从月压到天。

**混合架构的本质**：大模型出「对不对」的判断，小模型出「怎么动」的轨迹——用架构分工换数据积累。

**Astra 快不起来的根源**：每步决策都压给通用大模型，13 秒的通用性，π0.5 用 47 毫秒的专业动作头拿到——通用与专用的成本差在这里具象化。

**四破法的共同逻辑**：把「数据从哪来」改成「数据怎么省」——仿真翻倍造、人手视频借力、世界模型脑内预演、API 直接借训练成果。

**π API 的用法**：数据传云端、云端微调、模型下真机——某公司 33 条数据次日上真机，中小团队按条攒数据、按天迭代。

**Dream API 的定位**：zero-shot 无数据起步，48 步动作块 1.6 秒、$3/小时；适合先验证任务再决定要不要自采数据。

**混合架构的数字账**：26% → 48%（+22 点），保留 Astra 的 13s 级审查延迟——用时间换成功率，靠 π0.5 的 47ms 出动作兜住节奏。

**复习钩子**：造（仿真 54 万）、借（EgoDex 2 万 h）、演（世界模型）、租（π/Dream API）——一个字一条路。

**数账速记**：26%→48%（混合 +22 点）；33 条（π API 次日上真机）；59.3 vs 42.5（RoboDojo 6）；20/19、2/20、13s vs 47ms（Astra 对照）。

## 高频追问

1. **为什么 Astra 快不起来？** —— 它是通用大模型全包：感知、规划、出动作都过大模型，一次决策 13 秒；π0.5 把动作交给 47 毫秒的专业动作头。全包 26% 还慢，混合后 48%——通用性用在审查上，速度交给专用模型。
2. **π API 化对中小团队意味着什么？** —— 不用自建数据管线和训练集群，把少量数据传上去云端微调，33 条数据次日就能上真机；门槛从「养团队」降到「会采数据」，数据资产反而升值。
3. **仿真合成的数据偏差怎么处理？** —— 用少量真机演示锚定分布，合成只做大规模扩充（几十条 → 54 万条）；真机数据定「什么是标准操作」，合成数据补「量的覆盖」，偏差靠真机锚点压住。
4. **遥操数据为什么没法像文本那样攒？** —— 教机器人动手的动作数据没有互联网可爬，每条都要人遥控或真机跑，成本高、标准不统一，所以才要仿真、人手视频、世界模型、API 四条路一起破。
5. **Dream API zero-shot 是噱头吗？** —— 看数字：无数据 48 步动作块 1.6 秒、$3/小时，RoboDojo 6 真机 59.3 对 Astra 42.5；对零数据又想快速上真机的团队是真实选项，极限性能仍取决于任务匹配度。

## 易错点

- **以为堆遥操时长是唯一解**：仿真、人手视频、世界模型、API 化四条破法，别单腿走路。
- **把大模型全包当先进**：Astra 全包 26%，混合 48%——大模型当监工比当工人值钱。
- **只看战绩不算成本**：Dream API $3/小时按用量计费，规模化要算总账。
- **记混两组成绩**：RoboDojo 6 上 Dream API 59.3 对 Astra 42.5；大小脑混合是 26%→48%，两组数字别串。
