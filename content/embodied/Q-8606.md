## 口述答案

> 直答：先把 PPO 五步背下来——**采样动作、算回报、critic 估价值、算优势（A=R−V）、更新 policy**。GRPO 把第三步干掉了：同一任务/同一 prompt 采样一组（N 个 rollout），组内相对比较——减均值、除标准差——直接当优势，不要 critic。
>
> 具身场景为什么偏爱 GRPO：VLA 模型太大，critic 是一个和价值头同大的网络，养不起；GRPO 用组内排名替代价值估计，省掉的就是这一整块参数。
>
> 但 GRPO 有前提：组内比较要求**同一任务可重复采样**——同一个任务 reset 回同一起点，采 N 条轨迹才能互相比。真机上重置贵、又不能并行，所以这件事落进仿真里做。
>
> 一句话收束：PPO 的优势是「比 critic 预期好多少」，GRPO 的优势是「比同组平均好多少」——基线从学出来的网络换成了免费的组统计量。
>
> **「PPO 带裁判，GRPO 让选手互相排名——裁判也是要吃饭的（参数）」**

## 讲深一层

| 维度 | 要点 | 展开 |
|---|---|---|
| PPO 第一步 | 采样动作 | 当前 policy 与环境交互，on-policy：采一次用一次 |
| PPO 第二步 | 算回报 | 沿轨迹累计奖励 |
| PPO 第三步 | critic 估价值 | 单独的价值网络给状态定价 |
| PPO 第四步 | 算优势 A=R−V | 实际回报比 critic 预期好多少 |
| PPO 第五步 | 更新 policy | 按优势方向更新 |
| GRPO 优势 | 组内相对比较 | 同一任务采 N 个 rollout，减均值、除标准差当优势 |
| GRPO 省在哪 | 不要 critic | 少一个和价值头同大的网络，VLA 场景省的是大头 |
| GRPO 前提 | 同一任务可重复采样 | 真机重置贵、不能并行 → 放仿真里做 |
| 适用对比 | 组内比较 vs 价值估计 | 排名是免参数的基线，估值要一整个网络 |

**口误高发处**：五步顺序（采样在回报前）、优势是减法（R 减 V，不是别的组合）、GRPO 的标准化是先减均值再除标准差——三处顺序都不能颠倒。

**与 Q-8605 的衔接**：GRPO 正是 VLA 缺 critic 时的替代解——组内比较消掉价值网络；而「同一任务可重复采样」在真机上贵，又把训练推回仿真。

**为什么说「裁判要吃饭」**：critic 与 policy 同大——VLA 本身就大，critic 一上，显存、稳定性、训练时间全翻倍；GRPO 把这块参数开销换成采样开销——模型大、采样又能并行的具身仿真场景里是笔划算账。

**记忆抓手**：PPO 五步一个动词链（采样→回报→估值→优势→更新），GRPO 只改一处——第三步换成「组内排名」。

## 高频追问

1. **GRPO 的组大小 N 怎么权衡？** —— N 越大，组均值/标准差越稳，优势估计的方差越小；但采样成本随 N 线性涨，具身任务每条 rollout 都是实打实的仿真或真机时间。随机性大的任务加大 N，算力紧就减。
2. **真机上能跑 GRPO 吗？** —— 逻辑上能、成本上贵：它要求同一任务重置到同一起点再采 N 条，真机重置要人或机构介入、又不能像仿真那样大规模并行；主流做法是放仿真里跑。
3. **优势函数的直观含义？** —— 「这个动作比预期好多少」。PPO 里预期来自 critic（A=R−V）；GRPO 里预期就是组平均——选手互相排名，裁判退休。
4. **GRPO 省了参数，数据复用上省了吗？** —— 没省：PPO 和 GRPO 都属 on-policy，采一次用一次，GRPO 的组 rollout 也是当轮用完即弃——它省的是网络，不是数据。
5. **「同一 prompt」在具身里指什么？** —— 语言模型里 GRPO 对同一 prompt 采多个回答；具身里对应同一任务、同一初始状态重复 rollout——任务可重置、可重复采样，组内比较才成立。

## 易错点

- **「GRPO 不要 critic＝没有基线」**：组内减均值、除标准差本身就是基线，只是用采样统计替代了学出来的网络，不是裸奔。
- **「优势直接拿回报 R 用」**：不减基线的回报方差大、学不动；PPO 减 V、GRPO 减组均值，本质是同一件事。
- **「GRPO 可以无脑上真机」**：前提是同一任务可重复采样；先想清楚 reset 怎么做，再谈训不训。
- **「critic 只是个小附件」**：critic 与 policy 同大，VLA 场景等于显存翻倍——GRPO 省的就是这块大头。
