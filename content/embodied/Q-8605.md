## 口述答案

> 直答：给 VLA 加 RL，卡在两件事上——**模型太大，真机探索贵**，所以要把训练搬进仿真里并行跑（PyRL、SimpleVLARL 这类方案）；**VLA 是 SFT 出身的，缺 RL 需要的三样东西**：critic、动作概率、奖励。
>
> 面试开口顺序：先报两大难点，再展开缺的三样，最后报三条路线的名字——结构清楚，一分钟讲完。
>
> 缺的三样，一样一样说。**critic**：SFT 出来的模型没有价值网络，替代办法是 GRPO 组内相对比较，或外接一个价值头。**动作概率**：flow matching 去噪是确定性的，「这个动作的概率」算不出来——这正是当前新工作的焦点；离散动作 token 的概率反而天然就有。
>
> 第三样是**奖励**：真机上的奖励设计本身就难。再加上模型太大、整体更新不现实，于是有三条「只训部分参数」的路线——**LoRA**（RL4VLA）、**动作专家**（πRL）、**冻结全模型，只训一个初始化噪声的小模型**。三条路的共同点是不动整个 VLA，差别在动哪一部分。
>
> **「VLA 上 RL 的第一道坎不是算法，是『这个动作的概率』算不出来」**

## 讲深一层

| 维度 | 要点 | 展开 |
|---|---|---|
| 难点一：模型大 | 真机探索贵 | 真机采一条是一条，放仿真里并行训练——PyRL、SimpleVLARL 类方案 |
| 难点二：SFT 出身 | 缺 critic | GRPO 组内相对比较替代，或外接价值头 |
| 缺动作概率 | flow matching 去噪是确定性的 | 概率难算，是新工作焦点；离散动作 token 概率天然有 |
| 缺奖励 | 真机奖励设计难 | 没有现成奖励可抄，要围绕真实任务重新设计 |
| 路线一：LoRA | RL4VLA | 低秩增量，只训部分参数 |
| 路线二：动作专家 | πRL | 主干旁配动作专家，RL 不直接动整个 VLA |
| 路线三：冻结全模型 | 只训初始化噪声的小模型 | 主干完全冻结，RL 更新落在小网络上 |
| 选型逻辑 | 动得起哪部分、算得起哪种梯度 | 三条路线都是「只训部分参数」的不同切法 |
| 延伸 | Q-8606 详讲 GRPO | critic 替代与组内比较的细节在那张卡展开 |

**三样缺失的替代关系**：critic 有两条替代路——GRPO 直接消掉价值网络（组内比较），外接价值头则保留 critic 思路、多养一个网络；动作概率最难绕，确定性去噪拿不到概率密度，新工作集中在这里。

**为什么第一反应是仿真**：RL 吃采样量，真机单条轨迹贵且慢；仿真可以大量并行 rollout，把样本成本压下来——PyRL、SimpleVLARL 就是这个口径的方案。

**离散与连续的分界**：动作是离散 token 时，softmax 概率天然可算，RL 接口是现成的；动作走 flow matching 连续去噪时，「概率算不出」成为整条链的第一道坎——同一面墙，离散侧畅通、连续侧堵死。

**记忆抓手**：两难点（大、SFT 残缺）→ 三缺失（critic、概率、奖励）→ 三路线（LoRA、动作专家、噪声小模型）——按 2-3-3 往下背。

## 高频追问

1. **flow matching 为什么难算动作概率？** —— 去噪是确定性过程，动作不是从显式分布里采出来的，没有现成概率密度可写进策略梯度；离散动作 token 走 softmax，概率天然就有。「把确定性去噪的概率算出来」本身成了新工作的焦点。
2. **GRPO 怎么绕开 critic？** —— 同一任务采一组 rollout，组内减均值、除标准差直接当优势；「比组里平均好多少」替代「比 critic 估的价值好多少」，省掉一个和价值头同大的网络。
3. **LoRA 在 RL 里和 SFT 里表现为何不同？** —— SFT 的损失是逐 token 对齐参考答案，低秩增量学的是「往参考上靠」；RL 的更新信号是回报驱动的行为分布改变，同样的低秩增量作用机制不同——所以 RL 里用 LoRA 需要专门工作（RL4VLA）验证。
4. **SFT 完直接上 RL 行不行？** —— 直接上会卡在信号上：critic、动作概率、奖励三样都没有，得先解决「梯度从哪来」——GRPO 消 critic、动作概率交给新工作、奖励围绕真机任务重新设计，然后才谈得上训。
5. **仿真并行（PyRL/SimpleVLARL）解决的是哪个难点？** —— 难点一「模型大→真机探索贵」：仿真大量并行 rollout 出样本；但难点二的概率/critic/奖励问题，仿真替你解决不了。

## 易错点

- **「先调算法再看模型给不给力」**：顺序反了——第一道坎是动作概率算不出来，梯度信号都没有，算法无从谈起。
- **「flow matching 的概率能像离散 token 一样直接算」**：去噪是确定性的，没有采样分布可积；这是新工作的焦点，不是已有解。
- **「缺 critic 就再训一个大的」**：critic 与价值头同大，VLA 场景显存翻倍；GRPO 或外接轻量价值头才是省法。
- **「奖励照搬仿真那套」**：真机奖励设计本身是难点，任务判据要围绕真实硬件与任务重来。
