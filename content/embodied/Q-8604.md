## 口述答案

直答：模仿学习是 VLA 操作层的主力学法——人带着机器人做，它照着学。但它的成功率上限被示范质量锁死：示范里有什么它才会什么，实际水平卡在约 80%。

卡住的原因有两个。一是示范覆盖不到的失败态没法恢复：东西滑了、姿态歪了，这种局面示范里没出现过，策略当场就懵；二是数据分布偏移——自己一走偏就进入没见过的状态，越偏越远。

关键认知：这 80% 不是「再补数据」能解决的。失败态恰恰在示范分布之外，补示范永远补不到它——所以要换学习范式，不是换数据量。

RL 为什么能超越示范：它的学习信号是环境给的分数，不是示范的动作。RLToken 的插网线任务是现成例子：人类遥操 146 步完成，模仿学习要 228 步，RL 只用 66 步——RL 找到了比人更短的动作序列。

代价也要说清楚：RL 要靠大量试错去换高分，先用无数次不及格铺路。收一句：**「示范定义了及格线，RL 才能定义满分——但满分要用无数次不及格换」**。

| 卡点一 | 失败态没法学 | 示范覆盖不到的失败态没法恢复，一遇意外就懵 |

| RL 的代价 | 无数次不及格 | 高分是大量试错换来的，训练成本和探索开销要计入 |
| 选型口径 | 模仿打底、RL 冲上限 | 示范先保证及格，要「比人做得更好」再上 RL |
| 分布内 vs 分布外 | 失败态在分布外 | 示范只覆盖「走对的路」，失败态天然不在里面 |
| 范式结论 | 换范式而非堆数据 | 要越过 80%，靠的是 RL 的试错与分数信号 |
| covariate shift | 协变量偏移 | 分布偏移的学名：执行时的状态分布偏离了示范分布 |
| 复合误差 | 一步偏、步步偏 | 走偏后无示范可依，误差随步数累积放大 |

**分布偏移的直观图景**：示范数据是一条「走对了的路」，模仿学的是「在这条路上每步该怎么走」；一旦踩偏半步，脚下就是示范里没画出来的地方，错一步、偏一丈——这就是误差复合放大的来源。

**RL 没有这个问题的原因**：RL 的策略自己走出状态分布，失败态它亲身去过、被低分惩罚过，「走偏了怎么回来」也在学习信号里——这正是它能超越示范的机制。

**数字要背**：146 / 228 / 66——人类遥操、模仿学习、RL 的插网线步数，一组数字讲清「RL 找到比人更短的动作序列」。

**一句话记法**：示范定及格线（80%），RL 定满分（66 步对 146 步），满分是摔出来的。

## 高频追问

1. **为什么模仿学习有分布偏移（covariate shift）而 RL 没有？** —— 模仿只在示范的状态分布上学，自己执行走偏后进的是示范没覆盖的状态，错了没人教它回来，误差复合放大；RL 在自己走出的分布上训练，失败态亲身经历过、被分数修正过。
2. **80% 失败的那 20% 一般败在哪？** —— 败在示范覆盖不到的失败态：物体滑了、姿态歪了、到中途出了意外，示范里没有「这种情况怎么恢复」的样本，策略没法恢复。
3. **示范质量很高，还需要 RL 吗？** —— 示范质量决定模仿的上限，上限就是示范本身；只要任务要求「比人做得更好」——比如 RLToken 里 66 步对 146 步——就得靠 RL 超越示范。
4. **那能不能靠堆示范数据把 80% 提上去？** —— 提不动：失败态在示范分布之外，补示范补不到它；这是范式问题不是数据量问题，要换学习范式。
5. **模仿和 RL 能不能混着用？** —— 能，这也是操作层的常见做法：模仿打底先到及格线（约 80%），再用 RL 的分数冲上限、补失败态恢复；三层架构里「操作层模仿+RL 混合」说的就是这件事。

## 易错点

- **把 80% 当成数据量问题**：不是「再补数据」能解决的——失败态在示范分布之外，要换学习范式。
- **以为模仿学习上限很高**：模仿的成功上限=示范质量，示范什么水平，学出来就什么水平。
- **以为 RL 会更笨、步数更多**：RLToken 插网线任务里 RL 66 步，比人类遥操的 146 步还短——RL 找到了比人更短的动作序列。
- **把两种学习信号搞混**：模仿学习对示范动作负责，RL 对环境分数负责，优化目标根本不同。
