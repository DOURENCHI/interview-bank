## 题目

**题目**：配网络时四个参数：IP、掩码、网关、DNS，分别管什么？

**问**：IP、子网掩码、网关、DNS 各起什么作用？

## 口述答案

> **IP** 是主机在网络中的地址；**子网掩码**划分"哪些地址在同一网段"（决定是直接发还是交给网关）；**网关**是跨网段的出口（默认路由）；**DNS** 把域名解析成 IP。
> 一句话串起来：**掩码判断同不同网段 → 不同就发给网关 → 网关路由出去 → 访问域名时先问 DNS**。

## 讲深一层

| 参数 | 作用 | 配错的症状 |
|---|---|---|
| IP | 本机地址 | 冲突/不通 |
| 掩码 | 划分子网 | 同网段却走网关，或跨网段直发失败 |
| 网关 | 跨网段出口 | 能通内网、不通外网 |
| DNS | 域名→IP | 能 ping IP、不能 ping 域名 |
```bash
ip addr        # IP + 掩码
ip route       # 默认网关
cat /etc/resolv.conf   # DNS
```
- 同一网段的判断：`(ip1 & mask) == (ip2 & mask)`。
- 排查口诀：**能通 IP 不通域名 = DNS；能通内网不通外网 = 网关**。

## 高频追问

1. **掩码 255.255.255.0 表示什么？** —— 前 24 位是网络号，同网段最多 254 台主机。
2. **没有网关会怎样？** —— 只能和同网段通信。

## 易错点

- 配了 IP 没配掩码/网关，只能通局部
- 把 DNS 配成网关地址
