## 题目

**题目**：面试官问"OSI 七层和 TCP/IP 四层怎么对应"，很多人卡在"会话层去哪了"。

**问**：OSI 七层模型和 TCP/IP 四层模型怎么对应？

## 口述答案

> TCP/IP 四层是**应用层 / 传输层 / 网络层 / 网络接口层**。对应关系：OSI 的**应用+表示+会话**三层合并成 TCP/IP 的应用层；**传输层、网络层**一一对应；**数据链路+物理**合并成网络接口层。
> 所以"会话层去哪了"的答案是：**被并进应用层**了，实际由应用自己（HTTP 的 keep-alive、TLS 会话）实现。

## 讲深一层

| OSI 七层 | TCP/IP 四层 | 典型协议 |
|---|---|---|
| 应用 / 表示 / 会话 | 应用层 | HTTP、MQTT、DNS、TLS |
| 传输 | 传输层 | TCP、UDP |
| 网络 | 网络层 | IP、ICMP、ARP |
| 数据链路 / 物理 | 网络接口层 | Ethernet、WiFi |
- 分层的好处：每层只关心自己的封装，改一层不影响其他层。
- 面试常追问"ping 用哪层"：ICMP 在网络层；"ARP 呢"：网络层与链路层之间。
- 数据封装：应用数据 → TCP 段 → IP 包 → 帧 → 比特。

## 高频追问

1. **TLS 属于哪层？** —— 严格说在应用层与传输层之间，通常算应用层。
2. **交换机/路由器各工作在几层？** —— 交换机二层（也有三层交换机），路由器三层。

## 易错点

- 说 OSI 是"实际使用的模型"（实际是 TCP/IP）
- 把 ARP 归到应用层
