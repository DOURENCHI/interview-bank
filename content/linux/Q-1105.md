## 题目

**问**：硬链接和软链接有什么区别？为什么硬链接不能跨分区？

## 口述答案

> 关键在 **inode**。inode 存的是文件的元数据（权限、大小、数据块位置），**不含文件名**；
> 文件名只是目录里的一条「名字 → inode 号」的映射。
> **硬链接**是再建一条名字到同一个 inode 的映射，两个名字地位平等，删掉一个另一个还能用，
> inode 的链接计数减一，减到 0 才真正释放数据。
> **软链接**是新建一个文件，内容是「目标路径」，指向的是名字不是 inode。
> 硬链接不能跨分区，因为 inode 号只在单个文件系统内唯一。

## 讲深一层

```bash
ln file hard          # 硬链接
ln -s file soft       # 软链接
ls -li                # 看 inode 号
stat file             # 看链接计数
```

| 维度 | 硬链接 | 软链接 |
|---|---|---|
| 指向 | inode | 路径名 |
| 跨分区 | ❌ | ✅ |
| 能指向目录 | ❌（一般） | ✅ |
| 原文件删除后 | 仍可用 | 变成断链 |
| inode 号 | 相同 | 不同 |

## 高频追问

1. **为什么软链接能指向不存在的文件？** —— 它只存路径，不做存在性检查（悬空链接）。
2. **删了原文件，硬链接还在吗？** —— 在，链接计数没到 0。
3. **`rm` 到底删了什么？** —— 删目录项（名字），inode 计数减一。

## 易错点

- ❌ 说「硬链接是复制」 —— 不占额外数据块
- ❌ 说「软链接也是同一个 inode」
- ✅ 用 inode 和链接计数把机制讲清
