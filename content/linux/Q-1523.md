## 题目

**题目**：设备插上网线就能拿到 IP，这个过程谁在管？

**问**：DHCP 协议是干什么的？流程是什么？

## 口述答案

> DHCP 负责**自动分配 IP 地址和网络参数**（掩码、网关、DNS）。流程四步：**Discover**（广播找服务器）→ **Offer**（服务器给候选地址）→ **Request**（客户端确认要哪个）→ **Ack**（服务器确认）。
> 地址有**租期**，到期前客户端要续租（Renew，单播给原服务器）。

## 讲深一层

| 报文 | 方向 | 作用 |
|---|---|---|
| Discover | 客户端广播 | 谁是 DHCP 服务器 |
| Offer | 服务器→客户端 | 我给你这个地址 |
| Request | 客户端广播 | 我要这个 |
| Ack | 服务器→客户端 | 确认，租期开始 |
- 基于 UDP：服务器 67 端口，客户端 68 端口。
- 没有 DHCP 时可以用静态 IP 或 link-local（169.254.x.x，就是"拿了地址但没通"的表现）。
- 嵌入式里精简实现常用"静态 IP + 手工配置"，省一个协议栈。

## 高频追问

1. **看到 169.254 开头说明什么？** —— DHCP 失败，用了自动私有地址。
2. **DHCP 能跨网段吗？** —— 能，靠 DHCP 中继（relay）。

## 易错点

- 说 DHCP 用 TCP
- 不知道租期和续租
