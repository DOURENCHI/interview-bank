## 题目

**问**：`755`、`644` 是怎么算出来的？umask 在什么时候起作用？

## 口述答案

> 权限分三组：属主、属组、其他人，每组三位分别对应读（4）、写（2）、执行（1）。
> `755` = 属主 rwx(7)、属组 r-x(5)、其他 r-x(5)。
> `umask` 是**新建文件/目录时的权限掩码**：实际权限 = 默认权限 & ~umask。
> 普通文件默认 `666`、目录默认 `777`，umask 022 就得到 `644` 和 `755`。
> 注意 umask 只影响**新建**，已存在的文件改了 umask 也不会变。

## 讲深一层

```bash
chmod 644 file          # 数字法
chmod u+x,go-w file     # 符号法
umask                   # 查看
umask 027               # 设置：新建文件 640、目录 750
```

| 数字 | 权限 |
|---|---|
| 7 | rwx |
| 6 | rw- |
| 5 | r-x |
| 4 | r-- |
| 0 | --- |

为什么目录需要 `x`：进入目录（cd）和执行其中的文件都需要目录的 `x` 位；只有 `r` 只能列目录不能进。

## 高频追问

1. **目录的 `r` 和 `x` 分别管什么？** —— `r` 允许列文件名，`x` 允许进入和访问其中条目。
2. **粘滞位（`t`）是干什么的？** —— `/tmp` 用，目录里只有属主能删自己的文件。
3. **umask 能按进程设吗？** —— 能，它是进程属性，子进程继承。

## 易错点

- ❌ 以为 umask 是可加权限 —— 它是减去
- ❌ 忘了目录的 `x` 位
- ✅ 说出「默认 666/777 减 umask」
