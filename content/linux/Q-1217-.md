## 题目

**背景**：手撕题，白板写代码。
**问**：判断一个字符串是不是回文，要求不申请额外空间。

## 口述答案

> 双指针夹逼：左指针从头、右指针从尾，两边字符相等就同时向中间走，相遇即回文。时间 O(n)，空间 O(1)——没有额外空间，符合要求。边界：空串和单字符都算回文。如果题目追加"只看字母数字、忽略大小写"（LeetCode 125 变体），就在比较前各自跳过非字母数字并统一小写，指针跳的时候注意不要越过对方。还有一个高频变体是**单链表判回文**：快慢指针找中点，反转后半段再逐个比对，最后恢复链表。

## 讲深一层

```c
bool is_palindrome(const char *s) {
    int i = 0, j = (int)strlen(s) - 1;
    while (i < j)
        if (s[i++] != s[j--]) return false;
    return true;
}
```
- 忽略大小写版：`while (i<j && !isalnum(s[i])) i++; while (i<j && !isalnum(s[j])) j--;` 再比 `tolower`

## 高频追问

1. 单链表怎么判回文？——快慢指针找中点 + 反转后半段，O(1) 空间
2. 允许删除一个字符呢？——LeetCode 680，遇到不匹配时分"跳左"和"跳右"各验一次

## 易错点

- 用 `strcpy` 到临时串再比较——额外空间，直接违背题意
- 忘了空串按回文处理
